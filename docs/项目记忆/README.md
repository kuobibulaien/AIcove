## 模块边界速查（改对应模块前读 [全文](模块边界补充.md)）

| 模块 | 边界 | 决策 |
|---|---|---|
| 插件预设与角色绑定 | 插件配置统一预设化，角色卡按插件绑定预设；绘图、音色已改造，其他逐步接入 | ADR0008／0009 |
| MCP 连接器 | 每个连接器是插件 `mcp:<id>`，角色必须显式开启（「全部插件」不含）；只支持远程 Streamable HTTP＋令牌 | ADR0072 |
| 插件标签说明 | 全局一份，请求时统一覆盖；预设与插件配置不携带 | ADR0054 |
| 插件上下文过滤 | 插件关闭后，请求副本屏蔽对应标签与工具对，原始历史保留 | ADR0017 |
| 语义标签 | 标签统一经 `content_tags` 注册表声明、唯一扫描器解析，新标签不得各写正则；输出 HTML 的美化正则不执行 | ADR0044／0046／0048 |
| 酒馆兼容 | 组合预设按请求 owner 解析，绑定缺失时不静默回退；世界书只注入 raw 派生副本；SPreset／Kemini 由请求独立的 QuickJS 执行 | ADR0010／0042／0043／0059 |
| 分段 | 只切正文句子，组件内部（多模态标签、折叠／选项标签、代码块）不切，流式层与列表层共用同一规则 | ADR0047 |
| 记忆与上下文 | 原文是唯一真相；短期＝`features/context`，长期＝`features/memory`（由记忆 Agent 整理，聊天模型没有记忆工具）；新表暂不同步 | ADR0038 |
| 编辑提交 | 草稿按 owner 隔离，发送时校验 raw 版本并在同一事务落库 | ADR0012 |
| 语音渠道格式 | 新语音协议只往 `TtsRequestFormat` 注册表加，路由只认 `customConfig.requestFormat`，不按网址／模型名猜 | ADR0081 |
| 语音识别格式 | 新识别协议只往 `AsrRequestFormat` 注册表加并继承 `WebSocketSpeechRecognizer`，路由只认 `customConfig.asrRequestFormat`（与 requestFormat 分开） | ADR0082 |
| 音色预设 | 请求时固定 owner 与供应商快照 | 补充文 |
| 应用数据目录 | 应用自己的文件根目录只经 `appDataDirectory()` 取（Windows／Linux＝应用数据目录，其他平台＝文档目录），不直接调 `getApplicationDocumentsDirectory()`；用户导出的文件才放「文档」 | ADR0086 |
