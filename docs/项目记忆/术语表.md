# 术语表

> 领域术语统一口径。实现类名可以更具体，但文档与需求优先使用这里的口径。出现新术语时追加，带「避免使用」的别名。


## 插件配置包与酒馆预设（2026-09-06）

**插件配置包（Plugin Configuration Package）**：
一小包已打包好的插件专属设置，例如音色配置包包含具体渠道、模型、TTS 基本参数、音色 ID／文件等。角色卡按插件绑定配置包，未绑定时使用对应默认配置包。“包”是配置的逻辑组合，不强制是压缩文件，不规定存储格式。
_可用限定别名_：插件预设、音色预设、绘图预设；跨模块说明优先写插件配置包、音色配置包、绘图配置包、默认配置包。
_避免使用_：无上下文的“预设”、酒馆预设、SillyTavern Preset（这些不是该对象的同义词）。

**酒馆预设（SillyTavern Preset）**：
项目兼容的酒馆预设资源，涉及提示词条目、顺序及相关生成配置。与插件配置包是两个概念，不能因都曾称“预设”而混用绑定、ID、导入格式或运行时职责。
_避免使用_：插件配置包（直接当同义词）、两类对象同屏时不加限定的“预设”。

**酒馆兼容插件的配置包**：
若酒馆兼容插件使用统一配置包管理，外层包可引用酒馆预设、正则、世界书等资源；外层配置组合不等于内部酒馆预设。术语澄清不削减酒馆兼容范围，不授权代码重命名或数据迁移。

正式规范：[插件预设与角色卡绑定规范](../../apps/aicove_flutter/docs/02_前后端分离与架构规范/插件预设与角色卡绑定规范.md)。已有文档中的“插件预设／默认预设”按本节理解，不解释为酒馆预设。

## Agent 运行时

**Harness Runtime（Agent 驱动运行时）**：
在设备本地运行的官方 DeepSeek Harness/Cordis 插件树，负责 Agent loop、会话、工具、上下文和子 Agent 调度。
_避免使用_：Dart Agent 壳、自研 Harness

**Harness Host（Harness 宿主）**：
负责安装、启动、监督和升级 Harness Runtime，并向产品层报告状态的 Android 原生组件。
_避免使用_：Agent 本体、模型服务

**Aicove Bridge Plugin（Aicove 桥接插件）**：
安装在 Harness Runtime 中、把 Harness 会话和工具能力映射到 Aicove 产品契约的 Cordis 插件。
_避免使用_：Flutter 插件、WebView 桥

**设备能力（Device Capability）**：
由 Flutter 或 Android 原生层实现、可被 Harness 调用的设备与产品能力，例如通知、TTS、相册和本地消息投递。
_避免使用_：Harness 插件

**执行后端（Execution Backend）**：
承接命令、文件或 Android 系统操作的实际执行身份，可以是应用 UID、Shizuku shell UID 或 Root UID。
_避免使用_：权限等级

**运行时分发包（Runtime Bundle）**：
独立于 APK 版本安装和回滚的、包含 Node、Termux 用户空间、DSH 与兼容补丁的签名产物。
_避免使用_：模型包、APK 插件

**能力路由器（Capability Router）**：
按具体能力声明、用户模式和实时探测结果，在应用 UID、Shizuku shell UID 与 Root UID 后端之间选择并向下降级的宿主组件。
_避免使用_：Root 开关、权限等级判断器

**Agent 执行真相源（Agent Execution Truth）**：
记录模型实际可见历史、工具调用、compaction、分支和恢复状态的 DSH SessionEvent log。该定义属于 AIcove 2.0 proposed 架构，在 ADR 接受前不取代现行 1.x 规范。
_避免使用_：聊天数据库副本

**产品消息真相源（Product Message Truth）**：
记录联系人时间线、消息展示、多模态投递、已读/隐藏、备份和同步状态的 Drift raw message。
_避免使用_：DSH 上下文日志

**会话绑定（Session Binding）**：
AIcove conversation/agent 与 DSH session/branch 之间的显式持久映射，同时保存 seed 与投影游标。
_避免使用_：隐式同步关系

**事件投影（Event Projection）**：
把 DSH SessionEvent 幂等转换成 AIcove 产品消息或输出动作的单向过程；投影结果不是第二个 Agent 执行真相源。
_避免使用_：双向同步、全量覆盖

## 模型思考档位

**思考档位（Thinking Level）**：
统一的模型思考强度口径，canonical 值为 `auto/off/minimal/low/medium/high/xhigh/max`；`auto` 表示不发任何 thinking 参数。持久层与 UI 只用这套值，上游字段由 adapter 翻译。见 `决策记录/0003`。
_避免使用_：reasoning_effort（那是 OpenAI 的上游字段名）、思考预算（那是 budget 方案的一种实现）

**档位方案（Thinking Scheme）**：
某个模型把 canonical 档位翻译成上游参数的方式：`openaiEffort` / `claudeEffort` / `claudeBudget` / `geminiLevel` / `geminiBudget` / `generic`。由「供应商类型 + 模型 id」查表得出。
_避免使用_：协议、供应商类型

**软件默认档位（Software Default）**：
用户与模型都没设置时使用的档位——能关就关（`off`），不能关取该模型最低档；`generic` 方案例外，保持 `auto`。
_避免使用_：上游默认

**会话档位覆盖（Session Override）**：
存在 `conversations.thinkingLevels`（模型 key → 档位）里的用户显式选择，按会话隔离，同会话内换模型沿用该模型上次的设置。
_避免使用_：全局档位

## 全端共用界面（2026-09-11）

| 术语 | 统一含义 | 避免混用 |
|---|---|---|
| Mac 基准 | 在 macOS 确立共享设计并先验宽窄窗口，其他客户端复用同一页面 | Mac 专用业务前端 |
| 窄屏模式／手机模式 | 同一内容区展示一级界面或详情栈顶页的布局模式 | 根据操作系统判断的手机版分支 |
| 宽屏模式 | 左侧悬浮完整手机一级界面，右侧展开同一套详情；覆盖窄屏全部页面与入口 | 独立桌面首页、另做桌面设置 |
| 悬浮手机面板 | 由标题、内容和底部导航组成的完整一级界面，带外围留白、圆角和阴影 | 简化侧栏、手机模拟器、远控实例 |
| 详情界面／详情栈 | 二级及更深业务页面和它们的返回顺序；窄屏全页展示，宽屏放在右侧 | 仅聊天区、第三栏、各端独立栈 |
| 自适应布局壳 | 集中管理模式、尺寸、页面承载位置与局部约束的共享容器 | 分端复制的根页面 |

正式规范：[全端共用界面架构与布局规范](../../apps/aicove_flutter/docs/界面布局说明.md)。

## 高级材质（2026-09-14）

**高级材质**：纯色、毛玻璃、液态玻璃三种可跟随全局材质设置变化的材质的统称。“已接入高级材质”表示组件独立使用或共用统一材质表面，并按当前模式响应全局设置；纯色的现有厚度行为、三层可读性与接入判定统一见[高级材质系统](../../apps/aicove_flutter/docs/公共组件总览.md#advanced-materials)。
_避免使用_：只把液态玻璃称为高级材质；把任意固定纯色背景都算作已接入；把悬浮／背景／文字三个层级当作三种材质模式。
