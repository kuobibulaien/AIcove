# 0093 AIcove酱全权限：能做的都自己做，危险操作每次确认，读正文按角色授权

- 状态：accepted（2026-10-19 用户确认）
- 日期：2026-10-19
- 关联：修订 ADR0073 决定 5（工作范围）与「禁止档」的适用范围；ADR0066（本地隐私优先）
- 方案：[AIcove 助手与新手教程](../../../apps/aicove_flutter/docs/04_功能模块规范/AIcove助手/README.md)

## 背景

内置助手改名 AIcove酱后，用户要求她成为「完全体」Agent：用户大多是新手，软件里的事尽量由她直接做，用户能不动手就不动手。原先她只能改角色卡文字、预设开关和 13 项设置，其余都靠「去看看」按钮让用户自己点。

## 决定

1. **能做的都自己做**：工具覆盖设置全集、模型渠道、角色卡全部字段（图片、音色、思考档位、置顶免打扰）、酒馆预设的导入与扩充、插件全局选项。提示词要求「有工具就直接动手，不教用户去哪个页面点」。
2. **只有三件事必须用户亲手**：粘贴 Key／令牌、从自己设备选文件、系统权限弹窗。这三件由她把卡片递到聊天页（Key 卡片可带新渠道草稿，用户粘贴后才创建渠道），模型永远看不到 Key。
3. **危险操作能做，但每次确认**：删除角色、清空聊天、删除渠道、改渠道接口地址、删除预设一律是「重大」档，每次弹卡由用户点同意，审核模型不能代批。其余修改照旧按风险档，可撤销的进本机撤销日志（日志不存 Key）。
4. **读其他角色的聊天正文和长期记忆按角色授权一次**：第一次读某个角色时弹卡，同意后该角色以后直接可读，授权只存本机、可收回；隐私空间里的角色永远不可读写。
5. **工具按「工具组」接入**：新范围实现 `AssistantToolGroup`（工具、风险、确认文案自带），装配点只认工具组列表，加一组不改审批与装配代码。

## 代价

- 读正文会把那个角色的聊天内容发给 AIcove酱所用的模型渠道；靠「按角色同意一次＋可收回」约束，不做逐条确认。
- 删除角色在 App 里没有回收站界面，确认卡片明说找不回来。
- 暂不覆盖：编辑预设里已有条目／正则／世界书条目的文字（只能新增）、语音与绘图预设内容（ADR0092 施工中）、表情包库、联网搜索供应商与 MCP 连接器（要填令牌）、备份恢复、同步登录与局域网配对、空间文件；这些仍给页面按钮。
