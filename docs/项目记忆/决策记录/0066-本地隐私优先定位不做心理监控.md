# 0066 本地隐私优先定位，不做心理监控与内容审核

- 状态：accepted
- 日期：2026-10-07
- 关联：项目记忆 README 总览；ADR0065（诊断导出分级）

## 背景

项目记忆 README 原写“面向医院场景的 AI 心理陪伴助手”，导致 agent 按医疗产品推理，提出危机检测、心理安全兜底等建议。用户澄清了产品定位。

## 决定

- AIcove 是本地运行、隐私优先的 AI 陪伴聊天客户端，用于辅助排解情绪，**不是治疗产品**，作用等同用户直接在网页端与 AI 聊天。
- **不做**心理状态监控、危机检测与干预、内容审核，不读取通讯录或主动联系他人。理由：产品的陪伴价值建立在本地与隐私之上，监控用户心理即侵犯这份信任；团队也不具备审核资格。内容安全由用户所选的模型 API 厂商负责。
- 模型、TTS、生图、搜索等 API 外发由用户选择的服务决定，客户端只建议走官方渠道，不承诺防护。
- 安全设计聚焦**同步不泄露**：局域网同步扫码配对直连；服务器同步为用户自部署（无中心化服务器），有账号认证。
- 诊断与日志遵守 ADR0065：默认不含对话正文，完整内容只在用户本机主动选择时导出。

## 代价

- 用户在危机时刻不会得到客户端层面的额外提示，依赖模型厂商自身安全机制。
- 以后若有面向机构的部署形态，需要重新评估，不得在本定位下默认加入监控能力。

## 执行

agent 不再提出监控、危机干预、内容审核类功能建议；安全讨论聚焦同步与本地数据。
