# ADR0031：删除旧云端服务，仅保留云同步

## 背景与决定

用户明确要求清理云端文件夹及相关内容，不再需要中心化服务器配发 API 或会员；唯一云端功能是正在测试的云同步。

整目录删除会破坏现有同步，所以保留 `cloud_backend/` 路径与 `sync_v3/`、必要账号认证、数据库连接、运行配置和测试。删除旧 v1/v2 服务、API Key 配发与额度、会员、邀请码、云备份旧接口、云触发器、云记忆执行和 Prompt/Agent Studio。此决定取代 ADR0021 的“保留本地 Studio”与 ADR0030 的“其他云端代码只停维护”。

提示词 codegen 移到 `apps/aicove_flutter/tool/`，继续本地生成。客户端自行配置供应商 API；保留客户端 Agent 与随包资源。账号仅用于同步认证和数据隔离，保留命令行创建账号、登录和同步账号管理；未新增公开注册。

## 代价与回滚

旧管理面板与旧协议不再可用。现有数据库、旧表、附件、密钥、账号与客户端队列不删除或迁移；删除 ORM 中的会员字段不执行 ALTER/DROP。不触碰线上服务或用户数据，不恢复正在暂停的真实同步。

改动前源码及清单位于 `.codex-temp/cloud-retirement-20260913-172143/`；逐文件回滚避免覆盖并行工作。本地隔离验证不代表完整实机同步已验收。
