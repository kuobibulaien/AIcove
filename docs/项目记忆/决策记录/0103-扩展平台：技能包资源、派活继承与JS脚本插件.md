# 0103：扩展平台：技能包资源、派活继承与 JS 脚本插件

> 后续修订：安装与嵌套调用审批遵循 [ADR0107](0107-Agent工具默认无需审批.md)；工具命名、cwd 与嵌套调用管线遵循 [ADR0108](0108-Agent执行层与工具层按Pi收敛.md)。桌面非 JS 提示已改用 bash 与当前用户权限说明，macOS 关闭沙盒见 ADR0106；下文保留初版记录。

关联：0064（第三批）、0097（聊天／工具模式）、0098（QuickJS／桌面 shell）、0101（结果引用、校验、取消）。界面入口：聊天插件 →「扩展包」（`extension_packages_page.dart`），列出已安装包（技能数／脚本），桌面可导入文件夹、各端可导入 zip，导入后试加载脚本并提示失败原因，长按确认删除；角色仍在「管理插件」里逐个开启。

## 背景

Pi 审计第 5 节指出：声明式包只支持单篇 Markdown，标准技能携带的脚本、参考资料与模板会被拒绝；派活只继承搜索／MCP／工作区，不继承角色的包；QuickJS 代码模式尚不能安装第三方工具。这些断点使可复用技能无法沿角色授权到达真正执行任务的 Agent。

## 决定

### 角色的扩展随派活继承

- 杂活 Agent 继承发起角色显式开启的 `pkg:*`：声明式提示词、技能读取与技能 JS 工具、脚本插件的提示词和工具。其它聊天插件保持原规则。
- `TaskAgentCapabilities.prompts` 按插件 id 保存提示词，`toolOwners` 保存工具归属；runner 将提示词加入杂活系统提示，预设 `allowedPluginIds` 同时收窄工具和提示词。原有未标归属的手工能力调用保留原契约。
- 本机安装列表、插件 enabled、角色 roleExplicit 选择共同决定可用集合；预设只能收窄，不能新增角色未授权或本机不存在的包。冷启动先等包配置加载完。
- 聊天模式保留包提示词与只读技能工具，执行类工具交给杂活 Agent；工具模式直接拿执行工具。只读 Markdown 老技能的返回正文不变。
- 启停沿用角色 `enabledPlugins`：下一次 run 重新装配；已经绑定到旧 run 的工具和资源快照不被运行中替换。

### 标准技能可以携带完整资源目录

安装两种格式：

1. 原有 `aicove-package.json`，schema 仍为 1。原有 skill 的 `file` 保留；新增可选 `dir`，二者不能并用。
2. 根目录有 `SKILL.md` 的标准 Agent Skills 文件夹或 zip；SKILL.md 必须有 YAML frontmatter 中非空 `name`、`description`。不要求手写 manifest。包 id 将 name 转小写、非 ASCII 字母数字及 `-_` 的连续字符改为 `-`、去掉首尾 `-_`，结果须为 1～40 字符；版本为 `1.0.0`。同 id 导入按现有原子替换规则覆盖。

```json
{"schema":1,"id":"reports","name":"Reports","version":"1.0.0","contents":[
  {"type":"skill","dir":"skills/report"}
]}
```

`dir` 内须有 SKILL.md；技能名／说明默认来自 frontmatter，可用原有 `name`／`title` 覆盖。`dir:"."` 表示包根目录。目录内的所有文件视为已声明，包含 scripts、references、assets 以及普通隐藏资源；仅忽略 macOS `.DS_Store`、`._*`、`__MACOSX` 元数据。目录外仍拒绝未声明文件。

限制按解压后的实际内容计：**单包 20 MiB、1000 个文件、单文件 8 MiB**。目录读取与 zip 解压均在读取过程中限量；拒绝根目录或子项链接、绝对路径、`..`／`.`、空路径段、Windows 盘符或反斜线、控制字符，以及大小写／Unicode NFC 等价的重名。zip 支持根目录或一个外包装目录，不根据压缩包自报的解压大小放行。

### 模型按需读技能，JS 只读自己的资源

- `read_skill_<包id>({name})` 返回 SKILL.md 正文（去掉 frontmatter）和技能内的相对文件清单及大小。
- 同一个工具带 `path` 可读技能内文本，`offset=1`、`limit=200`，按行分页，limit 最多 2000；JSON 页返回 `next_offset`。二进制只返回 MIME 类型和字节数。长正文／大页走 ADR0101 的完整结果引用。
- 桌面平台的目录技能读回中还提供安装后的绝对路径，并说明非 JS 脚本只能通过已有 `workspace_shell`、逐条真人确认；macOS 应用沙盒限制不变。普通角色／后台杂活原本没有 shell 的，仍不获得 shell。
- 新增窄工具 **`run_skill_js_<包id>({name,path,args?,timeout_seconds?})`**。path 必须是该技能目录内的 `.js`，内容为异步函数体，允许顶层 await／return。
- JS 全平台复用 `WorkspaceScript`／`QuickJsAsyncSession` 宿主：64 MiB 堆、默认 30 秒、最长 120 秒、宿主并发 4、公网 fetch、当前 run 的 `tools.*`、text／console／image、相同的取消与收敛规则。
- `skill.list()` 返回本技能相对文件名；`await skill.readText(path,{offset?,length?})` 与 `readBytes` 按字节分段读，默认 4 MiB、单段最多 4 MiB，readBytes 返回 base64。它们读取不可变的技能快照，无写方法，不拼接任意磁盘路径。
- 扩展会话不隐式获得工作区，直接 `ws.readBytes/writeBytes` 报无授权工作区；需要工作区时通过当前 run 已授权的 `tools.workspace_*`。没有 Node、进程、shell 或任意文件系统接口。需要人工审批的工具不能在 JS 中间接放行。
- 扩展输出不先按 workspace 的 50 KiB 截断，而是交给 ADR0101 结果引用；沿用宿主最多保留最后 8 MiB 的 stdout 缓冲，超过时明确标记。现有 workspace_run_js 的输出产物与限制不变。

### 脚本插件只贡献工具和提示词

包新增内容项 `{"type":"script","main":"plugin.js"}`；一个包最多一个主文件，必须是包内存在的 `.js`。只从本地导入，不做细分权限：启用后可用上述宿主开放的全部能力，不能构建组件或新增页面。

```javascript
aicove.appendPrompt('需要计算时使用本包工具。');
aicove.registerTool({
  name: 'triple',
  description: '返回输入数值的三倍',
  inputSchema: {
    type: 'object', properties: {value: {type: 'integer'}}, required: ['value']
  },
  handler: async input => {
    const value = input.value * 3;
    text(value);
  }
});
```

- `registerTool`／`appendPrompt` 在加载阶段声明；加载阶段不允许网络或其它宿主调用。handler 中才使用 fetch、其它当前可用工具、文字输出和包内只读资源（`skill.*` 的范围在插件 handler 中是该包）。
- 注册名必须以字母开头，后续为字母、数字、下划线；模型工具名为 `pkg_<包id长度>_<包id>_<注册名>`，完整长度最多 64。长度前缀消除包名与局部名中下划线的拼接歧义；同包重名或不合法声明使脚本加载失败。
- 原始 inputSchema 直接交给 ADR0101 统一参数校验；handler 通过 controlledHandler 接收取消。插件 handler 默认 30 秒，64 MiB 堆。
- 每次调用都新建独立 QuickJS 会话，包括上次成功、异常、超时或取消之后；不跨调用保存 JS 状态。一个调用出错返回 isError，后续调用可重建继续；其它插件及 Agent 循环不被中断。
- 加载失败记录 `PackageScript.loadError` 和应用日志，跳过该脚本的全部工具／提示词贡献；同包独立声明的提示词／技能仍按原声明式规则使用。它不是请求必需的酒馆预设，不改变预设加载失败阻止发送的契约。
- 通过 tools 调用其它工具仍走当前 run 的统一校验／授权／取消链，不拿原始 handler；不导出本脚本自己的工具以避免直接自递归。宿主原有 workspace_run_js／workspace_shell 的导出限制不变。

### AIcove酱从授权工作区安装

- 新工具 `aicove_package_install({workspace,path})`，仅 AIcove酱的工具组注册。path 相对授权工作区根目录，空字符串表示根目录；只接受真实目录或 `.zip`，不接受 URL、绝对路径、链接或虚拟挂载。
- `AssistantPackageTools` 使用现有 major 风险闸门，且 `requiresHumanApproval=true`；handler 再检查本次 ToolCallScope 的 humanApproved。审核模型不能替用户批准，脚本也不能间接申请确认。
- 调用时重读本机工作区与角色授权；安装走原有 `AicovePackagesNotifier.importDirectory/importZip`，使插件管理器刷新。返回 id、plugin_id、name、version、activation=roleExplicit、effective_from=next_run。
- 安装不写角色开启列表；新包须显式开启。替换同 id 包保留角色原有选择，下一次 run 使用新快照。

## 界面调用 API

- `ref.read(aicovePackagesProvider.notifier)`：`await ready` 后可读初始状态；`importDirectory(Directory)`、`importZip(List<int>)`、`importFiles(Map<String,List<int>>)` 返回 `Future<AicovePackage>`，写入成功后自动 reload；失败抛原格式／文件系统异常。
- `ref.watch(aicovePackagesProvider)`：已安装包列表。包含 id、pluginId、name、version、description、skills、scriptMain；skills 的 dir 为 null 表示旧单文件技能，空字符串表示包根目录。directory 是本机安装路径，files 是只读资源快照。
- 角色启用仍由现有角色编辑 API 写 `enabledPlugins` 中的 `pkg:<id>`；`null`（全部插件）不会自动包括包。
- 导入 API 由「扩展包」页调用；模型安装只走上述工具和审批链。

## 代价与边界

每次调用重新执行注册代码，换取失败恢复简单且状态隔离；顶层注册应轻量。包资源随本机安装保存，不进入同步，不增加数据库 schema。没有 npm／git 分发、MCP stdio／OAuth／resources、生命周期钩子、会话树、tool_search 或 SDK。

跨平台实现复用既有 QuickJS，但本批实际运行证据来自 Mac Flutter 测试和 DeepSeek Flash；手机、Windows 和 iOS 尚未实测，商店脚本政策仍沿 ADR0064 上架前确认。
