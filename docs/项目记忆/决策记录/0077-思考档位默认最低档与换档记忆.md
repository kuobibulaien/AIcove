# 思考档位默认「最低」档：上游拒绝就换档，成功后按渠道＋模型记住

修订 [ADR0003](0003-模型思考档位统一领域模型.md) 的「软件默认档位」一条，其余（canonical 档位、按模型查表、优先级）不变。

## 背景

ADR0003 的软件默认是「能关就关，不能关取最低档」，但「能不能关」全靠静态查表判断，查表跟不上上游：

- Gemini 2.5 Pro 和整个 Gemini 3 系列关不掉思考，每个型号的档位集合还各不相同（3.8 Flash 没有 minimal，3 Pro 只有 low 和 high）。旧表给 2.5 系列一律配了「关」，2.5 Pro 会收到 `thinkingBudget: 0` 并报错。
- 中转站、新模型、国产模型都会落到 `generic`，旧逻辑对 `generic` 默认什么参数都不发，角色扮演聊天白白花钱等思考。
- DeepSeek、GLM、Kimi 用 `thinking.type` 开关思考，千问用 `enable_thinking`，都不认 `reasoning_effort: none`。

用户裁决（2026-10-13）：角色扮演基本不需要思考，默认档改成「尽量低」：能关就关，关不掉就用 minimal 或 low，试出来之后记住。

## 决定

- **新增档位 `lowest`（界面显示「最低」），作为所有方案的软件默认**。它不对应某个固定的上游值，请求时展开成候选链：该模型查表档位里 ≤ low 的部分（关 → minimal → low）；三档都不支持就取最低可用档。末尾再补一次「不发思考参数」兜底。
  实现：[thinking_level.dart](../../../apps/aicove_flutter/lib/src/core/api/thinking/thinking_level.dart) `lowestCandidates`，[thinking_level_resolver.dart](../../../apps/aicove_flutter/lib/src/core/api/thinking/thinking_level_resolver.dart) `applyTo`
- **换档重试放在 `AgentApiClient` 的公共发送层**：聊天和语音通话共用，各 adapter 不感知。只有上游返回 400/422 才换下一档，鉴权、限流、网络这类错误不重试。流式请求收到非 2xx 时还没输出任何增量，重发不会出现重复文字。全部候选都失败时，抛出最后一次的原始错误。
  实现：[thinking_fallback.dart](../../../apps/aicove_flutter/lib/src/core/api/thinking/thinking_fallback.dart)
- **只有换档后成功才记住**，这样可以证明问题确实出在思考参数上，不会因为别的 400（比如上下文超长）把记忆写坏。记忆键是 modelFullId（`渠道id:模型id`），同一个模型走不同中转站分开记。
- **记忆只存本机 SharedPreferences**，不入库，不云同步。丢了最多重新试一轮。修改渠道地址或自定义参数、删除渠道时，清空该渠道的记忆；聊天页档位面板提供「重新检测最低档」入口。
- **查表补充**（以 2026-10-13 官方文档为准）：
  - Gemini 2.5 Pro 去掉「关」。
  - OpenAI 兼容接口新增两种方案：`thinkingToggle`（DeepSeek／GLM／Kimi／豆包／混元，关用 `thinking.type=disabled`，其他档写 `thinking.type=enabled` 加 `reasoning_effort`）和 `qwenToggle`（千问，`enable_thinking`）。
  - `generic` 增加 minimal 档。
  - 表依然会过时，但过时只会多试一两档，不会报错。

## 备选

1. 手动覆盖：在模型设置里让用户自己选方言、勾选档位。要做数据迁移，而且要求用户懂参数。自动试档已经覆盖了这部分需求，暂不做。
2. 持续补表，不做重试。新模型和中转站永远补不完，被否决。

## 代价

- 某个渠道＋模型第一次请求时，最多多发 3 个快速失败的请求（例如 `gpt-4o-mini`：none、minimal、low 都会被拒，最后不发参数才成功）。
- 有些中转站收到不认识的参数不报错，直接忽略。这种情况下程序以为已经关掉思考，模型其实还在思考，目前检测不到。
- 预设里的 `reasoning_effort` 优先级仍然高于软件默认，这是有意为之（用户 2026-10-13 裁决）：预设作者往往反复测过才定下思考强度，应当尊重。因此酒馆预设带了 `medium` 的话，「最低」档不会生效。
