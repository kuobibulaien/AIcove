## 决定

采用固定版本 QuickJS 原版 2026-06-04，通过 package build hooks + 薄 C/FFI 桥编译；不使用双引擎、不实现自制 JS 语法子集。SPreset 宿主独立实现已验证的配置契约，原始消息后处理、工具工厂/action、输出处理函数由引擎直接执行。

每次发送固定 JSON 配置、启用节点与宏值，经 PresetScriptSnapshot / PresetScriptRuntime 契约进入基础设施适配器。ChatSendApiRunner 持有本次生成 runtime，所有结束路径释放；工具循环共用工厂闭包状态，不跨会话共享 JS 状态。脚本只接收请求副本、工具参数和输出，不接触凭证、数据库或任意宿主对象。

发送顺序：原文派生历史→既有正则/世界书/宏组装→上下文管理器→JS 消息处理→Provider。超限重试重新处理 canonical 副本；不把伪角色 JSON 喂给上下文压缩器。返回顺序：工具传输解包→JS 输出预处理→原始回复保存；显示正则/插件继续只改变显示派生结果。只有本预设注册的工具可被消费为正文，其他工具保留原执行链。

正则的匹配/捕获改由相同 QuickJS 引擎执行，继续保留已有授权、作用阶段、深度、HTML 清理、失败保留原文与诊断机制。引擎中断和内存限额替代 Dart RegExp 的近似 JS 编译。

## 范围与代价

首批针对小猫 Reborn2.3、Meowssiah1.1 的默认上下文/输出机制；2026-09-29 的 Kemini B1 传输工具契约扩展见 [ADR0043](0043-预设传输工具与业务工具作用域.md)，本条安全边界继续有效。不运行 tavern_helper 浏览器加载器，不添加 DOM/网络。激活的 MessageInjections、MacroNest、re_split、parse_clewd、separate_chat_history、合并模式 stop strings，以及 merge_tools 以外的强制后处理尚不支持，遇到后阻止发送。无 UI/schema 迁移，不自动更改角色绑定/默认预设。

原生引擎增加跨平台编译和更新维护责任。64 MiB 堆、512 KiB 栈、每次执行 1 秒、最多 10,000 微任务、8 MiB 桥接输入输出；Dart isolate 是调度/状态隔离，不是原生漏洞的进程安全边界。

小猫原有工具参数流仍在参数完整后解包；Kemini 宿主传输协议已按 ADR0043 接入节流后的增量正文显示。发送前按既有 token 估算器重新核对 JS 变换后的消息和完整工具定义；本地或服务端超限均从原文派生副本恢复一次，仍超限则停止。估算不承诺等同供应商 tokenizer。
