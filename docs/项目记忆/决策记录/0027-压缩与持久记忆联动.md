# 压缩与持久记忆联动

日期：2026-09-13；状态：superseded（2026-09-23 由 [ADR0038](0038-记忆与上下文重构为短期长期两层.md) 取代，以下仅保留原始记录）。用户确认“同意”，授权沿 DeepSeek Harness 的预算策略改进压缩，并在压缩时更新联系人记忆文件。本决定替代 ADR0024 的触发、保留与记忆联动策略，保留其移除历史条数设置的决定。

## 决定

- 默认272000是窗口容量。有效窗口取用户设置与模型/预设容量的较小值；触发线取80%与窗口减输出预留的较小值，最近原文预算16%。当前用户输入与未闭合工具调用受保护；不可安全缩小时报错，不静默删除。
- 手动压缩继续“新话题”：原文尾巴不带入，保留内容摘要、采用最新角色格式。自动压缩继续当前任务，保留近期闭合步骤；按需最多再压缩一次。
- 一次整理返回结构化summary与独立memory_updates。摘要包含背景、偏好、进展、待办、细节，取消600字限制，上限8192估算tokens/32768 UTF-16字符。长期记忆只接收有来源的稳定事实/重要经历；不把临时任务、旧格式或助手猜测作为永久事实。
- 同次请求读取有界旧记忆用于语义去重/明确更正；代码校验owner、来源ID、修改目标与原版本。保护手写常驻正文、手写事件以及人工修改过的自动记录。手动修改预览摘要时，只保留正文仍明确存在于修改后摘要的记忆建议。
- 摘要与待写记忆增量在同一SQLite事务保存，然后写单角色MEMORY.md。文件失败不撤销已保存摘要、不阻止继续聊天，留队列下次补写；同一作业的文件成功标记避免DB完成标记失败后重复写。撤销手动压缩取消尚未写入的作业。
- 文件保留version1，新增可选appliedCompactions头字段与generatedKey/generatedDigest/memoryKind事件字段。写入前使用revision/文件锁复核。自动常驻事实与手写正文合计约2000tokens，超预算事实留作按需读取的事件；不无界注入。
- 每轮工具循环的模型请求前检查；服务器明确超限时裁剪大工具正文，再按需摘要，只重试当前模型请求一次，不重执行已成功工具。非超限错误保持既有处理。
- 压力下才处理超过8192 Unicode字符的工具正文，保留4096开头/1024结尾与原文引用；非文本和调用元信息保留。原文先存runtime_context_records；context_read绑定owner，分页或关键词读取。运行中压缩以闭合调用/结果组为单位，单一user轮次也能整理。

## 边界与代价

这是现有Flutter聊天链路的本地策略，不是移植完整DSH运行时，也不改变ADR0001的长期架构方向。总结模型沿现有配置选择；本地token为估算，多模态估值与供应商真实分词可能不同。模型记忆建议和摘要都有损，离线测试不证明语义正确率。

运行时原文是已发/待发消息的持久快照，不替代DB raw聊天真相源；保存前后验证角色和原聊天版本。完整“忘记”涉及原聊天、摘要、备份的墓碑协议仍未实现：本批保证同一作业重试和陈旧修改建议不复活已删事件，不声称永久禁止未来根据尚在的原聊天再次学到事实。新作业表不在本批新增云同步契约。

## 验收与回滚

以真实临时SQLite/MD、重启补写、文件/事务故障、人工编辑与删除、角色隔离、闭合工具组、超限只重试模型、压力裁剪及原文读取验证。界面仅调整窗口说明，宽窄源码预览；实际应用/模型验收范围见需求日志。

回滚本批源码时保留raw、MD与新增表；不能用不认识可选元数据的旧版本重写MD，以免丢掉去重/人工保护标记。回滚到ADR0024实现前需保留新表读取隔离，不清理用户数据。
