# 0055 · 插线直读诊断凭证

日期：2026-10-04。用户反馈电脑抓日志前还要在手机上点进「设置→调试中心→诊断导出与电脑读取」复制带凭证命令，要求插上线就能直接读。

决定：新增 Android 导出组件 `DiagnosticTokenProvider`（authority `${applicationId}.diagnostics`），读写均要求 `android.permission.DUMP`。Flutter 端诊断服务开启后经 `diagnostic_identity` 通道把当前凭证交给 native 内存；`collect_diagnostics.py` / `collect_storage_inventory.py` 未显式给凭证时执行 `adb shell content query --uri content://<包名>.diagnostics/token` 自取。显式 `--token`／`AICOVE_DIAGNOSTIC_TOKEN` 仍优先，诊断页面命令保留作旧版兼容。

边界：凭证只放进程内存，不落盘到外部存储；应用未运行时查询为空，脚本提示打开应用，不自动启动应用。HTTP 通道仍只监听 loopback、凭证校验不变。

备选：写到 `/sdcard/Android/data` 让 adb pull，会让同设备有存储权限的应用也能读到；`run-as` 只适用可调试构建；去掉凭证校验会让手机上任意应用访问 loopback 端口。DUMP 只有 adb shell／系统持有，普通应用无法获得，安全面与“已授权 ADB 即可读日志”一致。

代价：多一个导出组件；凭证对已授权 ADB 的电脑不再保密（原本它也能拿到页面命令）。

回滚：删 manifest 中 provider、`DiagnosticTokenProvider.kt`、`publishAccessToken` 分支与脚本 `resolve_token`，恢复复制命令流程。无数据迁移。
