# 0064 Dart 微内核 Agent 运行时与全插件化

- 状态：accepted（方向确认；实施方案与分批任务另立）
- 日期：2026-10-07
- 取代：ADR0001（官方 DSH 作为唯一 Agent 运行时，proposed，未实施）
- 关联：ADR0060（统一装配与调度分离，装配机器落在本 ADR 的内核）、ADR0042（QuickJS 预设运行时）、ADR0044（语义标签注册表）、ADR0017（插件上下文过滤）、ADR0038（记忆两层）

## 背景

ADR0001 自 2026-08-21 提出后停留在 proposed，实施计划 Phase 0 未开工，产品代码中无 DSH 相关实现。复核后其前提不成立：

- DSH 是 Node 程序。安卓需在 App 内携带 Termux 用户空间、Node、bash、proot，并把可执行文件伪装为 `jniLibs/*.so` 才能执行；上游为 `0.1.0-rc` 预览版，兼容补丁须随版本重做（`历史任务/08-21-dsh-android-agent-runtime/research/dshm-runtime-analysis.md`）。
- iOS 不允许普通 App 另起进程或使用 JIT，DSH 这种“独立 Node 进程”方案在 iOS 不可用；进程内、无 JIT 的嵌入式方案 nodejs-mobile 存在，但 2026-10-07 查得其最新发布为 Node 18.20.4（2024-10，Node 18 已停止维护），低于 DSH 要求的 Node ≥22。上述版本信息为一次性查询，未做持续跟踪。
- DSH 的主要增量是 bash、文件工作区等编码 Agent 能力，陪伴场景基本不需要。
- 外部参照：Eta（`Mangi-11/Eta`，Kotlin 安卓 App）以 pi 为参考、用宿主语言重写 Agent loop 并编译进 App，可在手机正常运行；其扩展只有 Skills 与远程 MCP，Node/Linux 仅作为可选终端工具按需安装。说明“宿主语言内核编译进 App”可行；它的扩展只到 Skills 与 MCP，DSH 式全插件化需要另行设计。

“全插件化”包含两个相互独立的维度，需分开论证：

1. **宿主设计**：服务可替换、贡献点、生命周期、作用域清理、权限。这与内核语言无关，Dart 内核同样可以做到。
2. **运行时加载第三方代码**：Flutter 正式包为 AOT 编译，不能加载新的 Dart 代码；应用商店对下载可执行代码另有政策限制（具体口径未逐条核实）。因此第三方代码需要一个解释执行的载体，本项目已有 QuickJS（ADR0042）。

DSH 借 Node 同时满足了两个维度；本 ADR 用 Dart 宿主满足第 1 维度，用 QuickJS 沙箱满足第 2 维度。

## 备选

1. 维持 ADR0001：App 内嵌 Node 运行 DSH。可直接用 Cordis 生态；安卓需携带完整 Linux 用户空间，iOS 不可用，双进程通信与保活成本高。
2. 用 nodejs-mobile 嵌入 pi。进程内运行，但 Node 版本停滞（见背景），iOS 只能无 JIT 运行，App 内仍是 Dart 与 Node 两套运行时。
3. 内核整体放进 QuickJS。模型请求、流式、数据库、界面都需穿过宿主桥，等于在沙箱里重造半个 Node。
4. **Dart 微内核＋QuickJS 插件沙箱**：内核编译进 App 覆盖全平台，运行时可加载代码只开放给沙箱内插件。

## 决定

采用 4。

### 内核（Dart，可信，尽量小）

- **Agent 循环**以 pi 为语义参照：准备本轮（压缩、插入排队指令）→ 流式请求模型 → 执行工具批次 → 结果写回 → 下一轮或结束；取消、暂停、追加指令为三种独立信号。目标态还包括“仅在明确的工具调用终止原因下执行工具”；第一批为等价抽取，维持现行行为（有工具调用即执行、快速生图并发），暂停不做，见实施方案。
- **插件宿主**：注册表、服务容器（插件可提供／依赖服务）、生命周期、作用域自动清理（插件停用或卸载时，其注册的工具、钩子、服务、界面贡献全部撤销）、权限闸门（检查插件声明的能力与用户开关）。第一批采用 run 快照语义：run 开始时固定插件集合，运行中停用不影响当前 run，从下一次 run 起撤销；运行中立即撤销为后续目标态。
- ADR0060 的“唯一装配机器”位于本内核；配方／调度分离及其验收项照常适用。
- 聊天上下文真相源不变：DB raw message 仍是唯一真相源，不引入 ADR0001 设想的与之平级的第二会话日志；工具调用记录的落库形态在实施方案中定，且不得违反此条；第一批沿用现状：循环内只在内存追加，run 成功返回后由上层构造 ToolBlock 落库，不提供逐轮持久化与崩溃恢复。

### 全插件化（三种能力）

| 能力 | 含义 | 例 |
|---|---|---|
| 服务 | 向容器提供可被替换、可被依赖的实现 | 模型渠道、上下文组装片段、记忆库、检索 |
| 贡献点 | 向系统登记新条目 | 工具、命令、语义标签（经 ADR0044 注册表）、提示词片段、设置页、界面卡片 |
| 钩子 | 在固定时机介入 | 请求前后、工具执行前后、消息落库前后 |

现有记忆、TTS、生图、联网搜索、表情包、时间感知、主动关怀、酒馆兼容等改为**内置插件**，与第三方插件走同一接口；现有 `features/plugins/domain/plugin.dart` 的生命周期、工具、命令、钩子并入新接口，迁移期保留适配器。

### 插件形态与平台

| 形态 | 载体 | Android | iOS | macOS / Windows |
|---|---|---|---|---|
| 内置插件 | Dart，随 App 编译 | ✓ | ✓ | ✓ |
| 声明式包 | JSON / Markdown（提示词、技能、预设、标签、世界书） | ✓ | ✓ | ✓ |
| 脚本插件 | JS，运行于 `packages/aicove_quickjs` 沙箱，限时限内存，只能调用宿主开放接口 | ✓ | ✓（上架审核口径未核实） | ✓ |
| 外部工具 | MCP 远程 HTTP | ✓ | ✓ | ✓ |
| 外部工具 | MCP 本地进程（stdio） | ✗ | ✗ | ✓ |

- App 内不使用 Node，也不内嵌 Linux 用户空间。
- **界面扩展只开放声明式描述**（卡片、表单、开关、聊天内组件），由宿主统一渲染；脚本插件不能直接构建 Flutter 组件或新增任意页面。
- **生态兼容只兼容 MCP**；不兼容 pi 扩展、Cordis 插件或 npm 包接口。

### 分批

1. 内核循环＋插件宿主，以假模型测试跑通；前台聊天在开关后接入，旧链路保留为回退路径。内核循环从现有 `ChatSendApiRunner`（含 part 文件 2283 行，前后台已共用）等价抽取为固定阶段管线，现有业务分支逐一落到阶段的默认实现，循环结束后的结果处理原样保留，不另起并行循环。实施方案：[Agent运行时第一批实施方案](../../../apps/aicove_flutter/docs/02_前后端分离与架构规范/Agent运行时第一批实施方案.md)。
2. 现有功能迁为内置插件，声明式包落地；收拢 ADR0060 所列后台自拼请求。
3. QuickJS 脚本插件与对外安装；接口稳定后再开放第三方。

## 验收门

1. 内核与插件宿主为独立纯 Dart 包（pubspec 不依赖 Flutter），可用假模型在 `dart test` 中跑通工具多轮、取消、追加指令。
2. 插件停用后，从下一次 run 起其全部注册项被撤销（当前 run 按快照不受影响），重新启用行为一致（测试断言）。
3. 脚本插件超时、JS 异常或越权调用只影响该插件，不中断 Agent 循环与 App；现有 `QuickJsSession` 在 JS 出错后会关闭整个会话，脚本插件需定义会话重建与状态丢失语义；必要的预设传输错误仍须阻止发送，不得为“继续循环”吞掉。
4. 迁移每一批后，现有聊天、主动关怀、记忆整理的离线测试保持通过；接入前台聊天前具备回退开关。
5. 不新增与 DB raw message 平级的上下文真相源。

## 代价

- 需长期维护 Agent 循环与各家模型协议细节。生产级实现规模在数千行：现有 runner 已有 2283 行，Eta 的 runtime 目录约 5.8k 行、模型协议层约 8k 行 Kotlin（2026-10-07 按提交 `9de3a3f` 以 `wc -l` 粗略统计）。
- 不能直接复用 npm、pi、Cordis 生态，只能借鉴设计。
- QuickJS 无 JIT，宿主桥接口设计与权限模型要自己承担；脚本插件性能低于原生。现有 `QuickJsSession` 用独立 isolate 隔离 JS 状态与界面调度，但不隔离原生内存故障（见 `packages/aicove_quickjs/lib/aicove_quickjs.dart` 注释），验收门 3 只覆盖 JS 层异常、超时与越权。
- iOS 下载脚本扩展功能的审核口径未核实，上架前需专项确认；自装与测试分发是否受限同样未核实。各平台原生构建 `aicove_quickjs` 的情况需在第三批前逐平台验证。
- 现有插件迁移涉及配置与预设绑定（ADR0008／0009／0054），需兼容读取旧数据。
