# 0075：内容承载面跟随全局高级材质

## 背景

ADR0036 让 `MoeContentSurface`（设置分组、角色编辑卡、设置根页卡片等）固定为不透明 `componentBackground`，不随全局材质变化。用户 2026-10-12 指出这不是本意：容器应像聊天「更多」面板按钮那样是更厚的模糊底，高级材质作为全局默认设置作用到容器上。

## 决定

`MoeContentSurface` 未传显式 `color` 时按全局材质渲染：

- 纯色档：保持不透明 `componentBackground`，不变。
- 模糊档：与悬浮按钮同一套厚模糊（`MoeFrostedMaterial.surfaceFilter` + `surfaceTint`），厚度与底色填充均跟随全局设置。
- 玻璃档：~~暂不进入液态分支；底色跟随全局填充，模糊固定为默认厚度~~。2026-10-12 修订（用户裁决试行，可随时回撤到 tag `material-split-ok-20261012`）：经 `MoeLiquidGlass` 以背景材质基线渲染液态玻璃，模糊度与底色填充跟随玻璃档自己的滑块；滚动中由 `MoeLiquidGlass` 自动改用 `GlassQuality.standard`（提交 a6876c4c0），此前的滚动错位被判断主要来自已移除的安卓拉伸回弹。2026-10-15 再修订（用户试行）：内容卡片在滚动中保留 `GlassQuality.premium`（`keepPremiumWhileScrolling`，Mac 滚动未见错位，手机发热未验）；悬浮表面仍降为 standard。边缘透镜宽度按短边自适应，见公共组件总览「液态玻璃边缘透镜」。
- 显式 `color` 保持纯填充不模糊；高对比或降低透明度时回退不透明实色。
- 内容面随列表滚动也保留背景滤镜，这是对 ADR0036／09-22「滚动表面不建背景滤镜」守卫的内容面例外；`MoeFloatingSurface` 的滚动守卫不变。
- 移除未被调用的 `blurSigma` 参数与 `kMaxContentSurfaceBlurSigma`。

ADR0036 中「内容面不跟随全局材质、默认不透明」一条由本 ADR 取代；内容面与悬浮面分离仍有效，「内容面不进入液态分支」已于 2026-10-12 修订撤销。

## 代价

- 每张内容卡片在非纯色档多一个随滚动重绘的 BackdropFilter；长设置页在手机上的光栅耗时尚未用 Profile 测量。
- 滚动列表里的悬浮小控件（搜索框、分段选择）仍按守卫保持实色，与周围已模糊的卡片可能不一致，后续按需调整。

## 验收门

- `moe_content_surface_test` 覆盖三档、浅深色、显式颜色与无障碍降级；相关页面测试已同步。
- 源码渲染预览已对比三档效果；运行中应用与手机实机、Profile 性能未验。

## 2026-10-12 修订代价

- 玻璃档下每张内容卡片都是一个液态着色器表面，长设置页的功耗与光栅耗时未用 Profile 测量；手机实机滚动、回弹与快速翻页时的对齐尚未验收。出现错位或发热时回撤本修订。
