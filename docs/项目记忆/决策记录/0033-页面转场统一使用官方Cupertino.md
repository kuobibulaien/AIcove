# 0033 页面转场统一使用官方 Cupertino

- 日期：2026-09-14
- 状态：accepted
- 用户决定：不再维护自写左移动画，全部换成 Flutter 官方 Cupertino，并修改规范。

## 决定与边界

采用 Flutter 官方 Cupertino 页面动画；替代 ADR0015 的连续中断视差及提前返回轨迹。移除自写动画实现、调参 helper 和中断事件注入，设置抽屉同样通过官方页面路由打开。工作区适配保留宽屏同级直接切换、背景策略及页面状态保护。

行为规范唯一权威为[界面布局说明「页面转场」](../../../apps/aicove_flutter/docs/界面布局说明.md#页面转场2026-09-14)。已有类名保留以减少调用处变更，类内不维护动画算法。

## 代价、验收与回滚

使用 SDK 原生转场以降低维护成本；不把已知快速进退问题默认视为用户接受，也不以官方实现替代实际验收。移除旧补丁会改变中断行为，这一差异及未解决问题必须明确交付。通过与官方实际坐标对照、声明式页面更新、边缘取消及窄宽工作区退栈验证；性能结论仍需实机 Profile。

本地回滚仅恢复本批文件快照，不重置其它工作树改动。没有数据、依赖、部署或账号变更。
