# 0045 辅助回答改为预设对话选项

日期：2026-09-29。状态：implemented，离线验证通过，真实预设回复与运行设备未验。取代 ADR0037。

## 需求与边界

用户要求把辅助回答合并进“对话选项”，不再使用独立指定的模型：部分酒馆预设会让模型在回复末尾输出 `<options>` 语义标签，界面像处理图片、文字一样直接匹配原文，复用原辅助回答的右下角气泡与弹出面板。气泡不常驻：模型回答完成后出现并自动展开，用户选中后消失；未选择则收拢为气泡，仍可点开。

## 决定

- 删除 ADR0037 的生成链路（SmartReplyPort/Adapter/Controller、后台 Agent 调用、短上下文裁剪）以及通用设置里的开关和模型选择；AppSettings 不再读写 `smart_reply_enabled`、`smart_reply_model`，旧键留在存储中无害，无 schema 迁移。
- 解析与显示派生放在 `features/dialogue_options/domain`，复用 ADR0044 的 `ContentTagScanner`（本地注册 `options`、`option` 两个规格），不另写配对正则：大小写不敏感，取最后一组；有 `<option>` 子元素时逐个取正文，否则按行切分并去掉序号、项目符号；去空、去重。
- raw 原文不改。聊天列表 `buildChatMessageListItems` 只对显示副本去掉 `<options>` 元素（含流式截断未闭合部分），只剩选项的回复段不生成空气泡；流式可见过滤器隐藏 `<options>`；会话列表预览同样去掉。请求副本保持原样，是否发给模型由预设自带的酒馆正则（常见“行动选项”promptOnly 脚本）决定。
- 选项来源为会话末尾连续助手段中最后一组（一轮回复可能被拆成文字、语音、图片多条消息）；生成中不显示。
- 气泡状态只在内存：`conversationSendingProvider` 由真转假后，若出现与发送开始时不同的新选项组，自动展开一次；关闭面板不算选用。选中项经按会话隔离的 `dialogueOptionPickProvider` 交给输入框，填入成功（已有草稿追加换行、编辑历史时拒绝）后才记为已选用并隐藏气泡；沿用“只填入草稿、不自动发送”（与 ADR0044 B3 一致）。
- UI 继续使用 MoeIconButton 气泡与 MoePopupMenu/MoePopupMenuItem，位置规则不变（与回到底部同尺寸、共用右下角 Row）。选项多为整句，竖向菜单新增可选 `maxWidth`：按最长标签（含字号缩放）自适应，不小于默认 180，上限 360 且不超出安全区，超长才换行；其他菜单不传该参数，仍固定 180。

## 代价

- 已选用状态不持久化，重启应用后最新一轮若仍以助手回复结尾，会重新显示收拢气泡（不会自动展开）。
- `options` 规格尚未注册到全局内容标签注册表；ADR0044 B3 做预设标签映射时再迁入，届时请求过滤与显示口径由注册表统一。
- 没有预设输出选项时不再提供任何辅助候选，这是本次需求的明确取舍。

## 验证与回滚

解析、显示派生、列表去空气泡、会话末尾选项定位、流式隐藏且 raw 保留、自动展开一次、关闭后收拢、选用后消失、旧选项不重复展开、输入框按会话填入并标记选用均有专项测试。源码渲染预览在 `scratch/dialogue-options/`（360/1000，收拢、展开、与回到底部并排）。聊天与设置目录回归中 55 项失败与撤除本改动的基线逐条一致，属工作区既有问题。

回滚：恢复 ADR0037 相关文件（git 历史中可取回；删除前未提交的诊断与空回复改动备份为会话临时补丁），撤销本次列表、流式、输入框与预览接入行即可，不涉及用户数据。
