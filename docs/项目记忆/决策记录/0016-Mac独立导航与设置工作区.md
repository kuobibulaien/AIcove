# 0016 Mac独立导航与设置工作区

日期：2026-09-11
状态：reverted（用户否决，2026-09-11已回退代码和安装包）

用户要求先做一版Mac导航与设置小重构，聊天界面不动。

Mac根路由使用MacWorkspacePage，其他平台仍采用原来的MainPage/SplitChatPage。DesktopWorkspace提供固定分类侧栏，窄窗口收成图标导航；消息区域直接复用ChatPage，设置和角色/个人页面使用惰性创建、独立保留的Navigator。切换分类保留未提交表单和页面栈，不销毁聊天。

DesktopSettingsScope只作用于非聊天内容区，通过局部Theme和MoeAppBar分支提供中性底色、紧凑标题与内容宽度上限，复用原有页面和设置持久化。聊天页面与全局主题设置值均不改。背景色选择在此作用域内用可换行选项，解决窄窗口溢出。

验收：400/760/1200宽、1.2/1.8字号、深浅色、编辑草稿切换保留、嵌套返回、设置搜索和Command快捷键；实际安装效果见需求日志。

回滚：恢复本轮修改前的app.dart/MoeAppBar/UiSettingsPage（scratch/mac-layout-v1/before），去掉MacWorkspacePage与DesktopWorkspace入口即可；当前旧安装包在scratch/mac-layout-v1/AIcove-before.app。不能用git reset覆盖既有并行改动。
