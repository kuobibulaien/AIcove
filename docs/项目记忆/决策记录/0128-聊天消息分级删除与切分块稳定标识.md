# 0128 聊天消息分级删除与切分块稳定标识

- 状态：生效（离线前后端与界面渲染预览通过，实机与双端同步未验）
- 日期：2026-11-14

## 背景

排查聊天消息删除机制时发现前后三层存在多处语义错乱与交互断层：

1. **展示切分段合成标识断层**：`ChatMessageList` 将单条投影消息拆成多段气泡／折叠块／媒体块时使用 `${message.id}_chunk_$i` 临时 ID，多选勾选记录的是 `_chunk_` ID，而存储层 `ConversationShortWindowStore.hideMessages` 只认识数据库 `rawMessageId` 或投影 `message.id`，导致多选删除切分气泡、文档段落和折叠块全部静默失效；开关「显示思考／工具调用」还会令下标漂移。
2. **真删与本机隐藏错位**：单条右键／长按删除统一调 `softDeleteMessages`，传投影子块 ID 时误入本机 `SharedPreferences` 隐藏分支却把会话列表摘要强改成上一条甚至清空；短窗口按条数截断最老 `rawMessage` 的兄弟投影时，单删可见子块可能误判成整条消息已删空而误触发数据库软删。
3. **文档模式与折叠组件缺口**：文档模式整轮回复只有末尾一条操作栏且无「删除」按钮，无法一键删整轮回复；`MoeFoldSection`／`MoeCollapsibleBubble` 不响应桌面右键、文档模式窄标题右侧空白点按无菜单、展开后不可选字、菜单误露出无效的「编辑／引用／重新生成」；宽屏（1000px）文档模式多选勾选框贴死屏幕最左缘而非居中阅读栏；相邻纯工具消息合并折叠条需连删 N 次；独立运行状态行（已停止／报错／截断）与非发送态卡死的图片占位块成为删不掉的钉子户。

## 决定

1. **统一两级删除语义（`ChatTimelineDeletePlan`）**：
   - **整条／整轮真删（写入 SQLite `deleted_at` + 30 天 `purge_at`）**：删除用户整条消息、单气泡未切分回复、文档模式底部操作栏「删除」整轮回复、独立无正文的 `ChatRunStatusItem`，或通过单删／多选把某条 `rawMessage` 下的**全部主要内容块（正文／图片／音频／代码块／记录卡片）**删光时，统一走 `softDeleteMessages` 软删原消息，从 AI 上下文彻底移除、参与局域网与云端同步、安全左移被删的 `contextStartMessageId`，并从窗口外兜底回填会话列表 `last_message`，同时清理该会话残留的本机隐藏键。
   - **局部切分块／折叠块本机隐藏（`aicove.frontend_hidden.v1.$convId`）**：仅删除单个思考块、工具折叠条、预设语义折叠段、图文混排里的单张媒体，或多段气泡中的某几段而同源消息仍有剩余主要内容时，只写入本机 `'projected'`／`'pieces'` 隐藏集合，保留其余展示内容与 AI 上下文，且绝不篡改跨端同步的 `conversations.last_message`。多轮工具调用中的纯工具原消息单删折叠条时只做本机隐藏，仅在底部整轮「删除」时随整轮软删。
2. **确定性切分块标识（`__piece_`）与合并折叠条联动**：
   - 以 `buildChatMessagePieceId(messageId, kind, kindIndex)`（`${messageId}__piece_${kind}_${kindIndex}`）替代 `_chunk_`，按块语义类别独立编号，开闭思考或工具开关不影响正文与媒体块 ID。
   - 连续纯工具消息合并而成的单条工具折叠项携带 `mergedMessageIds`，删除或多选时一次性隐藏所涉全部工具投影。
3. **文档模式、折叠块与钉子户交互补齐**：
   - 文档模式 `ChatReplyActionBar` 增加「删除」按钮，按整轮回复锚点（含前置多轮工具消息及尾部独立状态行）执行整轮真删；确认弹窗按「整条真删／局部移除／混合多选」给出诚实直白的日常提示。
   - 折叠组件补齐桌面右键菜单、文档模式整行右键／长按热区（左键仅点标题与箭头切换展开）、`MoeFoldSection` 展开正文 `SelectionArea` 选字，菜单收敛为干净的「多选／复制／删除」。
   - 文档模式多选勾选框对齐居中阅读栏左缘（`selectionGutter = 50`）并设 `38px` 最小行高防挤压；独立 `ChatRunStatusItem` 与非发送态卡死 `pending` 图片占位开放右键／长按删除；`voice_call_live_*` 实时字幕不挂多选框；聊天记录与通话记录卡片隐藏无效的「编辑」入口。
4. **短窗口最老消息兄弟投影完整性**：
   - `ConversationShortWindowStore` 按条数裁切窗口头部时，保证最老一条保留 `rawMessage` 的全部兄弟投影完整留在窗口内，防止局部删除因看不见同源兄弟块而误升格为数据库真删。
