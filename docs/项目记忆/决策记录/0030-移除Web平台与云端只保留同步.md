# ADR0030：移除 Web 平台，云端只保留云同步

用户在审阅根 README 时裁决：云端“只是做了个云同步，还是半成品，剩下的都不需要”；Web 端说明与代码一并删除，一切以新版为主。本记录把 2026-07-20 的“不兼容 Web”裁决落实为代码删除，并收窄云端职责。

## 背景

- 根 README 原本一边写“云端默认忽略”，一边整节介绍云端 Agent Context 管理面板、主动关怀云触发器等能力，与实际开发重点矛盾。
- `kIsWeb` 分支散落在 10 个 Dart 文件，`flutter_web_plugins` 只为 Hash URL 策略引入，`web/` 目录与云端 `/app` 静态挂载仅服务已放弃的 Web 构建。

## 决定

1. 删除 `apps/aicove_flutter/web/`、所有 `kIsWeb` 判断（`PlatformUtils.isWeb / supportsLocalNotifications / supportsFileSystem` 一并删除，无调用方）、`flutter_web_plugins` 依赖、`resolvedApiBase()` 的 Web 分支、云端 `main.py` 对 `build/web` 的 `/app` 挂载及说明。
2. 目标平台：macOS（基准）、Android（真机验收）；iOS、Windows、Linux 工程目录保留但不做验收要求。
3. 云端职责只剩同步及必要账号能力（客户端已接入，正在测试）。本条原“保留其他接口代码”决定已被 ADR0031 取代，旧服务现已删除。
4. 根 README 三层定位改为：前端 `lib/src/ui/`、本地后端 `lib/src/features/` + `lib/src/core/`（Flutter 进程内 Dart 代码，方法调用不走 HTTP）、云端仅同步。“后端”一词在全项目文档中只指本地后端。

## 代价与回滚

- 若日后需要 Web，需重新 `flutter create . --platforms web`、恢复 `flutter_web_plugins` 与 Hash URL 策略，并逐处补回平台分支；本记录列出的删除点即恢复清单。
- 云端非同步接口已按 ADR0031 删除，恢复代码须使用清理前副本或历史版本。
