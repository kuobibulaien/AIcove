# 0094：AIcove酱的快捷面板是助手会话专属的 aicove-ui 动作组件

关联：ADR0091（交互组件，本 ADR 落地其决定 5 的 U3）、ADR0073／0093（风险档、审核、撤销与全权限）、ADR0045（追问只填草稿）。方案：[快捷面板方案](../../../apps/aicove_flutter/docs/04_功能模块规范/AIcove助手/快捷面板方案.md)。

## 背景

用户 2026-10-19 要求给内置设置写「快捷面板」：AIcove酱回复时放出角色列表、绘图预设列表等，用户在面板里点选要改哪个，不必跳页面找。现有两套机制：输入框上方的临时卡片（`assistant_cards`，不在对话流里，翻历史看不到）和回复正文里的 `aicove-ui` 代码块（ADR0091，U1 只有展示和本地交互）。

## 决定

1. **沿用 aicove-ui 代码块，新增「动作组件」**：`roles`、`drawing-presets`、`voice-presets`、`settings`、`providers`。模型只写意图（组件名、要突出的角色、要列的设置项），列表内容由 App 渲染时从本机实时读取，不由模型抄写，所以永远是当前数据、模型也写不错 id。临时卡片机制不变，继续只放 Key 输入、选文件这类必须用户亲手的事。
2. **只在助手会话渲染**：动作组件的渲染器通过 `MoeUiBlockScope.actions` 注入，只有 AIcove酱的聊天列表提供；其他会话、导出和预览里显示「只在 AIcove酱的聊天里能用」，不执行任何东西。提示词也只进助手会话。
3. **用户亲手点＝授权**（ADR0091 决定 5 原定）：面板里的直接修改调用同名助手工具的处理函数，因此与模型调用走同一份风险档、校验、撤销账本和撤销条；只读、可撤销、需审核档直接执行（审核模型是防模型越权的，用户自己点不需要它），重大档和「修改前每次问我」开着时弹确认框。面板不新增任何写路径。
4. **选中即回传**：用户在面板里选了谁、做了什么（最近 5 条）按 ADR0091 的块状态存本机，下一轮经 `<ui_state>` 告诉模型；「交给 AIcove酱」按钮只把一句话填进输入框（ADR0045），不替用户发送。
5. **补一个工具**：角色绑定的绘图预设此前没有助手工具（藏在人设编码里），新增 `aicove_set_role_drawing_preset`（可撤销，撤销还原含旧版工具／画师串绑定在内的整组绑定），面板和模型共用。

## 代价

- 面板列表在渲染时读本机数据，翻到很久以前的回复，看到的是现在的列表，不是当时的。
- 面板直接修改不经审核模型；误点靠撤销条兜底，重大档仍弹框。
- 面板执行的修改写进撤销账本的工具名与模型调用相同，撤销条不区分是谁改的。
- 第一批不做：音色预设设为默认（没有对应工具）、面板内直接编辑预设字段（仍打开编辑页）、插件开关面板。
