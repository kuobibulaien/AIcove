# 0113 桌面 Agent 文件工具直连本机目录

- 状态：accepted，2026-10-24 用户批准方案并要求纯工具实现；验证记录见 `scratch/native-workspace/`。
- 关联：0087、0098、0105、0108、0111。部分取代 0087 的不访问外部目录决定；内部空间存储及撤销协议不变。

## 使用方式

桌面工具模式角色可以直接调用 `read({path:"/绝对路径"})`，或用现有 `workspace_open({path:"~/项目"})` 切换工作位置；`workspace_open({id:"本机目录路径"})` 也接受目录。相对路径按当前位置解释；`path` 参数总是目录，只有 `id` 优先匹配内部空间 ID。`workspace_open({id:"aicove"})` 切回默认空间。不增加工具、不改聊天界面。

## 文件访问与权限

- `WorkspaceFileAccess` 隔离内部空间与本机文件后端。内部空间继续走 `WorkspaceStore` 的授权、索引、修改历史、配额及宿主目录写保护；本机文件直接落盘，无内部撤销、索引或同步。原调用方默认关闭本机能力，只有桌面工具模式聊天入口显式启用，聊天模式及原有杂活 Agent 不扩权。
- 本机支持绝对／相对／`~` 路径及符号链接，遵循当前操作系统用户权限，不提权。先解析系统符号链接，再解释其后的 `..`；指向内部空间的绝对路径与别名转回受管后端。索引及历史等宿主文件不开放通用写入。
- 本机文件无内部空间的 1 MiB 写入／编辑及 32 MiB 读取限制。文本读取分页（最多 2000 行／50 KiB），内容搜索流式处理；编辑整文件处理，巨大文件仍有内存开销。内部空间写入／编辑限制不变，内容搜索不再静默跳过 1 MiB 以上文本，超过 32 MiB 的内部文件报告跳过原因。
- 本机目录搜索不依赖索引；默认跳过 `.git/node_modules/.dart_tool/build`，`include_ignored:true` 可包含，不解析 `.gitignore`。目录损坏链接、搜索不可读文件与截断有结果说明。只移动／删除文件，不递归删目录，不暗中跨后端复制后删除。
- 本机写入共用按真实路径串行的队列和 revision 检查，同目录临时文件替换，保留 Unix 权限、BOM 和换行。取消前未提交的写入不落正式文件。外部程序不受本进程队列约束，检查与落盘间仍存在系统路径操作的竞态窗口。

## 当前目录与执行

- 每个聊天通过本机 SharedPreferences 独立记住本机目录，沿用内部空间选择键；不改 schema、不把本机路径同步到其他设备。
- 目录删除或不能遍历时自动切回默认 `aicove`，清理本机目录选择，并在本次系统工作区上下文说明「上次的本机目录 xxx 已不可用，已切回默认空间」。旧内部空间选择按原规则恢复。
- bash 从同一当前目录启动，保留审批、取消、超时与进程树清理。本机模式不扫描或锁住外部项目、不还原项目 `.aicove/`；命令中的 `cd` 不跨调用保存。
- codemode 工具调用和 `ws.readBytes/writeBytes` 使用同一文件后端；字节单次 4 MiB 限制保留，本机文件无 32 MiB 总量限制。宿主截断输出、图片及脚本状态仍存 AIcove 管理目录，返回可读的明确路径，不往用户项目创建宿主缓存。

## 本机 HTML 预览

`workspace_run` 复用现有 loopback 服务、默认浏览器、CSP、AI 接口和存档协议。本机相对 HTML 以当前目录为根；目标在当前位置外时以目标 HTML 父目录为根。禁止 HTTP 路径穿越和符号链接越界，禁止暴露内部空间管理目录及其上级目录；不提供目录列表。服务缓存不写项目，网页主动保存的 `<页面名>.save.json` 仍写页面同目录，不参与内部撤销。文件工具和网页存档共用本机提交队列及版本检查。
