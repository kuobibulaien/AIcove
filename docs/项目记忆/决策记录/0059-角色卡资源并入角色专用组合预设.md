# 0059 角色卡资源并入角色专用组合预设

- 状态：accepted
- 日期：2026-10-04

## 背景

酒馆角色卡除人设外常带 `alternate_greetings`、`extensions.regex_scripts`、`character_book` 与酒馆助手脚本。依赖变量系统的卡（如开场白末尾含 `<UpdateVariable>` 变量块和状态栏占位）靠卡内正则在显示和发给模型时隐藏这些内容。此前导入只取人设，开场白被拼进人设，正则与世界书全部丢弃，变量块原样显示并发给模型。

## 备选

1. 卡内正则与世界书作为「角色作用域」资源挂在角色上（贴近 SillyTavern scoped regex）：需新持久化归属、合并优先级、授权、显示解析与同步契约，改动 ADR0010 边界。
2. 直接并入角色绑定的预设：会污染其他也绑定该预设的角色。
3. 复制一份角色专用组合预设并写入卡内资源，角色改绑副本（选用）。
4. 副本只引用底预设、运行时叠加：引用失效、更新传播和跨端一致性更复杂。

## 决定

- 开场白：解析主开场白与 `alternate_greetings`，多套时创建前弹窗选择；开场白不进人设，创建角色时写成会话第一条 assistant raw 消息（ID 固定为 `msg_greeting_<会话ID>`，重试覆盖同一条）。原文保留宏替换后的全文供请求装配，显示副本按角色最终有效预设的已授权显示正则生成，与普通回复同构写 `rawPayload`；全部被隐藏时不回露原文。开场白不能重新生成（列表提示）。
- 卡含正则或世界书时，点「创建角色」建立「<角色名> 专用」组合：底预设按显式绑定→默认预设→内置「基础上下文」模板；显式绑定缺失报错不回退。新 ID 独立生成，完整复制 `rawPreset` 与 `compatibilityData`，追加卡内正则（与底预设同 ID 或无效的跳过并提示）和世界书，一次写出后改绑角色。底预设不被修改。
- 授权作用于整套副本：卡含正则时副本直接允许运行（10-04 用户裁决：不弹确认，先导入再由用户在预设「正则」里逐条管理），底预设已有正则在副本里也随之运行；卡只有世界书时沿用底预设授权，基础模板默认不授权。
- 不执行酒馆助手脚本（MVU 变量、状态栏），只提示；输出网页的美化正则按 ADR0046（10-04 修订）处理：只把占位符换成网页的规则显示时替换成空，其余交给标签组件。

## 代价

- 底预设原本未允许的正则在副本里会一起运行，需要时到预设里关闭；副本不随底预设后续更新；同一底预设被多张卡复制会产生多份文件。
- 变量块只是被隐藏，变量系统不运行；依赖变量的世界书条件未必生效。
- 主开场白只是占位符（如「【开场】」）时，选中后聊天里不显示任何内容；变量系统与 EJS 模板世界书条目待 MVU 讨论。
- 回滚：撤销提交；已建立的专用预设是普通预设文件，可在插件页删除，角色改绑原预设即可。
