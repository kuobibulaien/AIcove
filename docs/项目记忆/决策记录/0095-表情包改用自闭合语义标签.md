# 0095：表情包改用自闭合语义标签

关联：ADR0078（表情包库，本 ADR 取代其中「AI 侧仍用 `[标签]`」一条）、ADR0044（内容扩展统一语义标签注册表）、ADR0048（预设标签按外层目标识别）。

## 背景

表情包的 AI 语法一直是裸方括号 `[晚安]`，由表情包插件用正则抽取。它没有登记到语义标签注册表，语音、落库拆分、流式显示各走各的口径；方括号在语音链路里不被当作标签处理，用户反馈会影响语音生成。ADR0078 把它列为「沿用旧链路」的代价，现在要一并清掉。

用户 2026-10-21 确认：语法用自闭合属性；自动打标以后用「看图＋文件名」的视觉模型做（本 ADR 不涉及）。

## 决定

1. 语法为 `<sticker tag="标签"/>`，自闭合，标签名固定为 `sticker`，属性 `tag` 只认标签文字。
2. 标签由 `StickerTag`（`features/stickers/sticker_tag.dart`）声明为语义标签，`display` 为 `hidden`，归属方 `sticker`，注册进第一方提供方列表；识别只经唯一扫描器，不另写正则。
3. 只认顶层表情标签：语音、图片等标签里面的表情标签删掉、不产生事件。插件（`convertStickerTags`）与消息切段（`ChatMessageProcessor`）口径一致，表情事件按标签分队列，与正文中出现顺序一一对应。
   - 显示副本统一经 `StickerTag.removeFrom` 清理：流式可见输出、活跃／已封口文本、正文兜底与旧投影缓存都不保留表情标签；缓存只清显示，不回写 raw、不重放事件，标签清空后不生成空气泡。
4. 语音正文与语音清理（`TtsParser`）去掉表情标签，成对写法只留正文。
5. 默认提示词改写为新语法（`assets/prompt_defaults.json` → 经 `prompt_defaults_codegen.py` 生成）。配置里保存的仍是旧出厂文案时自动换成新默认；用户改过的模板不动，由用户自己更新。
6. 标签清洗去掉会破坏语法的 `<>"[]` 字符。
7. 库清单（`library.json`）本批不改格式，不做迁移。

## 代价

- 用户自己改过、仍含方括号的提示词模板不会自动更新，需要手动改。
- 旧历史消息里的 `[标签]` 不会被回溯处理，保持原样显示。
- 成对写法 `<sticker tag="x">正文</sticker>` 会保留正文，但提示词明确要求用自闭合，这是兜底而非推荐写法。

## 回滚

撤回 `sticker_tag.dart` 与 `plugin_content_tags.dart`、`tts_parser.dart`、`chat_message_processor.dart` 中的表情分支，把 `prompt_defaults.json` 的模板改回旧文案后重新生成。库清单格式未变，回滚不涉及数据。
