# ADR0052：显示正则结果与原文独立保存

- 日期：2026-10-02
- 状态：accepted
- 范围：首个公开测试版的聊天显示修复，不改变数据库 schema。

## 背景

原始回复用于模型上下文；显示正则后的回复用于界面。只保存插件消费标签后的 processedText，冷加载时重新从 rawReplyText 拆多模态，会绕过显示正则；将空 processedText 当成缺失也会重新显示被删除的原文。

## 备选

1. 从原文重做显示正则：需要持久化当轮完整预设和授权快照，且规则变化会改变旧消息。
2. 保存当轮显示正则结果：复用已有 ApiCallResult.replyText，保留插件尚未消费的媒体标签。

## 决定

采用方案 2。raw_payload v1 增加可选 displayReplyText，保存显示正则后的、插件消费标签前的文本。即时显示与冷加载多模态拆分都使用它；显式空字符串表示本轮没有可显示正文，不得回退原文。旧 payload 有 processedText 时将它视为已处理结果，字段完全缺失时保留旧原文兼容行为。rawReplyText 和数据库 canonical 内容继续服务模型请求，投影不得回写原文。

## 代价与回滚

每轮额外保存一份显示文本。旧包没有标签前的显示快照，无法完整恢复原来的媒体插入位置。回滚代码不删原文或 payload，新增字段可被旧版本忽略；回滚后可能重新出现显示正则绕过。

## 验证

显示正则清空、含 TTS 的过滤回复、旧 payload 缺失与空处理字段，以及原文保真均由自动化测试覆盖；不宣称真实设备播放已验收。
