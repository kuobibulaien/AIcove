# ADR0023：移除多模态辅助模型

- 日期：2026-09-13
- 状态：accepted（用户明确要求）

## 背景与决定

用户要求删除整块多模态辅助模型及相关代码，不再维护独立的图片解释、音频转写和视频摘要模型。

移除设置界面、AppSettings 字段和写入方法、辅助服务及专用提示词。旧配置键不再消费，无需数据库迁移，不改历史消息。聊天模型轮询与图片能力检查保留；非视觉模型只能复用已有图片提示词，不再发起额外模型请求。

音频和视频原始附件进入当前聊天模型的请求：Gemini 适配器转为 inlineData；OpenAI 兼容接口使用 file 内容块，具体格式支持由目标接口决定；当前 Claude 适配器明确拒绝音视频文件，避免静默丢弃。附件读取检查实际大小上限。

## 备选与代价

仅隐藏设置会保留隐式辅助请求，因此未采用。现在媒体理解依赖当前聊天模型及接口的原生能力，不支持时需切换模型，不再提供辅助转写兜底。

## 回滚与验证

可恢复本批移除的配置消费和辅助服务代码，历史数据未删除。离线回归覆盖配置加载、图片发送链、媒体字节到 Gemini 请求的转换、Claude 明确报错、上传大小限制与默认模型页宽窄布局。真实供应商付费请求未执行；Mac 已有待确认重载阻止本次同步，实机验收未完成。
