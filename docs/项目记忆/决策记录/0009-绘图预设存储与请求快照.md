# 0009：绘图预设独立存储与请求快照

## 背景与确认

用户要求角色绑定包含渠道、模型、风格、参考参数、辅助提示词的一个绘图预设，并回复「同意」确认包含旧配置迁移的实现方案。本决定落地 ADR 0008 的绘图配置包部分，不涉及酒馆预设格式。

## 备选

- 只扩展全局 ImageConfig、调用前临时切全局选中项：会导致并发角色及延迟生图串配置，不采用。
- 增加数据库表并批量重写所有角色：迁移和回滚范围过大，本次不采用。
- 独立版本目录、角色稳定 ID 引用、请求副本：采用，复用现有 ImageConfig 值对象和图片 Adapter。

## 决定

1. `aicove.plugins.image.drawing_presets.v1` 保存目录和默认引用，旧配置键不变。通过 DrawingPresetStore 读写，串行提交且保存成功后才发布内存状态。
2. 默认旧配置和单项收藏转换为完整预设；旧角色复合绑定按确定性 ID 渐进转换，不对未访问角色做批量写入。源引用缺失明确提示，不猜风格或渠道。
3. 新角色绑定存入 PersonaPromptCodec 的内部 ID 标记，人设正文解析时剥离；数据库版本不变。
4. prepare 阶段从请求角色解析 ImageConfig 副本，工具闭包与 ApiConfig 同源；快速模式事件携带不含凭据的副本，两条延迟交付路径均传递，不读取活动页面。
5. 模型只能覆盖支持的绘图参数，不能换渠道/模型，也不反写预设。辅助提示词默认高级折叠；旧画师编辑入口退出主流程但源码保留用于回滚。

## 代价与边界

保存模型暂复用 ImageConfig，因此序列化仍带已收成单值的旧列表字段；没有再造平行参数体系。旧键用于回退，不同步新编辑。旧版不理解新角色 ID 标记，回滚新绑定须显式映射或重新选择，不能声称全部编辑可自动回退。

本批不提供删除入口，不扩展正在单独止损的备份格式；跨设备预设定义与渠道映射仍未实现。真实供应商计费请求未执行，验证采用回环地址模拟 HTTP。

## 验收

新旧绑定解析、保存/重启/并发与故障、双角色请求、副本不受默认修改影响、工具及快速模式参数、NovelAI 权重文本与渠道归属冲突、角色编辑保存、窄宽屏和大字号均有测试。工程执行 flutter pub get、范围 analyze、Android flutter run --no-resident；全仓并行改造的失败单列，不冒充全绿。
