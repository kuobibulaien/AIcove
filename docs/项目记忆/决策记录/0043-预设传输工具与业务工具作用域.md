# 0043 预设传输工具与业务工具作用域

## 背景与授权

用户授权 B1 为本批唯一交付：Kemini Dramatron v3.1 的请求变换与回复解包。B2 显示顺序／历史重算后续实施；配置面板、脚本状态持久化与事件桥接另行立项。本决定扩展 ADR0042 的请求契约，保留其运行与安全边界。

Kemini 原导出 `function_calling=false`，SPreset 的 ToolBindings 为空，消息／输出回调关闭；伴生脚本却默认启用临时函数承载正文。将其全部视为业务工具会错误禁用，将整个浏览器脚本执行又会超出已有边界。

## 备选与探针结论

1. 按哈希定位原请求／回复函数，在 QuickJS 中执行原函数。
2. 在已有 QuickJS 宿主实现通用正文传输协议，仅读取已审核 Kemini 的配置。

采用 **方案 2**。抽取原 `prepareRequest` 与邻接函数后，离线探针报 `ReferenceError: 'crypto' is not defined`；回复部分分散于 IncrementalContentDecoder、SseContentRewriter、JsonArrayStreamSplitter、Response／ReadableStream／TextDecoder 包装和 eventLog。完整接入需要依赖追踪、浏览器响应包装或改写原函数；不符合“稳定纯函数提取”的收益预期。已有 Provider adapter 已负责 HTTP／SSE 解码，在统一调用结果上实现协议更容易保持原业务工具链。

探针：`.codex-temp/kemini-b1-2026-09-29/extraction-probe.json`。不执行整段 tavern_helper，不提供 window、DOM、网络或浏览器 shim，也不创建第三方 JS 通用宿主 API。

## 决定

### 识别与配置（2026-09-29 原位修订）

协议及控制提示词均为宿主自有实现，不执行导入的伴生脚本，因此取消原版本哈希门槛。v3.1 为测试来源，不是可发送版本白名单。

- 仅通过脚本 ID `2c7d747c-22d4-4e8b-95f8-5620b552fe6e` 或内容标记 `__keminiAntiTruncation__`／`keminiCompanion` 识别，不使用文件名。匹配多份时取第一份已启用脚本；全未启用则普通发送。
- 读取导出的 `data.keminiCompanion.antiTruncationEnabled`，缺省为开、显式 false 为关。仅读导出快照，不实现面板身份迁移、变量写入或事件状态。
- 锚点仅读字面量，找不到时记录 `transport_anchor_missing`，使用追加控制提示词兜底，继续注册传输工具。脚本内容变化不会阻止发送。
- 未识别记录 `transport_unrecognized`；配置类型错误或读取异常记录 `transport_config_read_failed`。两者均不注入传输能力，正常发送；工具重名等真实冲突仍在发送前拒绝。
- 原始 JSON SHA-256 `3d394088a2b4c19a6d819a9cfba7bfacb372296a626c1192eaa6cab62c383968` 仅用于标记离线测试来源，不参与运行校验。
- 协议实现为宿主自有 `assets/preset_runtime/transport.js`，不 eval 伴生脚本。随机工具名在 Dart 端生成后作为值传入，不给 JS 暴露随机数宿主或其它 I/O。

### 工具分类与权限

`PresetScriptRuntime` 增加 `businessTools`、`transportTools`、`toolChoice`、`diagnostics`，`tools` 为出站声明的并集。

- **业务工具**：现有插件与 SPreset 工厂沿用原 `supportsToolCalling` 权限、action 和工具循环。小猫既有 ToolBindings／consumeToolCalls 行为不改成新的权限豁免。
- **B1 传输工具**：由宿主 JS 根据识别后的配置注册，只有字符串 `content` 参数，没有业务 action。不受预设 `function_calling=false` 约束，仍受模型 tools 能力及模型禁用工具设置约束。
- 模型无法使用 tools：不注册传输工具、不加控制提示词或 tool choice，正常发送，记录 `transport_skipped_model_without_tools`。显式关闭记录 `transport_disabled`，启用记录 `transport_enabled`。
- 只有本次 runtime 注册的完整工具名能作为正文消费；不能按 `emit_complete_response_` 前缀吞掉未知工具。工具重名在发送前拒绝。

### 作用域与调用顺序

`DB raw 派生历史 → 既有组装／上下文管理 → SPreset 消息处理 → 传输请求副本 → Provider adapter`。

- 每次发送持有独立 runtime，工具循环共用；finally 释放。重试／压缩后始终从 canonical 副本重新派生，不累积控制提示词。
- 控制提示词插入首个含 `<format>` 的消息之前；缺失锚点时追加，尾消息是 assistant 则使用 user，否则 system。
- `ProviderChatRequestOptions.toolChoice` 是请求级值。OpenAI 映射 `tool_choice=auto`；Gemini 映射 `toolConfig.functionCallingConfig.mode=AUTO`。不写入持久化渠道配置。
- 控制提示词与传输 schema 纳入现有变换后预算检查；不回写 DB、预设原件或 canonical 历史。

`Provider 解码／流聚合 → 传输正文选择 → SPreset 输出处理 → 原回复保存／既有显示处理`。

- OpenAI 和 Gemini 的流式／非流式均传入统一调用结果；原始参数字符串仅留在请求内供截断恢复，业务 handler 继续收到原解析参数。
- Gemini 支持原子 args，以及有名开头／匿名 `partialArgs` 的 `$.content` 字符串片段。空参数结束标记不生成正文或新工具调用；JSON 数组流沿用现有解析器。
- 参数 JSON 不完整时，仅恢复已经收到的顶层 content 字符串，处理转义和完整 Unicode 单元；不猜测未到达内容。无可恢复内容时保留普通正文（可能为空）。网络错误仍沿用原流式失败处理，不承诺在任意连接异常下恢复。
- 普通正文与本次传输调用的正文取最长者，等长优先传输；不把两个通道拼接成重复正文。重复结束标记不再增加正文。
- 消费结果按调用数组位置记录，不能仅按可能为空／重复的工具 ID 过滤，否则会误删 Gemini 同轮业务调用。
- 后续业务工具请求从解包正文和剩余业务调用重建。禁止回用包含传输封套的原 provider response；Gemini 原生 model 角色在进入 JS 前归一为 assistant，结构化 parts 和业务调用签名保留。
- 保存的 rawReplyText 为解包正文；业务工具记录照旧保存。本决定不调整显示正则、think 剥离或历史投影顺序。

### 传输正文的流式显示（2026-09-29 修订）

- OpenAI arguments delta 累计后，约 50ms 合并一次最新快照，再跨 QuickJS 调用已有部分 content 解码器。不是每个网络分片调用一次 JS；流结束会刷新最后一批并做完整解包。
- Gemini `partialArgs` 同样累计显示；只有整块 `args` 的响应在结束后解包显示，不模拟假打字。未完整到达的转义及 Unicode 代理对不提前显示。
- 流式期间普通正文与本次传输正文已经按最长选择，等长优先传输；不拼接两条通道，不再暂存全部普通正文。如果两条通道内容不同而发生切换，现有替换回调重置显示；同一正文的连续片段不会回退。
- 中间文本仅用于流式 UI，不落库、不进入历史。最终 rawReplyText 始终来自流结束后的完整解包；业务工具调用仍在结束后照常执行，不被预览消费。
- 小猫原有 SPreset 输出协议保持既有行为，本次流式扩展仅接宿主传输工具。

## 验收与限制

离线测试直接读取仓库归档的 Kemini v3.1 原始 JSON，不使用改写提示词的兼容版。中性消息经真实 ChatSendApiRunner、QuickJS、AgentApiClient、两种 Provider adapter 和 HTTP 边界替身覆盖完整链路；业务混合场景显式启用业务工具权限，默认原件保持 function_calling=false。

验收包括：请求副本和工具策略；能力不足正常发送及诊断；脚本更新、锚点追加和读取降级；四种响应路径；截断转义；重名／空 ID 隔离；重复正文与结束标记；Gemini partialArgs／JSON 数组流；分片预览、跨分片转义／Unicode、最终正文一致；混合业务调用及后续轮次；小猫和既有生图／压缩回归。最终数量、静态检查和真实请求状态写入需求日志及模块文档。

不新增 schema、不安装或修改账户状态。B2 和面板均未交付；离线通过不等于运行中的应用已更新，也不等于真实供应商验收。

## 回滚

解除预设绑定或停用酒馆插件可回到既有发送行为。也可在原 JSON 显式关闭传输配置后重新导入，本批未新增面板开关。源码回滚只撤回 B1 的运行时契约、传输资产、供应商参数／片段保留和调用链改动；保留此前 QuickJS／小猫实现、原始预设、用户数据及其它工作树改动。
