# 0073 引导 Agent：项目管家，手动允许／无限制两种模式

- 状态：proposed（2026-10-11 用户确认方向：两种授权模式、建在新内核上；详细方案待写、待确认）
- 日期：2026-10-11
- 关联：ADR0064（Dart 微内核与全插件化，本 Agent 的运行底座）、ADR0060（统一装配）、ADR0065（诊断白名单）、ADR0066（本地隐私优先）、ADR0072（MCP 连接器）

## 背景

用户需要一个应用内的引导 Agent：负责新手教程，并能作为项目级管家调节各项功能、排查问题（例如看日志判断模型为什么慢、哪些工具没有生效）。现有可复用数据：`TraceQueryService` 的按轮阶段与工具调用计数、`ApiLogger` 的 `durationMs`、ADR0065 的诊断白名单；首字耗时尚未系统落盘。

## 决定（已确认部分）

1. **两种授权模式，由用户切换**：
   - 手动允许模式（默认）：读取诊断数据之外的内容（聊天正文等）、修改任何设置，都要用户当场逐次允许。
   - 无限制模式：可读取应用内全部数据、直接执行调整，作为项目级管家。开启前必须明确提示风险：所读内容会发送给用户所配的模型服务商；它的修改不经逐次确认。
2. **建在 ADR0064 新内核上**，不在旧链路上过渡；它的工具以内置插件贡献点的形式接入，因此依赖 ADR0064 第二批（内置插件接口）落地。
3. 模型使用用户自己配置的模型；无中心服务器。

## 待方案确认的默认值（AI 提议，可否决）

- 无限制模式下仍保留两条技术护栏，不减少能力：API 密钥、令牌只能被工具“使用”，值不进入模型上下文；每次修改先记录可撤销快照，删除类操作先备份。
- 首批工具：只读体检（慢在哪一段、工具为何未生效）＋入口与跳转；其次是调整类与新手教程。
- 入口为聊天列表中的固定系统联系人，复用聊天页，但不是角色卡，按 `AgentDefinition` 单独定义上下文、工具策略与输出契约。

## 代价

- 无限制模式会把隐私数据发给模型服务商，与 ADR0066 的默认立场相反，只能作为用户主动、知情的选择存在。
- 依赖第二批，交付时间晚于在旧链路上直接做。
