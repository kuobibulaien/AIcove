# 0073 引导 Agent（AIcove 助手）：内置角色＋按风险档自动审批

- 状态：accepted（2026-10-11 方向；2026-10-17 用户确认形态与授权，取代原「手动允许／无限制两种模式」）
- 日期：2026-10-11，修订 2026-10-17
- 关联：ADR0064（Dart 微内核与全插件化，本 Agent 的运行底座）、ADR0060（统一装配）、ADR0065（诊断白名单）、ADR0066（本地隐私优先）、ADR0072（MCP 连接器）、ADR0087（AIcove 默认空间）
- 方案：[AIcove 助手与新手教程](../../../apps/aicove_flutter/docs/04_功能模块规范/AIcove助手/README.md)

## 背景

用户需要一个应用内的引导 Agent：负责新手教程，并能作为项目级管家调节各项功能、排查问题。很多新用户连 API 都不会配，所以在有模型之前也要能引导。

## 决定

1. **助手是内置角色**：固定 id `aicove_assistant`，角色与会话随现有同步；人设可改，能力由只在助手会话里安装的内置插件挂载、不在角色卡里。
2. **两个阶段**：没有可用模型时走本机固定剧本（先问经验，可一键跳过全部教程），引导填 Key、测试连接、设默认模型；有模型后同一会话改由真实模型驱动。剧本卡片不入消息表。
3. **按风险档自动审批**：工具与设置项各自声明风险档（只读／可撤销／需审核／重大／禁止）。只读与可撤销直接执行（可撤销的给撤销条）；需审核交给独立审核请求，只看用户消息与工具调用、不看 Agent 文本和工具结果，失败按交给用户处理，连续 3 次被拒停下；重大档始终问用户，审核不能代批；禁止档不提供工具。用户可在助手聊天页「更多」里改为「修改前每次问我」（本机设置，助手不能改）。原「无限制模式」取消。
4. **Key 不进模型上下文**：模型需要 Key 时只能调用 `aicove_request_key` 在聊天页放一张输入卡片，值直接写进渠道，模型只知道卡片已显示。
5. **主要工作是让用户聊得顺**：写和改角色卡、排查插件生效、找上下文问题、理清酒馆预设／正则／世界书，并最终直接上手修改；能力由只在助手会话里安装的内置插件提供，不写在可编辑的角色卡里。
6. **资料库写给 Agent 看**：只写 AIcove 现状（功能地图、设置项清单、渠道、依赖、已知限制、排查路径），不写模型已知的常识；设置项清单由白名单注册表自动生成。
7. 建在 ADR0064 新内核上；模型使用用户自己配置的模型，无中心服务器。

## 代价

- 自动审批会有误放行与误拦截（两家公开数据都承认不是确定性保证），靠风险档把真正重大的操作排除在模型判断之外。
- 需审核档每次多一次模型请求，增加耗时和少量费用。
- 助手会话同步意味着排错对话会出现在所有设备上。
