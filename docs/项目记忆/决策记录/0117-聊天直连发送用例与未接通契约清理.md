# 0117 聊天直连发送用例与未接通契约清理

- 状态：accepted，2026-10-26 按用户五步计划第四步实施。
- 关联：0064、0108、0115、0116。保留 Port／Adapter 的真实测试与模块边界。

## 直接调用真实发送用例

聊天入口改为 `ChatActions → chatSendUseCaseProvider → ChatSendUseCase.executeTurn → ChatSendPort → ChatSendServiceAdapter → ChatSendService / ChatSendBackendService → KernelApiRunner → AgentLoop`。删除 `StandardChatAgent`、`StandardChatAgentRuntime`、`DirectAgentScheduler` 及三个标准聊天 Agent provider，不再构造仅用于标签／元数据的运行请求与结果。

- 保留 `ChatActions.retry`：失败表情经 `recallFailedMessage` 调它重发，不能当成死代码删除。
- `ChatTurnExecutionOptions`／UseCase 移除未执行的 `onProcessingResponse` 和只供旧测试使用的两种 execute 包装入口；流式准备回调移出 UseCase。实际启流并非死代码：retry／regenerate 在各自 `prepareTurn` 内完成历史准备后创建并启动流式交付，再由 UseCase 检查代次、请求模型；普通发送保留原来的启流位置。
- 正式 Raw 的登记、落库检查与 `toolProgress` 交接保留在 turn runner 的交付回调中；停止可见文本、工具保全、失败标记与 generation 收尾沿用既有合同。

## 删除未接通定义，保留实际配置与执行策略

删除没有调用方的 `chat_message_builder.dart`、`agent_context_defaults_loader.dart`，保留 defaults asset 与活跃的 `chat_types.AssistantMessageBuildResult`。

`agent_runtime_contracts.dart` 移除旧 RunRequest／Result／Status、Runtime／Scheduler、输出事件／交付接口及未接通的上下文节点／配方／装配模型。`AgentContextAssemblyPermission(s)`、profile 权限字段和 `canAssemble` 没有实际装配检查，移除这些声明与摘要器中的无效参数；保留 profile 的 layers、优先级、预算、历史窗口和活跃的 AgentDefinition／OutputContract／ToolAuthorization／DeliveryChannelKind 等配置。不将移除空权限字段表述为取消实际权限检查。

此外移除 `SendRequest`／`AssistantDeliveryResult`、依赖页面消息列表的 `prepareHistory`、旧插件筛选 `getEffectivePlugins`、未产生也未消费的 kernel `TextDelta`／`TextReset`／`ToolCallsObserved`。历史切片只走数据库入口；插件角色筛选使用 `PluginRuntime.selectForRole`，MCP 仍须显式开启。包内外的当前源码／测试／工具均已检索，不修改仓库外消费者。

`DEVELOPMENT.md` 同步为真实调用链，不再要求新增未实现的装配权限或投递接口。

## 测试口径

- 旧包装测试的历史准备、模型选择、流式回调和交付结果断言迁到 `executeTurn`；移除只验证旧壳元数据／IDs 的测试。补 direct provider 注入、取消准备边界和失败表情真实重发入口。
- 三项话题边界测试迁到内存数据库，保留切片结果与失效边界抛错断言；MCP 显式选择和全局关闭断言走真实 runtime。
- 扩大回归发现的两个既有测试漂移同步修正：进程恢复替身已提交用户消息后才抛错，应验证正常返回且已提交消息标为 failed；工具模式 golden 对齐本轮开始前已存在的直接工具清单、可用插件工具、多消息设置与本机目录说明，保留完整请求快照比较，不修改生产输出。
