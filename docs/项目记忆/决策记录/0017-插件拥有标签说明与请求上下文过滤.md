# 插件拥有标签说明与请求上下文过滤

## 背景

用户要求标签说明归回插件；绘图或语音关闭后，重新组装的上下文必须屏蔽对应标签及正文。原主聊天链路在标签列表为空时仍注入统一前导，并在绘图关闭后继续补历史图片保护规则、失败提醒。

## 决定

- 绘图插件拥有快速模式标签说明、历史图片保护规则与生图失败提醒语义；语音插件通过自身提示词入口提供 TTS 说明；时间插件提供时间提醒标签语义。主发送链路不再生成统一标签说明前导或绕过插件开关注入图片规则。
- ChatPluginContextPolicy 按本轮有效插件（全局开启且角色允许，使用请求预设快照）过滤请求副本。关闭的 `<image>` / `<tts>` 标签连同正文一起移除，支持大小写、属性、跨行、自闭合、嵌套以及未闭合正文。
- 历史绘图、语音工具调用和结果成对移除；关闭绘图时不读取或描述 assistant 生成图片块。用户正常上传的图片、音频等附件保留。
- 在 raw 转请求时过滤，并在酒馆正则、预设组装后再次过滤，防止重新插入。角色说明、话题摘要和最终消息中同样的标签按同一策略处理。纯标签的新用户消息过滤后为空时明确拒绝，不能默默重放旧问题。
- 不回写 raw、blocks、预设或摘要；重开插件后仍可用原始材料重新组装。Trace 将规则归属到 plugin.*，最终系统提示词来自最终请求消息。调试页仅显示全局插件预览，不宣称是角色实际请求。

## 备选与代价

仅去掉默认前导不能解决历史标签与失败提醒泄漏；直接删除数据库材料会破坏重新开启后的恢复，因此采用请求派生层过滤。关闭语音后，过去仅存在于 TTS 标签内的正文也不进入新请求（按用户明确要求），普通标签外文字仍保留。

## 验收与回滚

离线主链路、插件提示词、工具配对、酒馆、话题摘要与360/1000px调试页回归通过。实际构建/设备验收见当次需求日志；离线测试不代表真机已更新。回滚本次插件和请求组装代码即可，无 schema 或持久配置迁移。
