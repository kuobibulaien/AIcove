# ADR0051：局域网设备直连同步

- 状态：accepted，初版源码与主机网络验证完成；真实多设备及 Windows/iOS 验收待补。
- 日期：2026-10-01
- 授权：用户要求自行设计并实现，先完成局域网内同步。

## 决定

新增独立的局域网同步模式，不要求云账号或公网服务。复用本地主业务行、完整消息快照、媒体身份/哈希校验及 ADR0050 设置字段时间；不双向复制活动 SQLite 文件，不把一台手机当作必须常驻的中心服务器。

每台设备保有持久设备身份及自己的修改计数，实体以因果版本向量和不可变修订比较；并发设置按字段时间合并，并发聊天/文件修改及删除与编辑保留双方供显式选择。单纯较晚接收不产生新的编辑。配对设备交换摘要，仅传缺少的修订与附件；断线/重启后可重复，删除保留墓碑。

通过原生 Bonjour/NSD 发现已经配对的设备，并以扫码/输入配对码提供直接地址后备。首次扫码证明持有一次性随机邀请，另一端仍须确认；每对设备独立派生密钥，消息和分块附件使用 AES-256-GCM 认证加密。密钥放在设备凭据存储，不随业务数据同步。公开发现记录不包含聊天、账户或配对秘密。邀请到期、暂停与撤销配对均停止对应访问。

全端共用“局域网同步”页面，从设置进入，无账号依赖。移动端前台同步、回前台重连；不申请后台常驻/蓝牙或自动改系统防火墙。共用连接、应用层 Port 和持久化引擎；平台分支限于发现/权限、相机与应用生命周期。云同步保持独立，不能复用服务器 seq 作为设备直连的因果依据。

## 边界与代价

第一版面向能互相访问的同一 Wi-Fi/以太网/热点，不接入公网信令、中继或异地穿透。Bonjour 被路由器隔离时可尝试配对码中的直连地址；网络本身禁止设备互访时必须报告不可达。“通用”设置只留本机；退役记忆类型按现有契约不重新纳入。

两个设备需有同时在线的窗口；iOS/iPadOS 锁屏/后台不保证同步。首次合并前保全本地备份，不能自动删除业务历史。新增辅助表与依赖可回退，保留修订/墓碑/原文件；不提高业务数据库 user_version，不清空现有云队列。
