# 0092：插件提示词按模型分包，由预设绑定

关联：ADR0008／0009（插件预设与角色绑定）、ADR0054（插件标签说明全局一份，本 ADR 取代其中语音、绘图两个槽位）、ADR0081（语音请求格式注册表）、ADR0073（AIcove 助手）。方案：[插件提示词包](../../../apps/aicove_flutter/docs/04_功能模块规范/插件提示词包/README.md)。

## 背景

ADR0054 把标签说明收成全局一份，但各家模型对输入的要求不同：Fish Audio S2 用方括号自然语言标签，MiniMax 用圆括号语气词和 `<#秒#>` 停顿，NovelAI 要 Danbooru 标签和花括号权重，自然语言生图模型要完整句子。代码只好按网址、格式、模型名猜渠道，在全局文本后面追加写死的常量；Fish、通话、参数契约等说明用户看不到也改不了。用户 2026-10-19 要求按模型写独立默认说明、按正则或关键字匹配同家族模型、预设可绑定可编辑、在预设里看到全部说明、助手可直接改，后续插件同样改造；同日确认包共享编辑、预设默认一对一、角色绘图提示并入绘图预设、角色卡底部加联系人上下文入口。

## 备选

1. 维持全局一份，只把写死的常量挪进槽位。不同模型仍共用基础文本，改 Fish 写法会影响 MiniMax。
2. 说明存进每个预设。同家族多个预设要各改一遍，出厂默认更新无法跟随（ADR0054 之前的老问题）。
3. 说明做成独立的「提示词包」，按模型家族匹配出厂包，预设可显式绑定；包被预设共享，出厂包只存差异。

## 决定

采用 3。

1. 提示词包＝某插件给模型的全部说明，由带 scope 的有序节组成；代码不在包外追加说明文字。
2. 匹配只认渠道请求格式＋模型 ID 模式（关键字包含或 `/正则/`），顺序：预设显式绑定 → 自建包规则 → 出厂专用包规则 → 出厂通用包。不按网址猜。
3. 音色预设合成配置、绘图预设各加提示词绑定：可空的 `packId`（空＝自动匹配）＋不共享的专属节 `ownSections`。单个预设通常只给一个角色用：角色卡里「为这个角色新建」复制当前预设并只绑该角色；角色卡的「绘图提示」并入绘图预设的专属节（迁移时必要时为角色复制出专属预设），角色卡不再有这一项。
4. 包是共享对象：在预设页编辑即编辑该包，页面写明在用预设数；「另存为新包」只影响当前预设。
5. 存储 `aicove.plugins.prompt_packs.v1`（随设置同步）：出厂包差异＋自建包全文；出厂包本体在代码里。
6. 解析出的包随音色／绘图预设请求快照一起固定。
7. AIcove 助手可读写提示词包和绑定，写入档位 `review`，走本机撤销账本。

## 代价

- 用户改过的全局语音／绘图说明不再自动生效，迁移成未绑定的自建包，需要手动绑定（绘图预设里的工具描述例外，会自动绑回原预设）。
- 角色的「绘图提示」移出人设字段后只存在于预设里，回滚代码需手动抄回。
- 共享编辑可能误伤同包的其它预设，靠界面提示和「另存为新包」兜底。
- 阿里云、IndexTTS 等内联标签支持未用真实 Key 验证，初版保守不开。
- 工具提示词页在表情包、时间感知迁走前仍保留两项，两套入口并存一段时间。

## 修订（2026-10-21）：绘图作用域合并

- 绘图节按「快速 inline、工具说明、提示词、参数」四个作用域编辑；宽、高、张数、步数、强度合并为 `tool.params`，负面提示词并入 `tool.prompt`。
- 旧作用域读取时映射到新作用域（`PromptScopes.canonical`），存档不重写；出厂节 ID 合并后，用户改过的文字保留为同作用域的自建节。
- 代价：合并后的 `tool.params` 只能整段改，单独某个参数不能只关掉；旧出厂节的启用／关闭状态不再对应。
