# 上下文窗口与自动压缩

日期：2026-09-13；状态：superseded（触发、保留及记忆策略由[ADR0027](0027-压缩与持久记忆联动.md)替代；以下保留首批实现记录）。用户明确要求移除历史消息条数设置及相关代码，替换为默认272k的上下文窗口，达到阈值必定触发压缩。

## 决定

- 移除全局 historyMessageLimit、设置读写和发送前的N条裁剪；旧持久值仅在归一化时删除，不把消息条数当成token。
- 新设置 contextWindowTokens / context_window_tokens 默认272000，页面以k tokens编辑，1k=1000，沿用自动保存。
- 聊天主发送入口从DB raw载入完整当前话题。普通及酒馆请求完整装配后，以本地token估算（含系统、历史、工具schema及调用参数）检查；有效输入上限取用户窗口与模型/预设容量扣除输出预留后的较小值，达到上限即先压缩，不再静默截断。
- 自动摘要保留目标、进度、约束、工具结果和待办；保留最近3个完整user轮次，必要时缩到最近1轮，再超限则报错阻止发送。复用无工具权限的分批总结适配器，但使用独立AgentDefinition和提示词，不能调用手动新话题提交入口。
- AutomaticContextPort / AutomaticContextStorePort承接应用与存储边界；摘要复用topic_handoffs表，memory_state=automatic，previous_boundary_id固定所属手动话题边界。原文和conversation.contextStartMessageId不变，不生成UI话题分隔线，不自动归档长期记忆。
- 读取摘要校验当前请求的raw来源与摘要指纹，旧轮次重放不倒灌未来摘要；提交事务再次验证来源和话题。失败保留原文并阻止超限请求。手动摘要查询排除automatic记录。

## 范围与代价

本批处理聊天发送/重新生成及走主发送装配的主动请求边界；工具执行循环内部新增内容的压缩不在本批。token为本地估算，图片沿用现有估值，不声称与每家供应商分词一致。总结使用已配置总结模型，未配置则用默认聊天模型；没有进行生产模型请求，摘要语义质量尚需实际模型验收。

## 验收与回滚

以数据库和最终请求装配测试验证272k、阈值等号、失败、编辑失效、重放与关闭重开后的摘要恢复；宽窄设置页源码渲染和自动保存测试验证UI。实际运行端状态在需求日志记录。
回滚仅撤回本批源码差异，保留原聊天与已有用户改动；automatic记录可保留为派生缓存，由旧手动查询隔离，不需要删除数据或迁移schema。ADR0007仍约束手动新话题，本决定替代其自动压缩未实现的状态。
