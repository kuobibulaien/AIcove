# 0054 插件标签说明全局一份

- 状态：accepted
- 日期：2026-10-03
- 关联：ADR0008／0009（插件预设与角色绑定）

## 背景

插件注入给模型的标签／工具说明散在五处：绘图说明存在每个绘图预设里，`<tts>` 说明存在每个音色预设里并覆盖全局，表情包与时间感知模板在插件配置里，但只有调试中心旧「工具提示词管理」页能改（该页 10-03 已删）。同一角色换预设会换掉通用说明，违背「通用说明所有角色一致、角色只改专属提示词」。

## 备选

1. 保持现状，只把编辑入口挪进各插件／预设页。说明仍随预设变化。
2. 改成 skill 按需加载。标签格式规则必须常驻，不支持工具调用的模型也无法读取 skill，总量仅 2～3k tokens，收益小于多一轮请求的延迟。
3. 全局存一份，预设和插件配置不再携带说明。

## 决定

采用 3。

- 真相源：`features/plugins/prompts/plugin_prompts.dart`，SharedPreferences 键 `aicove.plugins.prompts.v1`（随 `aicove.plugins.` 前缀参与设置同步，按槽位字段合并），只保存与出厂默认不同的槽位；出厂默认仍来自 `assets/prompt_defaults.json`。
- 槽位：绘图 `<image>` 说明、`<tts>` 说明、表情包说明、当前时间提醒。新增插件说明在 `PluginPromptSlot` 加一项即可出现在编辑页。
- 运行时：`ChatSendBackendService.prepareApiConfig` 读取全局值，覆盖本轮绘图预设快照、`TtsPlugin.forRequest`、表情包与时间感知插件实例里的旧模板。
- 角色专属内容不变：人设、角色专属绘图提示词仍随角色卡。
- 编辑入口：设置 → 插件 → 工具提示词，自动保存，可逐段恢复默认。绘图预设与音色预设编辑页移除提示词字段。
- 迁移：首次读取时取默认绘图预设、默认音色预设（无则旧全局语音配置）、表情包与时间感知配置中的值；与默认相同的不保存。旧键与旧字段原样保留，回滚只需还原代码。

## 代价

- 非默认预设里改过的说明不再生效（用户确认取默认预设的值）。
- 旧字段保留在数据里但被忽略，后续清理需单独迁移。
- `draw_image` 工具说明未纳入：后续批次绘图改为只走 `<image>` 标签，该工具与说明会整体移除；提醒工具同样改标签后再加槽位。
