## 背景

此前 `packages/aicove_quickjs` 分裂为两套机制：
1. `QuickJsSession`（`bridge.c`）：仅支持同步微任务、1 秒超时、无宿主通道，遇到未决异步操作直接报 `Unresolved async operation: host I/O is unavailable`，预设脚本与正则使用它。
2. `QuickJsAsyncSession`（`async_bridge.c`）：支持 `__aq_host` 异步宿主调用（真实 HTTP `fetch`、文件读写、工具调用），但每次 `run` 跑完即销毁 `JSContext`，且在运行期以 1ms `Timer.periodic` 轮询推进。
3. 预设运行时（`QuickJsPresetRuntime`）此前完全不执行 `extensions.tavern_helper.scripts`，仅靠白名单与词法提取配置再由宿主仿写脚本替代，导致新预设（如 `kunlun_linux_1.6.json`）或自定义外部脚本无法直接工作。

## 决定

1. **底座二合一（长驻 `JSContext` + 事件驱动异步宿主通道）**：
   - `async_bridge.c` 支持同一 `JSRuntime`／`JSContext` 多次调用 `aqjs_async_begin`（释放上一轮结果、重置状态与当轮截止时间），栈上限提升至 2 MiB。
   - `QuickJsSession` 统一跑在多轮异步引擎上，支持传入 `hostCall`、自定义 `heapBytes`、`maxSourceBytes` 与 `timeout`，跨多次 `evaluate` 共享全局变量、闭包与挂载的钩子；等待宿主回包期间完全由事件唤醒驱动，去除 1ms 空转轮询。
   - 无宿主调用在途且微任务已排空的悬空 Promise 立即判定失败，保留死循环中断与内存保护边界。
2. **预设脚本底座全面开放外部访问与酒馆标准环境**：
   - `QuickJsPresetRuntime` 以 256 MiB 堆、32 MiB 载荷上限、30 秒超时开启长驻异步会话，向预设脚本开放：
     - **分层 `fetch`**：`http(s)://` 外部地址直接经 `PublicNetwork.fetch` 发起真实网络请求（支持远程 API 调用与动态 `<script src="https://...">` 脚本拉取执行）；`/api/backends/.../generate` 内部路由接入生成请求拦截链。
     - **持久化存储**：`localStorage` 同步读写内存并经宿主异步持久化、`sessionStorage` 会话内有效。
     - **标准无头浏览器与酒馆兼容层**：内置 `window`、无头 `document`／DOM 桩、jQuery `$`、`setTimeout`/`setInterval`、`crypto`、`TextEncoder`/`TextDecoder`、`Headers`/`Request`/`Response`/`ReadableStream`、`SillyTavern.getContext()`、`TavernHelper` 变量接口及 `tavern_events`（`eventOn`/`eventOnce`/`eventMakeLast`/`eventEmit`）。
   - 预设中启用的 `tavern_helper.scripts`（含 `kunlun_linux_1.6.json` 的 ATE 3.2.0 `dispatch_stream_payload_`／`display_stream`、`kunlun_IDE_1.2r.json`、通用外部脚本等）直接在 QuickJS 底座上原生执行，静默放行，不设脚本 ID 白名单或弹窗阻断；合成测试桩继续兼容以确保无私有预设环境下的单元测试稳定运行。
3. **宏与预设体积上限扩充**：
   - `SillyTavernMacroEvaluator` 新增 `{{roll ...}}`（支持 `{{roll N}}`、`{{roll XdY±Z}}`）及 `{{incvar::key}}`、`{{decvar::key}}`、`{{addvar::key::delta}}`。
   - `SillyTavernPresetParser.maxSourceBytes` 提升至 16 MB。

## 边界

- 纯 JS 运行底座解决所有请求改写、上下文管理、外部接口请求、动态远程脚本加载与变量持久化类脚本；依赖真实网页画布渲染独立面板／浮球的纯 UI 脚本（如漫画台设置面板、ARGO 球体界面）后续再议是否引入 WebView。
