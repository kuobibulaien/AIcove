# 0049：指定账号长期登录态

## 背景

用户明确要求当前唯一账号的登录态长期持久化，不依赖刷新。现场手机显示待登录，Mac 本机账号 token 为空；线上 read-v1 仍使用 7 天 token 且未注册 ADR0040 的续期接口。客户端已有续期代码不代表服务端已部署。

## 决定

- 服务端通过 `PERSISTENT_SESSION_USER_IDS` 显式指定账号 ID，为这些账号签发没有 `exp` 的 JWT；默认列表为空，其他账号继续沿用原有效期。
- 原签名校验、账号存在与停用检查继续生效；显式传入的过期时间仍生效，已有过期 token 不会自动恢复。
- 账号密码仅在重新登录时使用，不存入源码、文档或客户端设置。长期 token 沿用现有 `DeviceCredentialStorage`；其他端维持平台安全存储。
- 现有客户端的账号校验和兼容性续期调用无需改动。长期 token 无需续期；旧服务端 `/refresh` 返回 404 时客户端保留原 token。支持续期接口的服务端为同一长期账号返回相同 token。
- 本决定取代 ADR0040 对指定账号“长期离线仍须重新登录”的要求；其他账号继续使用 ADR0040。

## 代价与回滚

长期 token 没有自动到期，也没有逐设备吊销能力；停用账号可即时阻止请求。回滚保留原镜像和配置，不改签名密钥、不覆盖同步数据库或附件。移除配置不会让已签发的无到期 token 自动失效；需要撤销时必须另行明确授权停用账号或轮换密钥。

## 验收门

隔离测试覆盖账号范围、显式到期、未来时间下无需续期、账号停用拒绝，以及原同步协议回归。生产切换、两端长期 token 落盘和原壁纸到达分别记录实际证据，未完成部分不能宣称通过。

2026-10-01 实测：57 项后端测试通过；指定账号最小补丁已按授权上线，两端重新登录且重启保留会话。原壁纸另被角色整卡冲突阻止，用户选择云端版本后，Mac 自动下载原图、哈希一致，实际聊天页已显示；未处理其它冲突。
