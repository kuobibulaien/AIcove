# 0080 全局壁纸与角色壁纸共用一套调节、渲染与编辑页

- 状态：accepted（2026-10-14 用户确认：截取按当前形态存一份、另一形态可单独调；角色遮罩改平铺；同意会话表加列）
- 日期：2026-10-14
- 关联：ADR0058（同步 v3 按整行同步）、ADR0070（上一次给会话表加列的先例）

## 背景

全局壁纸（设置 JSON，每张一份遮罩＋模糊，平铺遮罩，内置图截取写死靠左）和角色专属壁纸（会话表三列，渐变遮罩，固定居中，在「聊天界面」页内联调节）是两套互不相干的数据、渲染和编辑入口。两者都不能调截取位置，而且模糊叠层总是居中裁切，和靠左裁切的原图会错位。

## 决定

1. **一套调节模型**：`WallpaperStyle`（`ui/theme/moe_wallpaper.dart`）包含遮罩、模糊，以及 `narrow`／`wide` 两份可为空的 `WallpaperFraming`（焦点 x/y 取 -1..1，同 Alignment；缩放取 1..4）。某一形态没有自己的截取时沿用另一形态的；两份都没有时用壁纸的默认焦点（猫窗靠左）。形态按窗口宽度和工作区断点（900）判断。
2. **一个渲染组件**：`MoeWallpaperView` 负责底色、按截取铺满的原图、同一截取下的静态模糊叠层，以及平铺遮罩。全局壁纸 `MoeGlobalWallpaper` 和角色壁纸 `ChatWallpaperLayer` 都委托给它。角色壁纸原来的上浓下淡渐变遮罩取消，改成平铺。
3. **一个编辑页**：`WallpaperEditorPage`（`ui/features/wallpaper/`）。上方是宽窄屏两块预览画布，按真实尺寸（390×844、1280×800）布局后缩小显示，内容是真实列表项或消息气泡。在画布上拖动改截取，双指或滚轮缩放；下方面板调遮罩、模糊和缩放。窗口够宽时两块并排，否则用标签切换。截取默认只写当前形态那一份；在另一形态的画布里调过才单独存，可以一键改回沿用。全局壁纸编辑页是它的薄包装；「聊天界面」页的壁纸标签只留一个进入编辑页的入口。
4. **存储**：全局壁纸的截取跟着 `global_wallpaper_styles` 写进设置 JSON。角色壁纸在会话表新增一列 `chat_background_framing TEXT`，存 `WallpaperStyle.encodedFraming`：库从 v22 升到 v23，同步结构从 19 升到 20，备份里归入「角色设置」。清除或更换角色壁纸图片时，截取一并复位（`nextChatBackgroundFraming`）。

## 代价与缺口

- 两种壁纸的图片存储方式没有统一：全局壁纸存本机文件、不同步；角色壁纸是 data URI 存库、随同步。
- 角色壁纸的模糊值仍然不进备份（`transfer_safety` 原有限制，没有在这次改动），截取会进备份。
- 收到同步结构 20 的数据时，旧版本应用会拒绝这条会话记录，需要各端都升级。
- 编辑页的手势在测试里验证过；真实触屏和触控板的手感还没有在实机上验证。
