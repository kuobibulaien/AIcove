# 0041：预设按上下文语义兼容，而非文本改写

> 2026-09-28：用户要求撤回本批逐项兼容实现，已恢复相关源码与测试，四个新增源码/测试文件移入临时回滚档案。本文保留历史记录，下面的“已实现”不再代表当前代码。撤回时 JS 沙箱路线仅调研；后续获准采用 QuickJS，见 [ADR0042](0042-QuickJS预设纯逻辑运行时.md)。

## 背景与决定

用户明确：Kemini 与小猫之神是测试样例，目标是兼容各种预设对整个上下文的处理方式，不需要复刻其前端。不再以删除脚本、改写提示词、把工具输出要求换成直接正文的派生文本版作为交付。原件保持不变。

沿用既有 Port → Store → Parser → Assembler → ApiConfig → Provider → Runner 链路；以配置字段和节点标识解析请求级上下文计划，不匹配预设名称或正文关键词。界面展示与上下文语义分别判断；浏览器脚本即使附带界面，其中改写 messages、tools、响应或历史的行为仍属于兼容目标。

备选的任意 JavaScript/DOM 执行环境本次未引入；静态声明可在 Dart 中解释。该选择只覆盖明确的语法子集，不代表已有完整脚本运行时。

## 已实现的第一批子集

- 非 Unicode JS 正则不再强制 Unicode；`addvar/incvar/decvar` 常见数值、字符串与数组操作。
- SPreset 相对普通节点的 MessageInjections：结构化工具调用/结果、reasoning/signature，保留空正文节点。
- ToolBindings 以 code 而非可能过期的 form 为准；支持数据式 return 对象及 JSON.stringify 常量返回回调。禁止执行动态表达式。绑定须对应启用节点，工具与现有插件重名时明确失败。
- 无自定义输出函数的 consumeToolCalls：按本轮声明名称解包到 rawReplyText，随后才走显示处理，不触发额外工具轮次。流式目前在完整响应后解包。
- 自定义输出函数/formatter 未支持时，不单独启用依赖它的工具声明与消费，避免半套转换。未知功能明确列入警告与兼容报告。
- Claude/Gemini 将规范化工具消息转换为各自请求格式。单次请求固定工具及配置快照，后续开关只影响下一轮。

## 尚未完成

ChatSquash、ForcedPostProcessing、自定义 JavaScript 输出脚本/formatter、Kemini 动态脚本与工具封装、绝对/附加节点的结构化注入、任意宿主 API。不能宣称两个样例或其他预设完整兼容。消息体预算计入新增结构化字段；尚未统一估算工具 schema 的开销。真实模型与运行中应用未验收，未重新导入原版。

## 验证与代价

使用中性合成预设验证解析→装配→Claude/Gemini 请求与真实 prepareApiConfig 工具快照；Runner 模拟客户端验证流式/非流式正文回写，不发生产请求。证据与测试入口见客户端酒馆兼容插件文档。

此前导入的三个文本派生副本属于已放弃方向，原始归档、默认选择与已有角色绑定没有改动；副本保留但目录说明标记为作废方案，未删除用户数据。

回滚：按本批文件增量撤回上下文计划、工具接入和适配器转换；无需 DB/schema 迁移。不要恢复已由 ADR0035 移除的全局开关来充当回滚。
