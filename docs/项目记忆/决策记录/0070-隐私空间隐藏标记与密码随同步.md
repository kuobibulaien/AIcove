# 0070 隐私空间：隐藏标记与密码随同步

- 状态：accepted（2026-10-09 已实施：单元／组件测试通过，并接本地真实后端跑通 25 条云同步契约测试（新增隐藏合并与密码同步用例）；未实机验收，未提交）
- 日期：2026-10-09
- 关联：ADR0047（会话加列并升同步结构版本的先例）、ADR0066（本地隐私优先定位）

## 背景

用户要求在聊天列表的滑动菜单中，于「置顶」「删除」之外新增「隐藏」：被隐藏的联系人从主列表消失，进入「隐私空间」；在列表顶部下拉半屏触发，输入密码后进入。

同日先实现过「隐藏名单与密码只存本机凭据目录」的方案，用户否决：隐藏只是前端不显示，状态必须随云同步走，在所有设备上一致。

## 备选

1. 隐藏名单与密码只存本机（已否决）：不改 schema，但换设备、重装、导入后都要重新隐藏。
2. **会话表加 `is_hidden` 列 + 密码哈希放进随设置同步的偏好**。

## 决定

采用 2（用户 2026-10-09 确认 schema 迁移与同步密码哈希）。

- 数据：`conversations.is_hidden`（bool，默认 false），整库 v19→v20；同步结构版本 `kCloudRowSchema` 18→19。云同步与局域网同步共用整行快照和字段级时钟，两台设备分别改显隐和其它字段时按字段合并。备份导出／导入同样带上 `is_hidden`。
- 密码：偏好键 `aicove.privacy_space.v1`（常量在 `core/sync/cloud_setting_policy.dart`），加入同步白名单。值为单个字符串 `v1$盐$哈希`（PBKDF2-HMAC-SHA256，6 万次，16 字节随机盐）；不用 JSON 对象，否则同步按字段合并可能把两台设备的盐和哈希拼错。每次验证都现读存储，别的设备改的密码同步过来后立即生效。
- 界面：联系人列表过滤 `isHidden`；首次隐藏先引导设置密码；下拉入口用指针位移判断（不依赖滚动越界量），覆盖触摸与触控板。隐私空间页可取消隐藏、修改密码（需先验证旧密码）。实现见 `features/chat/application/privacy_space.dart`、`ui/features/home/pages/privacy_space_page.dart`。

## 代价

- 旧版本设备收到带 `is_hidden` 的会话行时会提示「请先更新应用」，所有设备升级后恢复（同 ADR0047）。
- 只隐藏联系人列表入口，不对聊天记录加密；收藏、角色卡、后台自动回复、通知等其它入口不受影响。
- 忘记密码无法找回；密码哈希会出现在用户自部署的云端。
