# 会员分级和云服务系统设计

> 📌 落地状态（2026-06-13）：`models.py` 已有 `user_level` / `expires_at` 字段，`admin_api.py` 已实现管理员改级接口与按级别统计；**按级别限制各云服务功能的权限闸门尚未实现**，各 API 目前不校验 `user_level`。本文其余内容为设计目标，不代表已实现。

## 🎯 系统概述

实现一个灵活的会员分级系统，不同级别的用户可以使用不同的云服务功能。

### 级别定义

| 级别 | 名称 | 功能权限 |
|------|------|----------|
| 0 | 免费版 | 基础数据同步（联系人、消息、设置） |
| 1 | 基础版 | 免费版 + 数据备份 |
| 2 | 标准版 | 基础版 + Key分发（有额度） |
| 3 | 高级版 | 标准版 + 云触发器 |
| 4 | 专业版 | 高级版 + 云记忆库 |
| 99 | 管理员 | 所有功能 + 后台管理 |

### 2️⃣ Key分发（Level 2+）

**功能：**
- 管理员在后台统一管理API Keys
- 用户无需自己提供Key
- 每个用户有调用额度
- 支持多个Provider（OpenAI、Gemini等）
- 额度用完自动禁用

**数据库表：**
```python
# 管理员配置的Key池
class ApiKeyPool(Base):
    id = Column(Integer, primary_key=True)
    provider = Column(String(50))     # 'openai', 'gemini'
    api_key_encrypted = Column(Text)  # 加密的Key
    quota_total = Column(Integer)     # 总额度（如：1000000 tokens）
    quota_used = Column(Integer, default=0)
    is_active = Column(Boolean, default=True)
    created_at = Column(DateTime, default=func.now())

# 用户额度分配
class UserQuota(Base):
    id = Column(Integer, primary_key=True)
    user_id = Column(Integer, ForeignKey('users.id'))
    provider = Column(String(50))
    quota_total = Column(Integer)     # 分配的总额度
    quota_used = Column(Integer, default=0)
    quota_reset_at = Column(DateTime) # 额度重置时间
    created_at = Column(DateTime, default=func.now())

# 使用记录
class QuotaUsageLog(Base):
    id = Column(Integer, primary_key=True)
    user_id = Column(Integer, ForeignKey('users.id'))
    provider = Column(String(50))
    tokens_used = Column(Integer)
    request_id = Column(String(100))
    created_at = Column(DateTime, default=func.now())
```

**API端点：**
```
# 用户端
GET  /api/v1/keys/available        # 获取可用的Provider列表
POST /api/v1/keys/request          # 请求Key（返回临时Key或代理）
GET  /api/v1/keys/quota            # 查看自己的额度

# 管理员端
POST /api/v1/admin/keys/pool       # 添加Key到池中
GET  /api/v1/admin/keys/pool       # Key池列表
POST /api/v1/admin/keys/assign     # 给用户分配额度
GET  /api/v1/admin/keys/usage      # 查看使用统计
```

**工作流程：**
```
1. 管理员添加Key到池中：
   - Provider: OpenAI
   - Key: sk-xxx...
   - 总额度: 1000000 tokens

2. 管理员给用户分配额度：
   - 用户: USER-00001
   - Provider: OpenAI
   - 额度: 10000 tokens/月

3. 用户请求Key：
   - Flutter → POST /api/v1/keys/request {provider: "openai"}
   - 后端 → 检查额度 → 返回临时Key或代理URL
   
4. 用户使用Key：
   - Flutter → 调用OpenAI API
   - 后端 → 记录使用量 → 扣除额度

5. 额度耗尽：
   - 用户请求Key时返回"额度不足"
   - 下月1日自动重置额度
```

**使用流程：**
```
1. 用户聊天时：
   - Flutter → 发送消息
   - 后端 → 提取关键信息 → 存储到记忆库
   
2. 下次对话时：
   - Flutter → 发送新消息
   - 后端 → 向量搜索相关记忆
   - 后端 → 将相关记忆注入System Prompt
   - AI → 生成回复（带有历史记忆）
```

### 权限检查装饰器

```python
from functools import wraps

def require_level(min_level: int):
    """要求最低用户级别"""
    def decorator(func):
        @wraps(func)
        async def wrapper(*args, **kwargs):
            user_id = kwargs.get('user_id')
            db = kwargs.get('db')
            
            user = db.query(User).filter(User.id == user_id).first()
            if user.user_level < min_level:
                raise HTTPException(
                    status_code=403,
                    detail=f"此功能需要Level {min_level}及以上会员"
                )
            
            return await func(*args, **kwargs)
        return wrapper
    return decorator

# 使用示例
```
