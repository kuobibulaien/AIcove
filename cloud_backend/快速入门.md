# Cloud Backend 快速入门（5分钟上手）

## 🎯 它是什么？

一个以「云端数据服务」为核心的后端（FastAPI）：
1. **管账号**：注册、登录、鉴权
2. **管数据**：同步（含 v2）、备份/恢复、回收站等
3. **扩展能力**：云触发器、云记忆库、Key 分发与额度
4. **管理面板**：Prompt Studio / Agent Context Studio，入口 `http://localhost:8000/api/v1/prompt-defaults-admin/panel`

**不做的事：**
- ❌ 不负责AI对话（Flutter做）
- ❌ 不负责直接调用模型服务（Flutter做）

## 📝 第一次使用（3步）

### 第1步：创建管理员
```bash
curl -X POST http://localhost:8000/api/v1/auth/bootstrap-admin \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
```

**返回：**
```json
{
  "access_token": "eyJhbGc...",
  "token_type": "bearer",
  "user": {
    "id": 1,
    "username": "admin",
    "email": null,
    "user_level": 99,
    "unique_id": "ADMIN-00001",
    "expires_at": null,
    "is_admin": true,
    "is_active": true,
    "created_at": "2025-01-14T10:00:00"
  }
}
```

**保存这个token！** 后面要用。

### 第2步：创建邀请码
```bash
curl -X POST http://localhost:8000/api/v1/admin/invites \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGc..." \
  -d '{"code":"WELCOME","max_uses":100}'
```

**返回：**
```json
{
  "code": "WELCOME",
  "max_uses": 100,
  "used_count": 0,
  "enabled": true,
  "created_at": "2025-01-14T10:01:00"
}
```

### 第3步：普通用户注册
```bash
curl -X POST http://localhost:8000/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "username":"zhangsan",
    "password":"123456",
    "invite_code":"WELCOME"
  }'
```

**返回：**
```json
{
  "access_token": "eyJhbGc...",
  "token_type": "bearer",
  "user": {
    "id": 2,
    "username": "zhangsan",
    "email": null,
    "user_level": 0,
    "unique_id": "USER-00002",
    "expires_at": null,
    "is_admin": false,
    "is_active": true,
    "created_at": "2025-01-14T10:05:00"
  }
}
```

完成！现在可以在Flutter中登录了。

## 🔄 数据同步流程

### 上传联系人：
```bash
curl -X POST http://localhost:8000/api/v1/sync/contacts \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "items": [{
      "contact_id": "uuid-123",
      "name": "小美",
      "avatar_url": "https://example.com/avatar.jpg",
      "character_data": {
        "system_prompt": "你是一个温柔的女友"
      },
      "updated_at": "2025-01-14T10:00:00Z"
    }]
  }'
```

### 获取联系人：
```bash
curl http://localhost:8000/api/v1/sync/contacts \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 上传消息：
```bash
curl -X POST http://localhost:8000/api/v1/sync/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "items": [{
      "message_id": "msg-456",
      "contact_id": "uuid-123",
      "role": "user",
      "content": "你好",
      "created_at": "2025-01-14T10:05:00Z"
    }]
  }'
```

> 上面这组例子走的是旧版 `/api/v1/sync` 接口，适合快速验通；新功能优先看 `sync_api_v2.py`。

## 🌐 部署到服务器

### 1. 购买服务器
- 阿里云/腾讯云：60-100元/月
- DigitalOcean/Vultr：5美元/月

### 2. SSH连接
```bash
ssh root@your-server-ip
```

### 3. 安装Docker
```bash
curl -fsSL https://get.docker.com | sh
```

### 4. 部署
```bash
# 克隆代码
git clone your-repo.git
cd your-repo/cloud_backend

# 配置
cp .env.example .env
nano .env  # 修改SECRET_KEY

# 启动
docker-compose up -d
```

### 5. 配置域名（可选）
```bash
# 安装Nginx
apt install nginx certbot python3-certbot-nginx

# 配置（创建 /etc/nginx/sites-available/aicove）
server {
    listen 80;
    server_name api.yourdomain.com;
    location / {
        proxy_pass http://127.0.0.1:8000;
    }
}

# 启用
ln -s /etc/nginx/sites-available/aicove /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx

# 申请SSL
certbot --nginx -d api.yourdomain.com
```

完成！访问 https://api.yourdomain.com

## 📱 Flutter连接

### 开发模式（本地测试）：
```bash
flutter run --dart-define=API_BASE_URL=http://localhost:8000
```

### 生产模式（服务器）：
```bash
flutter run --dart-define=API_BASE_URL=https://api.yourdomain.com
```

或在 Flutter 侧调整 `apps/aicove_flutter/lib/src/core/config.dart` 里的地址常量：
```dart
const String _defaultApiUrl = 'https://api.yourdomain.com';
```

## 🐛 遇到问题？

### 端口被占用
```bash
# 查看占用
lsof -i :8000  # Linux/Mac
netstat -ano | findstr :8000  # Windows

# 修改端口（.env）
PORT=8080
```

### 忘记管理员密码
```bash
# 删除数据库重来
rm data/sync.db
python main.py
# 重新创建管理员
```

### 查看日志
```bash
# Docker方式
docker-compose logs -f

# 直接运行
# 日志显示在终端
```

### 数据库损坏
```bash
# 恢复备份
cp data/backup_20250114.db data/sync.db
```
