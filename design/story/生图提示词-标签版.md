# 宣传页生图提示词（标签版，用于二次生图）

用途：先用 GPT 等自然语言模型按 [生图任务书](生图任务书.md) 出构图，再拿那张图做**图生图**，用 Danbooru 标签加画师串统一画风、去掉噪点。坐标、文件名、透明要求仍以 [生图任务书](生图任务书.md) 为准。

下面的写法以 NovelAI（V4 及以后）为主，Stable Diffusion 系（Illustrious、NoobAI 等）的写法附在后面。

## 一、二次生图怎么设

| 目的 | NovelAI 图生图 | SD 图生图 |
|---|---|---|
| 换画风、保构图 | Strength 0.45–0.55，Noise 0 | Denoise 0.4–0.55，加 ControlNet（lineart 或 tile）锁结构 |
| 只去噪、尽量不改 | Strength 0.3–0.4，Noise 0 | Denoise 0.25–0.35 |

- **统一整套风格**：先挑出最满意的一张房间图，用 NovelAI 的 Vibe Transfer（风格参考）喂给后面每一张；SD 用 IP-Adapter。种子也尽量固定。
- **尺寸**：生图模型一般出不了 3200×1800。先用最接近 16:9 的尺寸（如 1344×768），出图后放大到 3200×1800。
- **透明背景**：这类模型不能直接出透明图。前景层、小道具都先在纯白底上生成（加 `simple background, white background`），再用 NovelAI 的去背景工具或 rembg 抠掉。房间图的窗户玻璃，先让它画成一片纯色夜空，抠图时一起挖掉。

## 二、画风串（每张都带）

### 正向

```
best quality, very aesthetic, absurdres, no humans, scenery,
faux traditional media, watercolor (medium), colored pencil (medium), ink (medium), lineart,
flat color, muted color, pastel colors, soft lighting, warm lighting,
storybook illustration, picture book, cozy, clean lines, smooth shading
```

- 用 `faux traditional media`（仿手绘的数码画），比 `traditional media`（真实手绘扫描）噪点少、画面干净。想要更多纸感，再把 `traditional media` 加回来。
- `storybook illustration, picture book` 不是 Danbooru 标签。NovelAI V4 以后能理解自然语言，留着有帮助；SD 系模型里可以删掉。

### 反向（专门压噪点）

```
lowres, worst quality, bad quality, jpeg artifacts, noise, film grain, dithering, chromatic aberration,
blurry, oversaturated, high contrast, 3d, realistic, photorealistic, text, watermark, signature, logo, frame
```

## 三、画师串（待你实测）

Danbooru 有防爬验证，姐姐没能逐个核实下面这些标签的拼写和作品数量，**先当候选**。在 NovelAI 输入框里打 `artist:` 加名字，会自动补全并显示作品数：补全不出来、或数量很少的，就是模型不认识，换下一个。

| 方向 | 画师串（NovelAI 写法） | 想要的效果 |
|---|---|---|
| A 平涂绘本，干净墨线 | `artist:mochizuki kei, artist:toi8` | 线条利落、颜色平、低饱和，最接近现在的绘本版 |
| B 柔和水彩 | `artist:shiratama (shiratamaco), artist:hiten (hitenkei)` | 颜色更通透、边缘柔，适合月光和台灯的氛围 |
| C 可爱童趣 | `artist:ningen mame, artist:kazuharu kina` | 物件更圆润可爱，适合终章的小道具 |

- **调权重**：NovelAI V4 以后写 `1.2::artist:toi8::`（大于 1 加强，小于 1 减弱）；老写法 `{artist:toi8}` 也能用，每层花括号约加强 5%。
- **混合**：两三个画师一起写，会互相调和。每次只换一个，比较着看。
- **画风标签放前面**：画师串和第二节的画风串一起放在提示词开头，场景标签放后面。

## 四、各张图的场景标签

每张的完整提示词 = 第二节画风串 + 第三节挑定的画师串 + 下面的场景标签。

### `room-back`：卧室

```
indoors, bedroom, night, wide shot, straight-on, from front,
arched window, night sky, crescent moon, curtains, window seat, cushion, pillow,
bookshelf, book, stuffed toy, jar, potted plant, wall clock,
canopy bed, bed, blanket, leaf print, wallpaper, wooden floor, rug, string lights,
green theme, cream walls, leaf motif
```

补一句自然语言（NovelAI V4 以后可以直接写在标签后面）：`the clock face is blank with no hands, the middle of the window seat is empty`。

### `room-front`：书桌近景

```
close-up, desk, from front, straight-on, table lamp, lampshade, book stack, mug, steam,
potted plant, sprout, radio, antenna, desk mat, leaf, hanging plant, monstera,
still life, simple background, white background
```

补一句：`a phone lying on the desk sees this view, objects are large in the foreground, nothing above the desk except the lamp and leaves hanging into the top corners`。

### `room-girl`：她的影子（可选）

```
1girl, solo, silhouette, sitting, from front, long hair, side ponytail, hair ornament, leaf hair ornament,
faceless, no eyes, blurry, soft focus, purple theme, simple background, white background
```

这张要把画风串里的 `no humans, scenery` 去掉。

### `note-bubble`：音符气泡

```
no humans, bubble, musical note, eighth note, sparkle, simple background, white background, object focus, still life
```

### 终章六个小物件

通用部分：`no humans, object focus, still life, simple background, white background, centered`，再接：

| 文件名 | 场景标签 |
|---|---|
| `plugin-tavern` | `sign, hanging sign, wooden sign, beer mug, foam, leaf` |
| `plugin-search` | `magnifying glass, sparkle, leaf` |
| `plugin-brush` | `palette (object), paintbrush, paint` |
| `plugin-record` | `record, vinyl record, musical note` |
| `plugin-diary` | `book, diary, closed book, bookmark, ribbon, leaf` |
| `plugin-chest` | `treasure chest, gold, sparkle, leaf` |

## 五、SD 系写法差异

- 画师不加 `artist:` 前缀，直接写名字，括号要转义：`shiratama \(shiratamaco\)`。
- 权重写成 `(toi8:1.2)`。
- 去掉 `storybook illustration, picture book` 这类自然语言，Illustrious 和 NoobAI 只认标签。
- 质量词按所用模型的说明来，如 NoobAI 常用 `masterpiece, best quality, newest, absurdres, highres`。
