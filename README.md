# AIcove

**一个会主动想你、记得你、能说话也能画画的 AI 陪伴应用**

[下载最新测试版](https://github.com/kuobibulaien/AIcove/releases) · Android · macOS (Apple Silicon)

</div>

---

AIcove 不是又一个「你问一句、它答一句」的聊天框。你在这里创建自己的角色，给 TA 设定人设、声音和画风；之后 TA 会用文字、语音、图片和表情包回应你，记住你们聊过的事，还会在合适的时候主动来找你。

所有聊天数据默认只存在你自己的设备上，模型用你自己的 API Key 直接调用，不经过任何中转服务器。

> 当前为公开测试版（预发布），功能仍在快速迭代。测试重要资料前请先做好备份。

## 特色功能

### 💌 主动关怀：TA 会先来找你

大多数 AI 只会被动回复。AIcove 的角色可以自己决定什么时候联系你：

- 早上发一句早安，深夜说一声晚安
- 你说「去开会了」，两小时后 TA 会问「会开完了吗？」
- 基于时间、聊天内容和你设定的规则触发，AI 用工具调用安排下一次关心

每个角色单独开关，Android 上支持后台常驻，App 关着也能收到消息。

### 🎙️ 多模态消息：会说话、会画画、会发表情

AI 在一条回复里可以自然地混合多种内容：

| 能力 | 说明 |
|---|---|
| **语音** | 角色用自己的声音说话，支持硅基流动、阿里云、MiniMax 等语音服务，可克隆专属音色 |
| **绘图** | 聊到兴头上直接画一张，支持 OpenAI 兼容接口、NovelAI、ComfyUI 自定义工作流 |
| **表情包** | AI 按语境挑选合适的表情包，也可以导入自己的表情包 |
| **时间感知** | 知道现在几点、离上次聊天过去多久，回复更像真实的人 |

每个角色可以绑定自己的语音预设和绘图预设：甜妹配甜嗓，画风也跟着人设走。

### 🧠 长期记忆：聊得越久，越懂你

- **短期记忆**：聊天太长时自动压缩旧内容腾出空间，也可以手动「翻篇」开始新话题
- **长期记忆**：每个角色有独立记忆库，后台的记忆整理助手会把重要的事（你的喜好、经历、约定）整理成档案，以后聊天时按需想起
- 原始聊天记录始终完整保留，记忆只是从原文整理出来的，不会篡改历史

### 🍺 酒馆生态兼容

玩过 SillyTavern 的朋友可以直接带着家当搬过来：

- 导入**酒馆角色卡**，一键创建角色
- 导入**预设**、**正则**、**世界书**，每一条都能单独开关
- 预设里的折叠段、选项标签会被识别成对应的界面组件：思考过程可折叠，`<options>` 选项答完自动弹出，点一下填进输入框
- 支持部分带脚本的高级预设（在独立沙盒中运行，不碰你的其它数据）

### 🔁 局域网直连同步：不用账号，手机电脑互通

- 同一 Wi-Fi 下扫码或输入配对码，手机和电脑就能互相同步聊天、角色与设置
- 无需注册云账号，数据不出你的局域网，设备之间认证加密
- 图片等附件支持断点续传

另有云同步（测试中）和离线导入导出备份可选。

### 💬 好用的聊天体验

- **多家模型随意切换**：OpenAI、Claude、Gemini、DeepSeek、MiniMax、智谱及各种 OpenAI 兼容接口；同一渠道可配多个 Key
- **思考档位**：按会话调节模型的思考深度，三家主流接口自动翻译成各自的参数
- **气泡 / 文档两种样式**：日常聊天用气泡，长文创作切成全宽 Markdown 文档模式
- **自然分段**：长回复像真人一样拆成几条消息发出，代码块和图片不会被切断
- **编辑与重新生成**：改写自己发过的消息、对不满意的回复重新生成
- **聊天记录分享**：选几条对话生成好看的长图，或转发给另一个角色让 TA 评价

### 📱 一套界面，手机电脑都顺手

- 手机上是熟悉的聊天应用布局；电脑宽屏时左边是完整的手机界面，右边展开详情，像 Telegram 桌面版一样
- 可换皮肤、自定义主题色、毛玻璃效果和聊天背景

## 快速上手

1. 打开 App，进入 **设置 → 模型**，添加你的模型渠道和 API Key
2. 新建一个角色，写下 TA 的人设；或者直接**导入酒馆角色卡**
3. 在角色设置里勾选想要的插件（语音、绘图、表情包、主动关怀、记忆库……）并选好预设
4. 开始聊天吧

## 隐私

- 聊天记录、角色和记忆都保存在本地数据库里
- 模型请求从你的设备直接发往你配置的服务商，AIcove 不收集、不中转
- 局域网同步只在你配对过的设备之间进行；云同步为可选功能
