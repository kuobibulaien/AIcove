功能清单
功能	说明
导出界面	选择 Scope（角色卡/聊天记录/设置等） → 选择角色 → 导出
导入界面	选择文件 → 预览内容 → 选择 Scope → 冲突时弹窗询问（合并/新建）
聊天预览	点击角色 → 只读聊天记录界面
