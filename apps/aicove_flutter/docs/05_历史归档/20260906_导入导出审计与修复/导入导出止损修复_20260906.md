## 当前明确限制

1. **memory 和供应商范围仍未实现，选中就明确拒绝操作。** 不再写一个假的“包含 memory”清单。UI 暂未重做能力开关；需要取消不支持项，不能把此止损误认为记忆备份已补齐。
2. 合并已有角色仍保留其本地卡/设置，完整字段、raw_payload/补图、MD/旧记忆、话题摘要与边界、预设依赖未补齐。新插件预设架构的完整绑定需在下一批统一设计，不能只导音色/预设 ID 就宣称可恢复。
3. 旧包中的设备绝对附件路径和缺失 files 引用现在会拒绝，而不是导入一个坏链接；新包中被排除/未打包的消息本地路径会移除。附件完整性告警、资源清单与旧包修复工具仍待后续。
4. 目前限制压缩包 256 MiB、声明解压总量 512 MiB、条目 10000；这是预检保护，不是流式内存上限，也未完成恶意高压缩率负载测试。全量 ZIP/JSON 仍在内存处理，事务中文件复制会延长数据库占用时间。
5. 进程崩溃/断电、清理失败、真实 Downloads/分享权限和多设备导入未实测。正常异常清理失败最多留下本次孤立目录；不承诺零孤立文件或断电级文件/DB 联合原子性。替换模式仍仅服务层可达，UI 没有新增危险按钮。
