## 每批交付门槛

1. 保存目标文件当前工作树快照及本批补丁，不从HEAD恢复或覆盖其它任务改动。
2. 对应故障测试转绿，关键对照通过，末项实际可操作、设置/存储值正确；回归受影响既有测试。
3. 相关静态分析与完整本批diff检查；按项目规则pub get、flutter run --no-resident及窄宽屏验证。真实中文字体、键盘、安全区、拖动、媒体需运行界面证据。
4. 不混入依赖升级、目录大迁移、数据库迁移或生产操作。跨页面修复按项目确认规则进入实施。

## 后续关键验证

旧分页影响新分页标志、工具提示词保存晚回调及失败收起、全局缩放与嵌套导航坐标、大列表帧耗时、损坏媒体回退。这些候选未计入43项。

故障测试数量不是独立问题数，局部源码检查不是测试覆盖率。本清单提供整改范围，不表示修复完成，也不承诺已发现全部隐藏bug。
