## 4. 图片

确认存在的问题：

- character_list_item.dart:91 头像容器为 56×56，217 行调用 AvatarHelper.buildAvatarWidget。
- core/utils/avatar_helper.dart:149 使用 Image.memory，154 网络图、170 asset、179 本地文件路径都未设置缩小解码参数。getAvatarProvider 同样返回原图 provider，联系人预热也沿用此路径。
- 新测试生成纯合成 2048×2048 PNG，实际布局 56×56，解析 ImageStream 得到的 raster 仍为 2048×2048。RGBA 4 字节/像素估算约 16 MiB/张，仅是像素数据量估算，不是手机 GPU 实测，也不含其他缓存副本。
- horizontal_role_card.dart:306 使用同一公共 helper；展示尺寸需求不同，后续应根据用途传入目标尺寸，不能全局把原图/全屏预览强制缩成头像。

已保护的路径：message_bubble.dart:635/645/658 对本地、网络、base64 聊天照片传入目标宽度；1029 行起聊天头像也有缩小解码。base64 字节有 data_image.dart 中的容量受限 LRU 缓存，不应误报为所有图片每次 build 都重新 base64 解码。

图片设置 width/height 只约束显示，cacheWidth/cacheHeight 才指示解码目标尺寸；网络磁盘缓存本身不等于缩小内存位图。来源：[Flutter Image API](https://api.flutter.dev/flutter/widgets/Image-class.html)。
