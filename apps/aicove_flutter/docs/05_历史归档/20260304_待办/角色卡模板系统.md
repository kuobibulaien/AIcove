# 角色卡模板系统

## 背景

重构后删除了独立的"预设管理页面"（废弃的 `preset_management_page.dart`、`character_preset.dart`、`preset_store.dart`），将模板功能整合到现有的角色卡系统中。

## 核心概念

- **收藏** = 放入"我的角色卡"
- **"我的角色卡"** = 模板库（收藏的角色卡作为模板使用）
- **新建角色时可以从模板导入**

## 编辑入口

### 入口1：聊天页内编辑
**路径**：聊天页 → 右上角 → 聊天设置 → 编辑角色信息

- 进入 `ContactEditPage` 编辑当前对话的角色
- 编辑完成后，AppBar 显示：
  - **保存**（覆盖当前角色）
  - **保存为新角色卡**（创建新角色到"我的角色卡"）

### 入口2：从"我的角色卡"编辑
**路径**：角色卡页面 → 我的角色卡分类 → 点击某张角色卡

- 进入 `ContactEditPage` 编辑模板
- 编辑完成后，AppBar 显示：
  - **直接保存**（更新模板）
  - **保存为新角色卡**（基于模板创建新角色卡）

## 新建角色时的模板选择

**路径**：角色卡页面 → "定制角色卡" → 新建页面

- 新建页面增加"从模板导入"入口
- 点击后弹出底部弹窗，列出"我的角色卡"中的所有模板
- 选择后预填充角色信息，用户可修改后保存

## 数据流

```
┌─────────────────┐      收藏       ┌─────────────────┐
│   普通角色卡     │ ─────────────→ │  我的角色卡     │
│  (Conversation)  │               │  (模板库)        │
└─────────────────┘               └─────────────────┘
                                          │
                                          │ 从模板导入
                                          ▼
                                  ┌─────────────────┐
                                  │   新建角色卡     │
                                  │ (预填充信息)    │
                                  └─────────────────┘
```
