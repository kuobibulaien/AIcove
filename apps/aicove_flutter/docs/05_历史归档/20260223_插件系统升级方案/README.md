## 🚀 最新进度 (2026-01-06)

### ✅ 已完成：Context Injection & Multimedia Support

| 特性 | 说明 |
|-----|------|
| **PluginContext** | 插件可感知对话上下文，并主动发送消息 |
| **PluginContent** | 插件可返回多媒体内容：图片、音频、UI组件 |

## 🚀 快速了解

### 这次升级做什么？

| 特性 | 现状 | 升级后 |
|-----|------|--------|
| **元数据** | 只有 id、name、description | 完整信息：版本、作者、配置模板等 |
| **生命周期** | 无 | 4 个钩子：初始化、启用、禁用、销毁 |
| **功能注册** | 无 | 命令、AI 工具、LLM 钩子的统一注册 |
| **配置管理** | 每个插件自己写 UI | 根据配置模板自动生成 UI |
| **上下文** | 无 | 插件可感知对话上下文并主动操作 |
| **多媒体** | 只能返回文本 | 可返回图片、音频、UI组件 |

### 对现有代码的影响

- `plugin.dart`：需要改造，添加新接口
- `plugin_manager.dart`：需要改造，支持生命周期
- 现有插件（如 TTS）：需要适配新接口，但核心逻辑不变
