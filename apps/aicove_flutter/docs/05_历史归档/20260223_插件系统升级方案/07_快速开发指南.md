# 插件开发快速指南

> 基于新的插件系统架构，快速创建一个新插件

---

## 🚀 5 分钟创建一个插件

### 1. 创建插件类，继承 BasePlugin

```dart
import 'package:flutter/material.dart';
import '../domain/index.dart';

class WeatherPlugin extends BasePlugin {
  // 1. 定义元数据（包含配置模板）
  static final _metadata = PluginMetadata(
    id: 'com.aicove.weather',
    name: '天气插件',
    description: '查询实时天气信息',
    version: '1.0.0',
    author: 'AIcove Team',
    icon: Icons.wb_sunny,
    configSchema: {
      'apiKey': ConfigField(
        type: ConfigFieldType.string,
        label: 'API 密钥',
        description: '天气API的密钥',
        required: true,
      ),
      'city': ConfigField(
        type: ConfigFieldType.string,
        label: '默认城市',
        defaultValue: '北京',
      ),
    },
  );

  // 2. 构造函数
  WeatherPlugin() : super(metadata: _metadata);

  // 3. 实现必需方法
  @override
  Future<String?> getSystemPrompt({String? userMessage}) async {
    return '你可以通过调用 get_weather 工具查询天气';
  }

  @override
  Future<PluginProcessResult> processResponse(String text) async {
    return PluginProcessResult(processedText: text, events: []);
  }

  // 4. (可选) 提供 AI 工具
  @override
  List<AITool> getTools() => [
    AITool(
      name: 'get_weather',
      description: '获取指定城市的实时天气',
      parameters: {
        'city': ToolParameter(
          type: 'string',
          description: '城市名称',
          required: true,
        ),
      },
      handler: (args) async {
        final city = args['city'] as String;
        // 调用天气API
        return '${city}的天气：晴，25°C';
      },
    ),
  ];

  // 5. (可选) 生命周期钩子
  @override
  Future<void> onInitialize() async {
    await super.onInitialize();
    debugPrint('[WeatherPlugin] 初始化完成');
  }

  @override
  Future<void> onDestroy() async {
    // 清理资源
    await super.onDestroy();
  }
}
```

### 2. 注册插件

```dart
// 在 PluginManager 中注册
final pluginManager = PluginManager();
pluginManager.register(WeatherPlugin());

// 初始化所有插件
await pluginManager.initializeAll();
```

### 4. 集成到 AI 对话流程

```dart
// 发送消息时，自动收集工具
final toolCollector = AIToolCollector(pluginManager);
final tools = toolCollector.toOpenAIFormat(); // 或 toAnthropicFormat()

// 发送请求
final response = await llmClient.sendMessage(
  systemPrompt: await pluginManager.getSystemPrompts(userMessage: message),
  messages: conversationHistory,
  tools: tools, // 包含 get_weather 工具
);

// AI 决定调用工具时
if (response.toolCalls != null) {
  final results = await toolCollector.executeTools(
    response.toolCalls!.map((call) => ToolCallRequest.fromOpenAI(call)).toList(),
  );
  
  // 将工具结果传回 AI
  for (final result in results) {
    conversationHistory.add(result.toOpenAIMessage());
  }
}
```

## 📚 核心概念

### PluginMetadata - 插件元数据

包含插件的身份信息和配置模板：

- `id`: 唯一标识（建议用反向域名）
- `name`: 显示名称
- `version`: 版本号
- `configSchema`: 配置项定义（**自动生成UI的关键**）

### ConfigField - 配置字段

定义一个配置项：

```dart
ConfigField(
  type: ConfigFieldType.select,
  label: '语音类型',
  options: ['甜美女声', '磁性男声'],
  defaultValue: '甜美女声',
)
```

支持的类型：
- `string`: 文本输入框
- `integer`: 整数输入框
- `number`: 数字输入框（含小数）
- `boolean`: 开关
- `select`: 下拉选择
- `multiSelect`: 多选复选框

### AITool - AI 工具

让 AI 可以调用你的插件功能：

```dart
AITool(
  name: 'search_web',
  description: '搜索互联网',
  parameters: {
    'query': ToolParameter(type: 'string', description: '搜索关键词'),
  },
  handler: (args) async {
    return await searchAPI(args['query']);
  },
)
```

自动转换为 OpenAI 或 Anthropic 的 Function Calling 格式。

### 生命周期钩子

- `onInitialize()`: App 启动 / 插件安装 → 加载配置、初始化资源
- `onEnable()`: 用户启用插件 → 开始工作
- `onDisable()`: 用户禁用插件 → 暂停工作
- `onDestroy()`: App 退出 / 插件卸载 → 释放资源
- `onConfigChanged(newConfig)`: 用户修改配置 → 应用新配置

## 🎯 实用示例

### 示例1：提供命令

```dart
@override
List<CommandHandler> getCommands() => [
  CommandHandler(
    command: '/weather',
    description: '查询天气',
    handler: (args) async {
      final city = args.isNotEmpty ? args[0] : '北京';
      return await _getWeather(city);
    },
  ),
];
```

用户输入 `/weather 上海` → 插件返回天气信息

### 示例2：注入上下文

```dart
@override
List<LLMHook> getHooks() => [
  LLMHook(
    type: LLMHookType.beforeRequest,
    handler: (context) async {
      if (context is LLMRequestContext) {
        final weather = await _getCurrentWeather();
        context.appendSystemPrompt('当前天气：$weather');
      }
    },
  ),
];
```

每次 AI 请求前，自动注入当前天气信息。

### 示例3：处理响应

```dart
@override
Future<PluginProcessResult> processResponse(String text) async {
  final events = <PluginEvent>[];
  
  // 解析 <weather>城市</weather> 标签
  final regex = RegExp(r'<weather>(.*?)</weather>');
  for (final match in regex.allMatches(text)) {
    final city = match.group(1)!;
    events.add(PluginEvent(
      pluginId: id,
      type: 'weather_query',
      data: {'city': city},
    ));
  }
  
  return PluginProcessResult(
    processedText: text.replaceAll(regex, ''),
    events: events,
  );
}
```

## ✅ 最佳实践

1. **用反向域名作为 id**：`com.yourteam.pluginname`
2. **配置模板要完整**：提供 `description`、`defaultValue`，方便用户理解
3. **生命周期钩子正确清理资源**：避免内存泄漏
4. **AI 工具的 description 要详细**：AI 根据描述决定是否调用
5. **错误处理要完善**：单个插件出错不应影响其他插件
