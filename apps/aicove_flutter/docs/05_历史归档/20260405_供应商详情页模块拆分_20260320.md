# 供应商详情页模块拆分记录

日期：2026-03-20

## 背景

`lib/src/ui/features/settings/pages/provider_detail_page.dart` 之前同时承载了：

- 页面骨架与 Tab UI
- 表单自动保存
- 供应商编辑动作
- 多 Key 规则与数据转换
- 多 Key 管理子页面

单文件体量超过 2000 行，已经偏离“UI 不直接承载复杂业务规则”的项目约束。

## 本次拆分

### 1. 模块纯逻辑抽离

新增：

- `lib/src/features/settings/provider_detail/provider_detail_support.dart`
- `lib/src/features/settings/provider_detail/provider_detail_actions.dart`

职责：

- `provider_detail_support.dart`
  - 请求格式解析
  - Vertex Express 判定
  - 多 Key 条目模型
  - 多 Key 配置序列化 / 反序列化
- `provider_detail_actions.dart`
  - 供应商详情模块的动作门面
  - 自动保存、测试模型、切换多 Key、切换 Vertex、模型排序等统一入口

### 2. 多 Key 子页面拆出主文件

新增：

- `lib/src/ui/features/settings/pages/multi_key_manager_page.dart`

拆出内容：

- `MultiKeyManagerPage`
- 多 Key 表单 sheet
- 多 Key 列表行组件

### 3. 主页面收瘦

保留在 `provider_detail_page.dart` 的内容：

- 页面路由壳
- 顶部信息区
- 配置 / 模型两个 Tab 的组装
- 连接测试弹层
- 底部操作栏

拆分后主文件行数约从 2046 行降到 1021 行。
