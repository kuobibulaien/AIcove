# 聊天界面功能增强

> 更新日期：2026-02-27

## 1. 消息长按操作菜单

### 功能描述
长按消息气泡，在消息上方弹出悬浮气泡菜单（类似 QQ/微信），提供以下操作：

| 操作 | 说明 | 适用消息 |
|------|------|----------|
| **复制** | 复制消息文本到剪贴板 | 所有消息 |
| **引用** | 引用该消息进行回复 | 所有消息 |
| **编辑** | 撤回消息到输入框重新编辑，发送后覆盖后续历史 | 用户消息 |
| **重新生成** | 删除当前 AI 回复并重新请求生成 | AI 消息 |
| **增强生成** | 用“增强上下文”重新生成当前 AI 回复（仅在调试开关开启时显示） | AI 消息 |

### 技术实现

#### 公共组件：MoePopupMenu
📄 `lib/src/ui/shared/widgets/menus/moe_popup_menu.dart`

- 使用 `Overlay` + `OverlayEntry` 实现，不会抢夺输入焦点（避免输入法收回）
- 带三角形箭头指向目标消息
- 自动计算位置（优先上方，空间不足则下方）
- 淡入淡出 + 缩放动画

**使用方式：**
```dart
MoePopupMenu.show(
  context,
  targetKey: bubbleKey,  // 目标元素的 GlobalKey
  items: [
    MoePopupMenuItem(icon: Icons.copy, label: '复制', onTap: () {}),
    MoePopupMenuItem(icon: Icons.edit, label: '编辑', onTap: () {}),
  ],
);
```

#### 相关文件
| 文件 | 职责 |
|------|------|
| `moe_popup_menu.dart` | 悬浮气泡菜单公共组件 |
| `message_action_sheet.dart` | 消息操作菜单（调用 MoePopupMenu） |
| `message_bubble.dart` | 消息气泡（添加 onLongPress 回调） |
| `chat_message_list.dart` | 消息列表（处理长按事件） |
| `chat_actions.dart` | 聊天业务逻辑（regenerate、editMessage 方法） |

## 2. 引用回复功能

### 功能描述
用户可以引用某条消息进行回复，让 AI 知道用户是针对哪条消息回复的。

### 使用流程
1. 长按消息 → 点击「引用」
2. 输入框上方显示引用预览（蓝色竖线 + 内容摘要 + 关闭按钮）
3. 输入回复内容并发送
4. 消息会附加引用前缀 `> 引用「...」`

### 技术实现

#### 数据流
```
quotedMessageProvider (StateProvider<QuotedMessage?>)
    ↓
Composer 监听并显示预览
    ↓
发送时附加引用前缀，清空 Provider
```

#### 相关文件
| 文件 | 改动 |
|------|------|
| `chat_actions.dart` | 添加 `QuotedMessage` 类和 `quotedMessageProvider` |
| `composer.dart` | 添加 `_buildQuotedMessagePreview()` 显示引用预览 |
| `chat_page.dart` | 发送时检查引用消息并附加前缀 |

## 3. 界面设置：隐藏用户头像

### 功能描述
在界面设置中添加「隐藏用户头像」选项，开启后用户消息气泡将贴着屏幕右边缘。

### 设置路径
设置 → 界面设置 → 聊天界面 → 隐藏用户头像

### 技术实现

#### 数据流
```
AppSettings.hideUserAvatar
    ↓
ui_settings_page.dart (开关控件)
    ↓
message_bubble.dart (条件渲染用户头像)
```

#### 相关文件
| 文件 | 改动 |
|------|------|
| `settings_models.dart` | 添加 `hideUserAvatar` 字段 |
| `app_settings.dart` | 添加解析和 `setHideUserAvatar` 方法 |
| `ui_settings_page.dart` | 添加「聊天界面」设置卡片 |
| `message_bubble.dart` | 根据设置条件渲染用户头像 |

## 5. 增强生成（增强对话）

### 功能描述
当对话出现“人设漂移”时，可以对某条 AI 回复使用“增强生成”：

1. 用调试中心配置的**增强系统提示词**覆盖本轮辅助策略
2. 在上下文最前插入一条**任务派发消息**（第一条用户消息）
3. 只携带**最近 N 轮**（默认 3 轮，可配置）进行重新生成
4. 若模型按约定输出 `<enhance>...</enhance>`，会只提取标签内部文本回填到当前会话

> 增强生成仍复用正常发送链路，工具调用与多模态能力保持不变；只改变本轮上下文拼接方式。

### 设置路径
设置 → 调试中心 → 增强对话

### 相关文件
| 文件 | 职责 |
|------|------|
| `lib/src/ui/features/debug/pages/enhanced_dialogue_page.dart` | 调试中心配置页（开关、系统提示词、第一条用户消息、最近轮数） |
| `lib/src/features/settings/settings_models.dart` | 增强对话配置模型 `EnhancedDialogueSettings` |
| `lib/src/features/settings/app_settings.dart` | 设置读写映射与持久化更新方法 |
| `lib/src/features/settings/ui_models_api.dart` | 本地存储默认值与规范化逻辑 |
| `lib/src/features/chat/presentation/widgets/message_action_sheet.dart` | 消息菜单新增“增强生成”操作 |
| `lib/src/ui/features/chat/widgets/chat_message_list.dart` | 菜单点击分发与开关可见性控制 |
| `lib/src/features/chat/data/enhanced_dialogue_service.dart` | 增强上下文拼接与 `<enhance>` 标签提取 |
| `lib/src/features/chat/chat_actions.dart` | 增强重生成入口与发送链路接入 |

## 6. 手势触发的自动回底保护（新增 2026-02-27）

### 功能描述
当用户在消息列表中主动上滑或下滑（表示正在翻看历史）时：

1. 立即暂停“新消息自动回到底部”
2. 本轮 AI 连续回复不会再把画面强行拉回底部
3. 只有当用户再次发送消息（文本/图片/文件）后，才恢复自动回底

### 相关文件（功能 ↔ 文件）

| 文件 | 职责 |
|------|------|
| `lib/src/ui/features/chat/widgets/chat_message_list.dart` | 消息列表滚动控制：识别用户手势、锁定自动回底、保持当前阅读位置、接收恢复令牌 |
| `lib/src/ui/features/chat/pages/chat_page.dart` | 聊天发送入口：用户发送文本/图片/文件时，递增恢复令牌，通知消息列表恢复自动回底 |
| `test/ui/features/chat/widgets/chat_message_list_auto_scroll_guard_test.dart` | 行为测试：覆盖“手势后不回底”和“用户发送后恢复回底”两个场景 |
