# 04 预生成机制

> 本文档描述内容预生成与上下文隔离的实现细节

---

## 为什么需要预生成？

### 问题场景

```
晚上 10:30 - 用户说"我去睡了"
早上 8:00 - 触发器触发，需要发"早安"

如果这时候才调用 AI 生成内容：
1. 需要等待 API 响应（1-3 秒）
2. 可能 API 超时/失败
3. 消息会有延迟感
```

### 预生成的好处

```
晚上 10:30 - 用户说"我去睡了"
晚上 10:31 - 后台预生成"早安呀~昨晚睡得好吗？"并缓存
早上 8:00 - 触发器触发，直接发送缓存内容（毫秒级）
```

```
                              │
                              ▼

                              │

│ 2. 构建预生成请求                                                │
│    - 使用独立 session ID（不污染聊天）                           │
│    - 注入 Proactive System Prompt                               │
│    - 附加角色设定                                                │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│ 3. 调用 AI 生成内容                                              │
│    - 不使用工具（纯文本生成）                                     │
│    - 温度适当调高（0.7-0.8）增加自然感                           │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│ 4. 保存预生成结果                                                │
│    - 存入 cachedContent                                         │
│    - 记录 preparedAt 时间                                       │
│    - 更新状态为 prepared                                         │
└─────────────────────────────────────────────────────────────────┘
```

## 上下文隔离

### 为什么需要隔离？

如果预生成使用聊天的 session，会导致：

```
聊天历史：
  用户: 我去睡了
  AI: 晚安~
  [预生成请求] 系统: 请生成早安消息  ← 这会污染历史！
  AI: 早安呀~

下次用户发消息，AI 会看到上面的预生成请求，很奇怪。
```

### 隔离策略

使用独立的 session ID：

```dart
// 聊天 session - 保持连续
final chatSessionId = 'conv_${conversation.id}';

// 预生成 session - 每个触发器独立，用完即弃
final proactiveSessionId = 'proactive_${trigger.id}_${DateTime.now().millisecondsSinceEpoch}';
```

## Proactive System Prompt 设计

预生成时需要告诉 AI：
1. 这不是用户发的消息
2. 你要主动发起对话
3. 不要用被动语气

### 模板

```dart
String buildProactiveSystemPrompt({
  required String characterName,
  required String addressUser,
  required String triggerTitle,
  required String? triggerPrompt,
  required DateTime triggerTime,
}) {
  return '''
[PROACTIVE_MESSAGE_GENERATION]
你现在要生成一条主动发送的消息，而不是回复用户。

角色：$characterName
对用户的称呼：$addressUser
触发原因：$triggerTitle
预计发送时间：${_formatTime(triggerTime)}
${triggerPrompt != null ? '指导提示：$triggerPrompt' : ''}

要求：
1. 以 $characterName 的身份主动发起对话
2. 语气自然，像是你自己想起来要联系用户
3. 不要使用被动语气（如"好的"、"收到"、"明白"）
4. 不要提及"触发器"、"提醒"、"系统"等元信息
5. 根据触发原因和对话上下文，生成合适的开场白

只输出消息内容本身，不要有任何解释或前缀。
[/PROACTIVE_MESSAGE_GENERATION]
''';
}
```

### 示例

**输入**：
```
角色：阿洛娜
触发原因：早安问候
指导提示：用户昨晚说去睡觉了，请温柔地说早安
```

**期望输出**：
```
早安呀老师~昨晚睡得好吗？今天也要加油哦！
```

**错误输出**（不应该出现）：
```
好的，我来发送早安消息：早安呀老师~
```

## 预生成代码实现

### 1. 保存上下文快照

```dart
/// 创建上下文快照
String _createContextSnapshot(Conversation conversation, int messageLimit) {
  final recentMessages = conversation.messages.length > messageLimit
      ? conversation.messages.sublist(conversation.messages.length - messageLimit)
      : conversation.messages;

  final snapshot = {
    'conversation_id': conversation.id,
    'character_name': conversation.title,
    'address_user': conversation.addressUser ?? '用户',
    'messages': recentMessages.map((m) => {
      'role': m.role, // 'user' | 'assistant'
      'content': m.displayText, // 只取文本摘要（多模态用占位符/摘要）
      'timestamp': m.createdAt.toIso8601String(),
    }).toList(),
    'snapshot_at': DateTime.now().toIso8601String(),
  };

  return jsonEncode(snapshot);
}
```

### 2. 执行预生成

```dart
/// 预生成主动消息内容
Future<void> prepareProactiveContent(AutoReplyTrigger trigger) async {
  try {
    // 1. 更新状态
    await _updateStatus(trigger.id, AutoReplyTriggerStatus.preparing);

    // 2. 解析上下文快照
    final snapshot = jsonDecode(trigger.contextSnapshot!);
    final messages = (snapshot['messages'] as List)
        .map((m) => {
          'role': m['role'],
          'content': m['content'],
        })
        .toList();

    // 3. 构建 Proactive System Prompt
    final proactivePrompt = buildProactiveSystemPrompt(
      characterName: snapshot['character_name'],
      addressUser: snapshot['address_user'],
      triggerTitle: trigger.title,
      triggerPrompt: trigger.prompt,
      triggerTime: trigger.nextFireAt,
    );

    // 4. 获取角色设定
    // 工程里角色设定通常来自 Conversation.personaPrompt
    // （可通过 conversationsProvider 从 conversationId 找到会话）
    final characterPrompt = await _getPersonaPrompt(trigger.conversationId);

    // 5. 组装完整系统提示词
    final systemPrompt = '$characterPrompt\n\n$proactivePrompt';

    // 6. 调用 AI（使用独立 session）
    final sessionId = 'proactive_${trigger.id}_${DateTime.now().millisecondsSinceEpoch}';

    // 6.1 选择模型/Provider（建议复用 ChatRequestBuilder.resolveProviderConfig）
    final settings = await _ref.read(appSettingsProvider.future);
    final providerConfig = await ChatRequestBuilder(_ref).resolveProviderConfig(settings);

    // 6.2 调用 AI（不需要 tools，因此用 sendMessage 即可）
    final response = await _agent.sendMessage(
      agentId: 'proactive_generator',
      sessionId: sessionId,
      modelFullId: providerConfig.modelFullId,
      messages: [
        {'role': 'system', 'content': systemPrompt},
        ...messages,
      ],
      userText: '', // 空的用户消息，因为这是主动发送
      temperature: 0.8, // 稍高的温度增加自然感
      token: settings.backendApiKey,
      providerApiBase: providerConfig.providerApiBase,
      providerApiKey: providerConfig.providerApiKey,
    );

    // 7. 保存结果
    await _updateTrigger(
      trigger.id,
      status: AutoReplyTriggerStatus.prepared,
      cachedContent: response.trim(),
      preparedAt: DateTime.now(),
    );

    AppLogger.info('TriggerController', '预生成完成', metadata: {
      'triggerId': trigger.id,
      'contentLength': response.length,
    });

  } catch (e) {
    AppLogger.error('TriggerController', '预生成失败', metadata: {
      'triggerId': trigger.id,
      'error': e.toString(),
    });

    // 预生成失败，降级为 pending（触发时实时生成）
    await _updateStatus(trigger.id, AutoReplyTriggerStatus.pending);
  }
}
```

### 3. 触发时使用预生成内容

```dart
/// 发送主动消息
Future<void> sendProactiveMessage(AutoReplyTrigger trigger) async {
  String content;

  if (trigger.hasCachedContent) {
    // 使用预生成内容
    content = trigger.cachedContent!;
    AppLogger.info('ChatActions', '使用预生成内容发送');
  } else {
    // 实时生成（降级方案）
    content = await _generateProactiveContentRealtime(trigger);
    AppLogger.info('ChatActions', '实时生成内容发送');
  }

  // 创建消息并发送
  final msgId = genId('msg');
  final message = Message.text(
    id: msgId,
    role: 'assistant',
    content: content,
    status: 'sent',
  );

  final now = DateTime.now();
  await _ref.read(conversationsProvider.notifier).updateOne(
    trigger.conversationId,
    (c) => c.copyWith(
      messages: [...c.messages, message],
      updatedAt: now,
      lastMessage: message.displayText,
      lastMessageTime: now,
    ),
  );
}
```

## 预生成失败的处理

### 失败场景

1. **网络错误**：API 请求失败
2. **API 限流**：请求过于频繁
3. **超时**：生成时间过长
4. **内容审核**：生成内容被过滤

### 降级策略

```dart
// 预生成失败后，触发器状态变为 pending
// 触发时会尝试实时生成

Future<void> _fireTrigger(AutoReplyTrigger trigger) async {
  // 作废检查...

  if (trigger.hasCachedContent) {
    // 有预生成内容，直接发送
    await _sendCachedContent(trigger);
  } else if (trigger.status == AutoReplyTriggerStatus.pending) {
    // 没有预生成内容，尝试实时生成
    try {
      await _generateAndSendRealtime(trigger);
    } catch (e) {
      // 实时生成也失败，记录日志但不重试
      AppLogger.error('ChatActions', '主动消息发送失败', metadata: {
        'triggerId': trigger.id,
        'error': e.toString(),
      });
      // 标记为 expired（发送失败），避免反复触发
      await _updateStatus(trigger.id, AutoReplyTriggerStatus.expired);
    }
  }
}
```

## 预生成内容的时效性

### 问题

预生成的内容可能会过时：

```
晚上 10:30 - 预生成"早安呀~今天天气不错"
凌晨 3:00 - 天气变了，下起大雨
早上 8:00 - 发送"今天天气不错"（已经不准确了）
```

### 解决方案

1. **避免时效性内容**：在 Proactive System Prompt 中提示 AI 不要提及天气、新闻等时效性信息

```dart
final proactivePrompt = '''
...
注意：不要提及具体的天气、新闻、时事等可能变化的信息。
...
''';
```

2. **设置过期时间**：预生成内容超过一定时间后，触发时重新生成

```dart
bool _isCachedContentStale(AutoReplyTrigger trigger) {
  if (trigger.preparedAt == null) return true;

  final age = DateTime.now().difference(trigger.preparedAt!);
  // 超过 12 小时认为过时
  return age.inHours > 12;
}

Future<void> _fireTrigger(AutoReplyTrigger trigger) async {
  if (trigger.hasCachedContent && !_isCachedContentStale(trigger)) {
    await _sendCachedContent(trigger);
  } else {
    await _generateAndSendRealtime(trigger);
  }
}
```

3. **标记为非时效敏感**：对于"想你了"这类不涉及时效的消息，允许较长的缓存时间

```dart
// 可以在触发器中添加字段
final bool timeSensitive;  // 是否时效敏感

// 或者根据触发类型判断
bool _isCachedContentStale(AutoReplyTrigger trigger) {
  final age = DateTime.now().difference(trigger.preparedAt!);

  // 早安/晚安类型，12小时过期
  if (trigger.title.contains('早安') || trigger.title.contains('晚安')) {
    return age.inHours > 12;
  }

  // 情感类型，24小时过期
  if (trigger.priority == AutoReplyTriggerPriority.low) {
    return age.inHours > 24;
  }

  // 默认 6 小时过期
  return age.inHours > 6;
}
```
