## 项目记忆（AI 协作）

所有 agent 共用的长期记忆在仓库根目录 `docs/项目记忆/`：README 一页纸（总览 / 架构边界 / 当前重点 / 写入规则）、需求日志（用户原话，hook 自动追加）、决策记录、经验教训、术语表。大任务先在对话中确认目标 / 边界 / 验收，完成后把长期有效结论回写到项目记忆，不要把临时过程塞进正式 docs。

## 维护规则

1. 新文档先按 `文档治理规则.md` 落位。
2. 公共组件变更必须更新 `公共组件总览.md`。
3. 核心架构和长期规则同步更新 `docs/项目记忆/`。
4. 过时重构方案移入 `05_历史归档/`。
5. `scratch/`、毕业论文、交付包、参考素材不作为当前项目文档真相源。
