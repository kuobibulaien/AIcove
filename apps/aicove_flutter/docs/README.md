## Trellis 工作流

Trellis 已接入项目根目录：

| 位置 | 用途 |
|---|---|
| `.trellis/spec/` | 长期规范与项目知识 |
| `.trellis/tasks/` | 大任务 PRD、研究、验收 |
| `.trellis/workspace/` | 会话日志与交接 |
| `.agents/skills/` | Codex 可用的 Trellis skills |

大任务建议先在 `.trellis/tasks/` 建任务文档；完成后把长期有效结论提炼回 `.trellis/spec/`，不要把临时过程塞进正式 docs。

## 维护规则

1. 新文档先按 `文档治理规则.md` 落位。
2. 公共组件变更必须更新 `公共组件总览.md`。
3. 核心架构和长期规则同步更新 `.trellis/spec/`。
4. 过时重构方案移入 `05_历史归档/`。
5. `scratch/`、毕业论文、交付包、参考素材不作为当前项目文档真相源。
