# 后端公共服务库

> 更新日期：2026-10-16（按当时代码重写；旧版写于 2026-03，描述的多个类已删除）
> 适用范围：`apps/aicove_flutter/lib/src/` 与 `apps/aicove_flutter/packages/`
> 本文只给「去哪找」的地图。每个服务的行为以代码与对应 ADR 为准，不在这里重复。

## 分层

```text
packages/aicove_agent_kernel/   纯 Dart Agent 内核（不依赖 Flutter）：循环、阶段管线、插件宿主、工具闸门、事件
packages/aicove_quickjs/        QuickJS 运行时（预设脚本，ADR0042）
lib/src/core/                   与业务无关的基础设施：模型 API、数据库、媒体、日志、同步追踪
lib/src/features/               业务模块：聊天、插件、上下文、记忆、主动关怀、同步、语音通话……
lib/src/ui/                     界面层（规范见 界面布局说明.md、公共组件总览.md）
```

## Agent 运行时（ADR0064）

| 位置 | 内容 |
|---|---|
| `packages/aicove_agent_kernel/lib/src/agent_loop.dart`、`stages.dart` | 内核循环与固定阶段管线（准备→请求→解包→工具决策→执行→续写） |
| `packages/aicove_agent_kernel/lib/src/plugin_host.dart`、`scope.dart` | 插件宿主、能力声明与作用域清理 |
| `packages/aicove_agent_kernel/lib/src/tool_gate.dart`、`change_journal.dart` | 工具授权闸门与可撤销变更日志 |
| `features/chat/services/api_runner.dart` | 编译期开关 `AICOVE_AGENT_KERNEL_CHAT`／`_BG`，默认走内核；设为 `false` 回退旧 runner |
| `features/chat/services/chat_send_api_runner_kernel.dart` | 前台聊天接内核的 `ApiRunner` |
| `features/background_agent/background_agent_service.dart` | 后台 Agent（压缩、记忆整理、主动回复等）的运行壳 |
| `features/agent_plugins/` | App 侧插件 API v2：`AicovePlugin`、`PluginRuntime`（宿主注册表）、`PluginRequestScope`（请求期贡献，含 ADR0063 请求前提醒）、`tool_policy.dart` |
| `features/agent_context/` | 上下文装配配方 `ContextProfile`、`ConversationWindowSpec`（ADR0060）、酒馆预设解析与存储 |

## 插件（features/plugins/）

- 内置插件按目录分：`image`、`tts`、`trigger`（主动关怀）、`time_awareness`、`web_search`、`memory`、`sticker`、`tavern_compat`、`mcp`（ADR0072），各自的 `*_agent_plugin.dart` 是在内核 v2 上的注册入口；`packages/` 是声明式包的加载与注册。
- `plugin_manager.dart` 只负责插件的注册与生命周期，执行能力经 v2 注册器贡献（见 `PluginRuntime`）。
- `plugin_providers.dart` 汇总各插件配置的 Riverpod Provider。
- 预设化与角色绑定见 `02_前后端分离与架构规范/插件预设与角色卡绑定规范.md`（ADR0008／0009）。

## 原则

- 门面稳定：界面只调用 `ChatActions` 等门面，不直接碰装配和执行细节。
- 原文是唯一真相：过滤、压缩、提醒只作用于请求副本，不回写原始消息。
- 插件不进核心：新功能做成插件，经内核贡献点接入，发送核心不判断具体插件类型。
