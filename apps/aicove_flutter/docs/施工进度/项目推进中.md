- 优化：**聊天背景模糊改为静态模糊图，不再实时高斯模糊**
  - 现象：
    - 聊天页进出场和聊天背景设置页预览明显掉帧，尤其是开启聊天背景模糊后更重
    - 真机日志里可见 `Skipped frames` / `Davey`，问题更像页面首帧负载而不是全局转场动画
  - 根因（通俗版）：
    - `chat_page.dart` 和 `chat_background_settings_page.dart` 之前直接对整屏背景图做 `ImageFiltered.blur`
    - 这种“实时模糊整页图片”的方式每次进入页面、重建页面、拖动设置时都要重复参与绘制，代价很高
  - 关键改动（性能链路 ↔ 文件）：
    - `lib/src/ui/features/chat/pages/chat_page.dart`
      - 聊天页背景改为“原图 + 静态模糊图叠层”
      - 复用 `BlurredBackgroundService` 预生成/缓存模糊图，不再在聊天页里实时 `ImageFiltered.blur`
      - 根据 `chatBackgroundBlurSigma` 只调整静态模糊层透明度，保留原本“模糊强弱”的视觉趋势
    - `lib/src/ui/features/chat/pages/chat_background_settings_page.dart`
      - 聊天背景设置页的缩略预览同步改成静态模糊层
      - 预览拖动遮罩/模糊滑杆时，不再对整张缩略背景做实时高斯模糊
    - `test/ui/features/chat/pages/chat_background_settings_page_test.dart`
      - 新增回归测试，锁定“聊天背景预览不再使用 `ImageFiltered` 实时模糊”
  - 验证命令：
    - `flutter test test/ui/features/chat/pages/chat_background_settings_page_test.dart`
    - `flutter test test/ui/features/chat/widgets/chat_message_list_auto_scroll_guard_test.dart`

    - `flutter run --no-resident`
