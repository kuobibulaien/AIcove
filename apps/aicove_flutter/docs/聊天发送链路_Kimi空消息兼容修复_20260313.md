# Kimi 空消息兼容修复（2026-03-13）

## 1. 现象

- 调用 Moonshot / Kimi 接口成功；
- 日志里可见 `API调用成功`，但 `textLength=0`、`chunksCount=0`；
- 最终用户收到的是空消息。

## 2. 根因

- `kimi-k2.5` 默认开启 thinking；
- Moonshot 官方文档说明：`reasoning_content` 与最终 `content` 共用 `max_tokens` 预算；
- 现有 OpenAI 兼容请求未给 Kimi thinking 模型补 `max_tokens` 安全下限；
- 当 reasoning 消耗掉大部分预算时，接口可能仍然成功，但最终 `content` 为空；
- 前端本身不会把 `reasoning_content` 当聊天正文显示，因此看起来像“成功但空消息”。

## 3. 修复

- 文件：`lib/src/core/api/providers/openai_adapter.dart`
- 策略：
  - 仅对 `kimi-k2.5` / `kimi-k2-thinking*` 自动补 `max_tokens: 16384`；
  - 若用户已手动配置 `max_tokens`，则保持用户配置优先；
  - 若用户显式关闭 thinking（`thinking.type=disabled`），则不额外注入该兜底值。

## 4. 回归测试

- 文件：`test/core/api/openai_adapter_request_test.dart`
- 覆盖点：
  - Kimi 默认 thinking 会自动注入安全 `max_tokens`；
  - 手动配置 `max_tokens` 时不被覆盖；
  - thinking 关闭时不注入；
  - 非 Kimi 模型不受影响。
