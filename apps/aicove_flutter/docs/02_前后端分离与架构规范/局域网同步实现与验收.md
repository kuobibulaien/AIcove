# 局域网同步实现与验收

2026-10-01，ADR0051。状态：初版源码与主机网络验证完成。真实设备上的发现、配对、手机生命周期及 Windows/iOS 尚未验收；本轮不操控桌面、不安装、不请求生产云服务。

## 用户行为

> 2026-10-04 起配对方式与常连行为以 ADR0057 为准：主机同时显示二维码与 6 位数字；加入端可实时扫一扫、输入数字或导入二维码；配对后切后台不断开。

1. 无云账号也能从「设置 → 调试 → 同步与备份」打开“局域网同步”，显式开启后监听本地网络。
2. 一端显示十分钟有效的一次性二维码/配对码，另一端拍摄/导入二维码或粘贴配对码，显示两端名称；邀请端确认后开始交换现有角色、完整聊天、渠道、可同步设置与预设文件。
3. 同网络中已配对设备自动重连；暂停停止监听/传输，取消配对立即拒绝该设备后续请求。本机历史保留。
4. 各端离线继续修改，重连补齐。设置按实际编辑时间合并、主动清空生效，“通用”值不上传也不被替换。同条聊天/预设或删除与编辑并发保留冲突，由用户选择。
5. 图片/音频等按身份和哈希分块传输，仅补缺少内容；中断安全重试，大附件不把整个历史装进内存。没有原文件的历史引用显示缺口，不制造假的原图。

## 数据与连接契约

- 持久设备编号与单调本机修改计数；实体修订带版本向量，确定有无因果先后。修订内容哈希是幂等编号，两个设备保存/转发相同修订不再创建编辑。
- 交换修订摘要，再获取缺少的不可变修订；并发设置生成确定性合并修订，其他并发保存多个头。显式解决创建继承全部冲突因果的新修订。
- LAN 记录和云端版本/游标/队列隔离。接收写入沿现有 CloudLocalStore 契约，完整消息父子同事务，settings 接收保留 General 字段，文件路径限定既有根目录。
- 原生 Bonjour/NSD 只广告设备编号、协议与监听端口。配对码携带随机邀请和私网直接地址，禁止自动连接任意公网地址。地址变化后以配对设备身份重新发现，并通过加密认证确认。
- 邀请只用于首次请求与派生每对设备的永久密钥；两端确认后才能读取业务数据。所有业务与分块文件通过带请求绑定的 AES-GCM 信封传输，不记录或输出秘密。
- 明确限制请求体、修订数、分页、并发、超时、文件块/文件大小及路径。篡改、未知设备、撤销设备和重放请求不能写业务数据。

## 回滚

关闭 LAN 模式后切回旧客户端代码。辅助表、设备凭据、修订日志与备份保留；原文件及云队列不删除。首次功能不涉及生产云服务部署。

## 实现与已完成验证（2026-10-01）

- 入口：`SettingsPage → LanSyncPage`，经 `LanSyncPort`/Riverpod 调用 `LanService`。设备名称沿公共自动保存控制器；确认配对、取消配对与选择冲突版本是显式动作。
- 设备名（2026-10-04）：未手动命名时读取系统名（Android「关于手机」设备名，读不到用厂商＋型号；Mac 电脑名去掉“某某的”前缀；见 `device_names.dart`）。名称写入同步设置 `aicove.devices.v1`（设备 ID → 名称，每台只写自己的字段，按字段时间合并不冲突），云同步与局域网共用；冲突处理页按此标注设备，并支持“以此设备为准处理差异”批量处理。
- 存储：`core/sync/lan_tracking.dart` 安装辅助表与父子消息触发器，不提升业务 schema；`LanRepository` 记录不可变修订，每批采集至多 500 条，云 outbox 独立。角色删除先等待聊天墓碑；删除与离线聊天并存时保留两者，选择保留角色会产生观察过删除请求的新修订。
- 连接：`LanTransport` 只访问私网 IPv4；监听端口由系统分配；Bonjour 失败时可扫描配对码直接连接。已配对端点变化可用保留密钥通过新配对码更新地址，不必删除历史或重新授权。原生发现与本轮主机测试分开记录；IPv6-only 网络本期未支持。
- 认证：邀请十分钟有效、一次性随机密钥，每对设备以 HKDF 派生 AES-GCM 密钥；设备/请求/响应类型进入认证数据。邀请端确认后才能读取业务；未知、未确认、篡改、重放和撤销请求拒绝访问。持久凭据写入 `DeviceCredentialStorage`，发现仅广播协议、设备标识和端口。
- 限制：请求 8 MiB，业务修订 4 MiB，摘要 100 条/页，单实体最多 64 个并发版本，服务最多 4 个请求；请求读取/连接超时。附件每块 512 KiB、每个文件最多 128 MiB，持久部分文件可续传、完整 SHA-256 通过后才发布；既有完整附件不重传。LAN 注册附件不主动下载公网 URL，已有缓存仍能复用；接收端拒绝 POSIX/Windows 绝对附件路径与 file URI，普通聊天文本保持原样。
- 媒体：`LanMedia` 与云端共用媒体索引及到达通知，不替换云下载回调；先接收身份再应用本机路径，缺少原文件保留为可见缺口。媒体队列独立于消息同步，暂停中断网络并保留部分文件。
- 自动运行：SQLite 已提交变更触发 300 ms 合并唤醒，每 3 秒核对离线文件/设置与对端修改；移动端暂停、回前台重连。默认关闭；无云账号初始化不会请求云服务。

## 吞吐修复（2026-10-04，两端最终修复已装，现有配对同步验收通过）
