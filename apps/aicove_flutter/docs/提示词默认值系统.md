# 提示词默认值系统

更新时间：2026-09-13

## 真相源

- 默认模板：`assets/prompt_defaults.json`
- Dart 常量：`lib/src/core/prompts/prompt_builtin_defaults.g.dart`
- 模板渲染器：`lib/src/core/prompts/prompt_template_renderer.dart`
- 本地生成工具：`tool/prompt_defaults_codegen.py`
- 随包 Agent 配置：`assets/agent_context_defaults.json`

路径均相对 `apps/aicove_flutter/`。默认模板和随包 Agent 配置由源码维护；旧云端 Prompt Studio / Agent Builder 已删除，不依赖管理服务器配发。

## 维护流程

1. 修改 JSON 的 `variables`、`prompts`；保留模板 ID 与 `dartName` 的唯一性。
2. 在 `apps/aicove_flutter/` 执行 `python3 tool/prompt_defaults_codegen.py`，生成 Dart 默认常量。
3. 按根 README 的交付检查规则验证改动。运行时通过 `PromptBuiltinDefaults` 和 `PromptTemplateRenderer` 读取与插值。

`agents` 元数据不生成 Dart 常量。既有 `agent_context_defaults.json` 继续作为客户端本地资源消费；删除旧管理服务器不删除此资源，也不改变客户端 Agent 装配。

## 客户端节点

内置默认节点随包发布，只读；用户自建节点保存在客户端本地，不得覆盖内置节点的同名 ID。默认配置更新随应用版本生效。
