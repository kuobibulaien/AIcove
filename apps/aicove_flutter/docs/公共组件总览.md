# 公共组件总览（权威版）

> 📖 本文档是**前端公共组件的权威清单**，所有组件新增/变更都以此为准。
> 旧的 `前端公共组件库.md` 已合并到此文档，保留为历史索引，请勿再单独维护。

这份文档用最简单的语言，告诉你项目里有哪些"现成的零件"可以直接用。

## 🤔 什么是公共组件？

想象你在搭乐高：
- **公共组件** = 预制好的乐高积木块
- 不用每次都从零开始做，直接拿来用就行
- 改一处，所有用到它的地方都会变

## 📱 界面零件

### 1. MoeAppBar - 页面顶部栏

📄 `lib/src/ui/shared/widgets/moe_app_bar.dart`

**是什么**：每个页面最上面那一条，显示标题和按钮的地方

**长什么样**：
- **主题色背景**（可自由切换粉红色、蓝色等，见下文）
- 左边可能有返回箭头
- 中间是标题文字
- 右边可能有操作按钮（比如 + 号）

**用在哪**：设置页、角色卡页、个人资料页……几乎所有页面的顶部

**长什么样**：屏幕上方出现一个圆角小条，显示文字，比如"保存成功"

**用在哪**：

## 🔲 图片处理

### 1. AvatarHelper - 角色头像/立绘统一处理

📄 `lib/src/core/utils/avatar_helper.dart`

**是什么**：统一处理角色头像和立绘的工具类，解决不同页面头像显示不一致的问题

**为什么需要它**：
- 角色有两个图片字段：`avatarUrl`（头像）和 `characterImage`（立绘）
- 不同场景需要不同的优先级：
  - **头像场景**（消息列表、聊天设置）：`avatarUrl` → `characterImage`
  - **立绘场景**（角色卡片、详情页）：`characterImage` → `avatarUrl`

**用法**：
```dart
final helper = AvatarHelper(
  avatarUrl: conversation.avatarUrl,
  characterImage: conversation.characterImage,
  displayName: conversation.displayName,
);

// 头像场景（消息列表、聊天设置）
helper.buildAvatarWidget(fallback: yourFallbackWidget);
helper.getAvatarProvider();

// 立绘场景（角色卡片、详情页）
helper.buildCharacterWidget(fit: BoxFit.cover);
helper.getCharacterProvider();
```

**用在哪**：
- 消息列表头像（CharacterListItem）
- 聊天设置页头像（ChatSettingsDialog）
- 角色卡片（HorizontalRoleCard）
- 角色详情页（CharacterDetailPage）

### 3. ImagePreheatQueue - 图片预热队列

📄 `lib/src/core/utils/image_preheat_queue.dart`

**是什么**：一个“分帧排队”的图片预热工具，会把图片提前解码进内存缓存，减少进入聊天页时的图片闪烁和卡顿感

**用在哪**：
- 联系人列表里（列表可见时预热头像、按下时高优先级预热）  
  📄 `lib/src/features/chat/presentation/widgets/contacts_list_content.dart`
- 聊天页里（首帧后兜底预热，不抢动画帧）  
  📄 `lib/src/ui/features/chat/pages/chat_page.dart`
- App 启动/恢复时（预热最近会话，减少“刚打开就进聊天”闪一下）  
  📄 `lib/src/app.dart`

**怎么用（最常见）**：
```dart
final queue = ref.read(imagePreheatQueueProvider);
queue.enqueueAllFromContext(context, providers);
queue.enqueueAllFromContext(
  context,
  providers,
  priority: ImagePreheatPriority.high,
);
```

#### MoeToggleBar - 单选切换框 (Toggle Bar)

用于在多个选项中单选切换，类似 iOS 分段控制器。

**参数说明**：
| 参数 (Parameter) | 类型 (Type) | 说明 (Description) |
|-----------------|-------------|-------------------|
| `value` | `T` | 当前选中值 (required) |
| `items` | `List<MoeToggleItem<T>>` | 选项列表 (required) |
| `onChanged` | `ValueChanged<T>` | 值变化回调 (required) |
| `expanded` | `bool` | 是否撑满宽度（默认 true） |

**使用示例**：
```dart
MoeToggleBar<String>(
  value: _selected,
  items: [
    MoeToggleItem(value: 'openai', label: 'OpenAI'),
    MoeToggleItem(value: 'claude', label: 'Claude'),
    MoeToggleItem(value: 'gemini', label: 'Gemini'),
  ],
  onChanged: (v) => setState(() => _selected = v),
)
```

#### MoeSettingsGroup - 设置分组容器 (Settings Group Container)

iOS 风格的设置分组卡片，自动处理最后一行的分割线。

**⚠️ 宽度规范（重要）**：
> `MoeSettingsGroup` 默认有 `margin: EdgeInsets.symmetric(horizontal: 16)` 的外边距。
> 如果外层 ListView/ScrollView 已经设置了 padding，会导致双重边距，卡片宽度不一致。
>
> **解决方案**：统一让 `MoeSettingsGroup` 的 `margin` 为 0，由外层容器的 `padding` 控制边距。
>
> ```dart
> // ✅ 正确用法
> ListView(
>   padding: const EdgeInsets.all(16),  // 外层统一控制边距
>   children: [
>     MoeSettingsGroup(
>       margin: EdgeInsets.zero,  // 👈 关键：设为 0
>       children: [...],
>     ),
>   ],
> )
>
> // ❌ 错误用法（会导致 16+16=32px 双重边距）
> ListView(
>   padding: const EdgeInsets.all(16),
>   children: [
>     MoeSettingsGroup(  // 默认 margin: 16
>       children: [...],
>     ),
>   ],
> )
> ```

**参数说明**：
| 参数 (Parameter) | 类型 (Type) | 说明 (Description) |
|-----------------|-------------|-------------------|
| `title` | `String?` | 分组标题（可选） |
| `children` | `List<Widget>` | 子组件列表（通常是 MoeSettingsRow） |
| `titleFirst` | `bool` | 是否为第一个分组（影响标题上边距） |
| `margin` | `EdgeInsets?` | 外边距（**建议设为 EdgeInsets.zero**） |
| `backgroundColor` | `Color?` | 卡片背景色 |
| `borderRadius` | `BorderRadius?` | 卡片圆角 |

**使用示例**：
```dart
MoeSettingsGroup(
  title: '通用设置',  // 可选的分组标题
  margin: EdgeInsets.zero,  // 👈 推荐：让外层控制边距
  children: [
    MoeSettingsRow(icon: Icons.language, label: '语言'),
    MoeSettingsRow(icon: Icons.palette, label: '主题'),
  ],
)
```

#### MoeSettingsRow - 设置行 (Settings Row)

设置页面的标准行组件，支持开关、箭头、文字等多种尾部类型。

**参数说明**：
| 参数 (Parameter) | 类型 (Type) | 说明 (Description) |
|-----------------|-------------|-------------------|
| `icon` | `IconData` | 左侧图标 (required) |
| `label` | `String` | 主标题文字 (required) |
| `subtitle` | `String?` | 副标题/描述文字 |
| `trailingType` | `MoeSettingsRowTrailing` | 尾部类型（见下表） |
| `switchValue` | `bool?` | 开关状态（trailingType 为 switch 时使用） |
| `onSwitchChanged` | `Function(bool)?` | 开关回调 |
| `detailText` | `String?` | 详情文字（trailingType 为 text 时使用） |
| `trailing` | `Widget?` | 自定义尾部组件（trailingType 为 custom 时使用） |
| `onTap` | `VoidCallback?` | 点击回调 |
| `enabled` | `bool` | 是否启用（默认 true） |
| `showDivider` | `bool` | 是否显示底部分割线（默认 true） |

**尾部类型枚举**：
| 类型 (TrailingType) | 说明 (Description) |
|--------------------|-------------------|
| `chevron` | 箭头（默认，用于导航） |
| `switchControl` | 开关控件 |
| `text` | 文字（用于显示当前值） |
| `custom` | 自定义组件 |
| `none` | 无尾部 |

**使用示例**：
```dart
// 1. 带开关的设置行 (Switch Row)
MoeSettingsRow(
  icon: Icons.wifi_off,
  label: '离线模式',
  subtitle: '不使用云同步，仅本地存储',
  trailingType: MoeSettingsRowTrailing.switchControl,
  switchValue: true,
  onSwitchChanged: (value) { /* 处理开关变化 */ },
)

// 2. 带箭头的导航行 (Navigation Row)
MoeSettingsRow(
  icon: Icons.settings,
  label: '高级设置',
  trailingType: MoeSettingsRowTrailing.chevron,  // 默认值，可省略
  onTap: () { /* 跳转到子页面 */ },
)

// 3. 带文字的行 (Text Detail Row)
MoeSettingsRow(
  icon: Icons.language,
  label: '语言',
  trailingType: MoeSettingsRowTrailing.text,
  detailText: '简体中文',
  onTap: () { /* 打开语言选择 */ },
)

// 4. 自定义尾部 (Custom Trailing)
MoeSettingsRow(
  icon: Icons.check,
  label: '自定义',
  trailingType: MoeSettingsRowTrailing.custom,
  trailing: MoeCheckbox(value: true, onChanged: (v) {}),
)
```

#### MoeListTile - 通用列表项 (List Tile)

通用的列表项组件，支持头像、标题、副标题、尾部图标。

**参数说明**：
| 参数 (Parameter) | 类型 (Type) | 说明 (Description) |
|-----------------|-------------|-------------------|
| `leading` | `Widget?` | 左侧组件（头像/图标） |
| `title` | `Widget` | 标题（**注意是 Widget 类型，需要用 Text() 包裹**） |
| `subtitle` | `Widget?` | 副标题（**Widget 类型**） |
| `trailing` | `Widget?` | 右侧组件 |
| `onTap` | `VoidCallback?` | 点击回调 |
| `onLongPress` | `VoidCallback?` | 长按回调 |
| `selected` | `bool` | 是否选中状态 |
| `enabled` | `bool` | 是否启用 |

**使用示例**：
```dart
MoeListTile(
  leading: CircleAvatar(
    backgroundImage: NetworkImage('https://...'),
  ),
  title: const Text('角色名称'),      // ⚠️ 必须用 Text() 包裹
  subtitle: const Text('最后一条消息'), // ⚠️ 必须用 Text() 包裹
```

### 嵌套圆角公式

当元素嵌套时，内层圆角应遵循：

```
R_inner = R_outer - Padding
```

示例：外层卡片 20px 圆角，内部有 16px padding，则内部元素应该用 4px 圆角。

```dart

SmoothClipRRect(
  radius: MoeSmoothRadii.md, // 20px
  child: Padding(
    padding: EdgeInsets.all(16),
    // 内层
    child: SmoothClipRRect(
      radius: MoeSmoothRadii.md - 16, // 4px
      child: ...
    ),
  ),
)
```

## ⌨️ 键盘弹出规范 (新增 2026-01-25)

### 问题背景

在底部弹窗（BottomSheet）中有输入框时，键盘弹出会导致界面抖动。

**错误做法**：在 `SingleChildScrollView` 或 builder 内部使用动态 `viewInsets.bottom` 作为 padding：
```dart
// ❌ 错误：内容区域每次键盘高度变化都会重新布局，导致抖动
SingleChildScrollView(
  padding: EdgeInsets.fromLTRB(20, 16, 20, 24 + viewInsets.bottom),
  ...
)
```

**正确做法（新规范）**：**不推高整个 sheet 外框**，只在内部内容区用 `AnimatedPadding` 给键盘让位，让观感更像“输入框抬起”，而不是“整块弹窗飞起来”：
```dart
// ✅ 正确：外框不动，内部内容区给键盘让位（推荐）
final viewInsets = MediaQuery.viewInsetsOf(context);
return Container(
  ...
  child: AnimatedPadding(
    duration: kAnimFast,
    padding: EdgeInsets.only(bottom: viewInsets.bottom), // 内部让位
    child: SingleChildScrollView(
      padding: const EdgeInsets.all(16), // ✅ 固定 padding
      ...
    ),
  ),
);
```

### 已封装的组件

| 组件 | 键盘处理 | 说明 |
|------|---------|------|
| `MoeBottomSheet` | ✅ 已内置 | builder 内部只需使用**固定 padding** |
| `AddProviderSheet` | ✅ 已修复 | 自定义 sheet，内部 AnimatedPadding 处理 |
| `showCreateAutoReplyTriggerSheet` | ✅ 已修复 | 自定义 sheet，内部 AnimatedPadding + 可滚动处理 |
| `MeoTalkDialog` | ✅ 已修复 | 含输入框的底部对话框会跟随键盘上移 |

### 使用 MoeBottomSheet 的正确姿势

```dart
showMoeBottomSheet(
  context: context,
  title: '编辑',
  builder: (context) => Padding(
    padding: const EdgeInsets.all(16),  // ✅ 固定 padding
    child: Column(
      children: [
        TextField(...),
        MoePrimaryButton(...),
      ],
    ),
  ),
);
```

如果不使用 `MoeBottomSheet`，需要自己处理键盘（同样遵循“外框不动、内部让位”）：
