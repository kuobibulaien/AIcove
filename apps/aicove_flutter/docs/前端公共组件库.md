## 📦 快速开始

### 统一导入

```dart
// 导入所有 Moe 系列组件
import 'package:aicove_flutter/src/ui/shared/widgets/index.dart';

// 导入主题 tokens
import 'package:aicove_flutter/src/ui/theme/tokens.dart';
```

### 获取主题颜色

```dart
// 在 build 方法中
final colors = context.moeColors;

// 使用颜色
Text('Hello', style: TextStyle(color: colors.text));
Container(color: colors.primary);
```

```dart
final colors = context.moeColors;
```

## 🔘 按钮组件

位置：`ui/shared/widgets/buttons/`

### MoePrimaryButton - 主按钮

```dart
MoePrimaryButton(
  label: '确认提交',
  icon: Icons.check,        // 可选
  enabled: true,            // 可选，默认 true
  onPressed: () => doSomething(),
)
```

**特点**：粉色背景，白色文字，iOS 风格无水波纹

### MoeSecondaryButton - 次级按钮

```dart
MoeSecondaryButton(
  label: '取消',
  icon: Icons.close,        // 可选
  onPressed: () => Navigator.pop(context),
)
```

**特点**：透明背景，边框线，适合取消/辅助操作

### MoeIconButton - 图标按钮

```dart
MoeIconButton(
  icon: Icons.more_vert,
  onTap: () => showMenu(),
)
```

### MoeTileButton - 功能入口按钮

```dart
MoeTileButton(
  icon: Icons.settings,
  label: '设置',
  onTap: () => openSettings(),
)
```

## 📤 弹窗组件

```dart
showMoeActionSheet(
  context: context,
  title: '选择操作',           // 可选
  description: '请选择要执行的操作',  // 可选
  actions: [
    MoeSheetAction(
      icon: Icons.edit,
      label: '编辑',

      onTap: () => edit(),
    ),
    MoeSheetAction(
      icon: Icons.delete,
      label: '删除',
      isDestructive: true,      // 危险操作（红色）
      onTap: () => delete(),
    ),
  ],
  showCancelButton: true,       // 显示取消按钮
);
```

### MoeBottomSheet - 通用底部弹窗

```dart
final result = await showMoeBottomSheet<String>(
  context: context,
  title: '选择模型',
  showCloseButton: true,
  maxHeight: MediaQuery.of(context).size.height * 0.7,  // 可选
  builder: (context) => ListView.builder(
    shrinkWrap: true,
    itemCount: models.length,
    itemBuilder: (context, index) => ListTile(
      title: Text(models[index]),
      onTap: () => Navigator.pop(context, models[index]),
    ),
  ),
);
```

## 🎬 动画组件

位置：`ui/shared/animations/`

### ExpandingPageRoute - 卡片展开动画

```dart
// 方式1：使用扩展方法
Navigator.of(context).pushExpanding(
  page: DetailPage(),
  sourceContext: cardContext,  // 来源卡片的 context
  sourceRadius: 16,
);

// 方式2：手动创建
Navigator.of(context).push(
  ExpandingPageRoute(
    page: DetailPage(),
    sourceRect: getSourceRect(context),
    sourceRadius: 16,
    targetRadius: 0,
  ),
);
```

### ParallaxSlidePageRoute - 视差滑动动画
