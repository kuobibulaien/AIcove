## 1. 为什么改

现在给模型的语音、绘图说明散在六处，靠猜渠道硬拼：

| 位置 | 内容 | 问题 |
|---|---|---|
| 全局槽位 `aicove.plugins.prompts.v1` | `<tts>` 基础说明、`<image>` 快速模式说明 | 所有模型共用一份；`<image>` 说明写死 NovelAI 语法，换自然语言模型也照发 |
| `assets/prompt_defaults.json` 的 `tts.minimax_guide` | MiniMax 语气词与停顿 | 代码按网址／格式里有没有 `minimax` 决定拼不拼 |
| `tts_plugin.dart` 里的 `_fishAudioGuide` 常量 | Fish S2 方括号标签 | 用户看不到也改不了；按模型名含 `s2.1`／`s2-pro` 猜 |
| `fish_audio_streaming_tts.dart` 的 `kFishAudioCallSpeechGuide` | 通话里的 Fish 语气说明 | 只有 Fish 有，另一份文本，改不了 |
| `image_plugin.dart` 的参数契约拼接 | `<image>` 里传 JSON 的规则、64 倍数 | 代码里替换句子、追加段落 |
| 绘图预设里的 `drawingSystemPrompt` | 调用模式 `draw_image` 工具描述 | 仍按预设存，和 ADR0054 口径不一致 |

用户 2026-10-19 要求：按模型写独立的默认说明（不同渠道商对输入要求不同），按正则或关键字把同家族模型匹配到同一份；预设可以自由绑定、编辑；在某个预设里能看到它用的**全部**说明（基础标签规则、该模型推荐写法、其它规范）；AIcove 助手也能直接改；后续插件按同样方式改造。

## 2. 核心对象

**提示词包**：某个插件给模型的全部说明，由若干「节」组成。代码不再在包外追加任何说明文字；只属于某个预设的要求写成该预设的专属节（见第 5 节）。

```text
PromptPack
  id            稳定 ID；出厂包以 builtin. 开头
  pluginId      tts | image（以后 sticker、time_awareness …）
  name          显示名，如「Fish Audio S2」
  match         匹配规则列表，见第 3 节；空＝不参与自动匹配
  sections[]    有序的节
    id          包内唯一
    scope       用途，见下表
    title       节标题
    text        正文，可含 {变量}
    enabled     关掉后不发给模型
```

| 插件 | scope | 发到哪里 |
|---|---|---|
| 语音 | `chat` | 聊天请求的 `<tts>` 标签说明 |
| 语音 | `call` | 语音通话里给模型的语气说明；为空时通话禁止写标签（与现在一致） |
| 绘图 | `inline` | 快速模式 `<image>` 标签说明（含参数契约） |
| 绘图 | `tool.description`／`tool.prompt`（含负面）／`tool.params`（宽高张数步数强度） | 调用模式 `draw_image` 工具的描述与参数说明；旧作用域读取时映射到上面三个 |

同一 scope 的启用节按顺序用空行拼起来，再替换变量。变量只填数值，不藏说明文字：

- 语音：`{max_chars_per_chunk}`、`{voice_frequency}`（取自本次音色预设）
- 绘图：`{pov}`、`{pov_hands}`、`{default_width}`、`{default_height}`、`{default_count}`、`{default_steps}`、`{default_guidance_scale}`（取自本次绘图预设）

是否支持 `steps`／`guidance_scale` 这类随渠道变的规则，由各出厂包自己写成节（ComfyUI 包写支持，NovelAI／自然语言包写不支持），不再由代码判断后拼句子。

## 3. 按模型家族匹配

规则形如 `{formats: [...], models: [...]}`：

- `formats`：渠道的请求格式（语音认 `customConfig.requestFormat`，与 ADR0081 一致；绘图认 `novelai`／`comfyui`／`openai`）。省略＝不限。
- `models`：模型 ID 模式。普通文字按不区分大小写的「包含」匹配；写成 `/…/` 按正则（不区分大小写）匹配。省略＝不限。
- 两项都满足才算命中。

选择顺序：预设明确绑定的包 → 用户自建包里规则命中的 → 出厂专用包里规则命中的 → 该插件的出厂通用包。同一层多个命中取列表里靠前的。不按网址猜。

## 5. 绑定、编辑与存储

- **绑定**：音色预设的合成配置、绘图预设各加一个提示词绑定 `prompts = {packId, ownSections}`。`packId` 空＝「自动（按模型匹配）」，界面显示自动选中的是哪个包。旧数据读出来都是空，行为直接切到按模型的新默认。
- **本预设专属的节**（`ownSections`）：只属于这个预设、不随包共享的节，结构与包里的节相同，按 scope 排在包的节后面。用户确认（10-19）单个预设通常只给一个角色用，所以原来角色卡里的「绘图提示」（角色专属生图要求）并进绘图预设，成为它的专属节；音色预设同样可以加专属节（例如「这个角色句尾多用语气词」）。
- **新建默认一对一**：在角色卡选音色／绘图预设时，多一项「为这个角色新建」——复制当前生效的预设（含绑定的包和专属节），命名「角色名 · 原预设名」，并只绑到这个角色。预设仍可被多个角色共用，编辑页写明在用角色。
- **编辑是共享的**：包是独立对象，可被多个预设共用（例如两个 Fish 音色都用「Fish Audio S2」）。在预设页编辑，就是编辑这个包，页面顶部写明「N 个预设在用」；想只改这一个，点「另存为新包」，新包自动绑到当前预设。
- **出厂包可以直接改**：只存与出厂不同的部分，每节可「恢复默认」；出厂节不能删，只能关；可以往任何包里加自己的节、删自己加的节。出厂默认更新后，没改过的节自动跟随新版。
- **自建包**：从任一包复制，名字、匹配规则、所有节都能改；被预设引用时不能删，先列出在用的预设。
- **存储**：SharedPreferences 键 `aicove.plugins.prompt_packs.v1`（`aicove.plugins.` 前缀，随设置同步），内容为出厂包的差异＋自建包全文。出厂包本体在代码里（`features/plugins/prompts/`），不进存储。
- **请求快照**：解析出的包随本次音色／绘图预设一起固定，执行中改包不影响已发出的请求（沿用 ADR0008 第 3 条）。

## 6. 界面

- **2026-10-22 改版**：绘图预设的提示词区用「快速模式／调用模式」分段切换，默认跟随当前调用流程，只列这个模式会发给模型的节（一组卡片，不再按作用域拆成多组）；预设固定用的包与当前模型自动匹配的不同时，显示「当前模型推荐「X」」一行，点一下改回自动；共享提示缩成一句放在节列表下方；「加一节」只在当前模式的作用域里选。
- **音色预设编辑页、绘图预设编辑页**新增「提示词」分区：当前包选择（自动／手选），按 scope 分组列出全部节（标题、开关、正文可展开编辑、恢复默认、加一节），底部「预览最终提示词」按本预设的真实参数渲染出发给模型的全文（含角色专属绘图要求的位置提示）。
- **角色卡编辑页**：「角色卡信息」里只剩人设提示词，「绘图提示」移到绘图预设的专属节；音色／绘图预设选择里加「为这个角色新建」；页面最底部加「联系人上下文」入口（编辑已有角色时显示），打开调试中心同一个页面，查看这个角色下一次请求发给模型的完整内容。
- **插件页**加「提示词包」入口：按插件列出全部包、在用预设数、匹配规则编辑。
- 设置 → 插件 → 工具提示词：去掉语音、绘图两项，只剩表情包、时间提醒，等它们改造后整页退役。

## 7. AIcove 助手

新增工具（读不需要确认；写入走现有风险闸门＋本机撤销账本，档位 `review`，因为改一个包会影响所有共用它的预设）：

| 工具 | 作用 |
|---|---|
| `aicove_list_prompt_packs` | 列出某插件的全部包、匹配规则、在用预设 |
| `aicove_read_prompt_pack` | 读一个包的全部节原文；或给一个预设 ID，读它实际生效的包和渲染后的全文 |
| `aicove_edit_prompt_section` | 改某节正文／开关，或恢复默认；目标可以是包，也可以是某预设的专属节 |
| `aicove_add_prompt_section` | 往包里或某预设的专属节里加一节 |
| `aicove_fork_prompt_pack` | 复制成新包，可顺带绑到某预设 |
| `aicove_bind_prompt_pack` | 把预设绑到某包或改回自动 |

角色字段 `custom_drawing_prompt` 从改角色工具里去掉，改为编辑绘图预设的专属节。资料库 `assets/aicove_docs/plugins.md` 补「提示词包」一节，告诉助手先读再改、改共享包前说明影响范围。

## 8. 迁移

不动数据库，只读写 SharedPreferences。

1. 全局槽位里语音、绘图两项若被用户改过：各生成一个自建包「旧版自定义说明」（复制当前模型匹配到的出厂包，把正文换成旧文本、去掉已拆成独立节的 `{minimax_guide}` 占位），**不自动绑定**，在提示词包列表里置顶标注。旧键原样保留。
2. 绘图预设里的 `drawingSystemPrompt` 与默认不同的：为该预设生成自建包（工具描述节换成旧文本），**并绑定到该预设**，保持它原来的行为。
3. 角色卡里的「绘图提示」非空时：若角色的绘图预设只有它一个角色在用、且不是默认预设，就把文本加成该预设的专属节；否则复制一个「角色名 · 原预设名」的新预设放进专属节，并把角色改绑到新预设。完成后从角色的人设字段里去掉这段标记。启动时扫一遍，发送前对当前角色再查一次，导入的旧角色卡也会被迁移。
4. 回滚：提示词与预设的旧键、旧字段都没删，还原代码即可；第 3 步移走的绘图提示只存在于预设专属节，回滚后需要手动抄回角色卡。

## 9. 分批与验收

| 批次 | 内容 | 验收 |
|---|---|---|
| P1 数据与运行时 | 提示词包模型、出厂包、匹配、存储、请求接入（聊天 `<tts>`、通话、`<image>`、`draw_image`），删掉按网址／模型名猜渠道的代码，迁移 | 单测：匹配优先级、正则与关键字、差异存储与恢复默认、迁移；回归：MiniMax／Fish S2／NovelAI 三个出厂包渲染结果与改造前逐字一致（除有意拆分的格式）；真实 DeepSeek：Fish S2 包出方括号标签、自然语言包出完整英文句子 |
| P2 界面 | 两个预设编辑页的提示词分区、提示词包列表页、工具提示词页收缩 | 窄／宽屏源码渲染预览；编辑后预览全文变化；共享提示与另存为新包 |
| P3 助手 | 六个工具、撤销、资料库 | 离线工具测试；真实 DeepSeek：「把纳西妲的语音提示词里加一条：句尾多用语气词」能找到 Fish 包、说明影响范围、改完可撤销 |

后续插件（表情包、时间感知、主动关怀等）照同一结构加 scope 与出厂包；工具提示词页在最后一个槽位迁走后删除。
