# AIcove酱快捷面板方案

- 状态：第一批已实现（2026-10-19）；ADR0094。是 [交互组件方案](交互组件方案.md) 的 U3「动作组件」。
- 用户原话（10-19）：「我们可以写一些内置的前端容器，比如修改角色（展示一个角色列表，让用户选择修改哪个），修改画图预设（展示画图预设列表，让用户选择修改哪个画图预设），总之给内置的设置写一些快捷面板。」

## 为什么用 aicove-ui，不用输入框上方的卡片

| | 输入框上方卡片（`assistant_cards`） | aicove-ui 动作组件（本方案） |
|---|---|---|
| 位置 | 输入框上方一排，不在对话流里 | 回复正文里，紧跟她的解释 |
| 历史 | 不入消息表，翻回去看不到 | 原文在消息里，翻回去还能点 |
| 模型怎么放 | 调工具 | 写代码块（输出格式，不占工具轮） |
| 用户操作回传 | 无 | `<ui_state>`（ADR0091） |
| 适合 | Key 输入、选文件：必须用户亲手、做完就收的 | 列表、开关：要用户挑一个、可以反复回来点的 |

所以卡片保留给「必须用户亲手」的三件事，快捷面板都走 aicove-ui。

## 组件（第一批）

模型只写意图，列表由 App 渲染时实时读取。所有面板都支持 `title?`。

| 组件 | 属性 | 列出 | 点选一行后 |
|---|---|---|---|
| `roles` | `purpose?: edit\|drawing\|voice`，`ids?`（只列这几个） | 可见角色（隐私空间不列），副标题按用途显示简介／绘图预设／音色 | 打开角色卡（edit）、打开它的绘图预设编辑页（drawing）或音色编辑页（voice）；「交给 AIcove酱」 |
| `drawing-presets` | `role?`（角色 id） | 全部绘图预设：模型、默认标记、在用的角色 | 打开编辑页；有 `role` 时「给某某用」直接换绑定（可撤销），首行「跟随默认」；「交给 AIcove酱」 |
| `voice-presets` | `role?` | 全部音色预设：来源、内置、默认、在用的角色 | 打开编辑页；有 `role` 时「给某某用」直接换音色（可撤销），首行「不单独绑定」；「交给 AIcove酱」 |
| `settings` | `keys: [设置 key]`（最多 8 个，来自设置白名单） | 每项实时值＋控件：开关、分段／下拉、滑块、文本、模型选择 | 改了就生效（可撤销）；换到别家渠道的模型弹确认 |
| `providers` | 无 | 模型渠道：启用、有没有 Key、模型数 | 打开渠道详情；没 Key 的「填 Key」把 Key 卡片递到输入框上方 |

「交给 AIcove酱」把「帮我改一下『纳西妲』的绘图预设：」这类半句话填进输入框，用户补完自己发送。

## 授权与撤销

面板里的修改调用同名助手工具（`aicove_set_role_drawing_preset`、`aicove_set_role_voice`、`aicove_settings_set`、`aicove_request_key`）的处理函数，经 `AssistantPanelActions`：

1. 用 `AssistantRequestScope.riskOf` 评档（与模型调用同一份）。
2. 只读、可撤销、需审核：直接执行（用户亲手点就是授权，不送审核模型）。重大档、或「修改前每次问我」开着：弹确认框，确认文案用工具组自己的 `describe`。
3. 执行结果进撤销账本，聊天页撤销条照常出现。
4. 结果一句话记进块状态 `did`（最近 5 条），选中的行记 `picked`，下一轮作为 `<ui_state>` 交给模型。

## 实现位置

- 名单：`features/ui_blocks/domain/ui_block_catalog.dart` 的 `kUiActionComponents`（只有名字，渲染器与状态清洗共用）；状态清洗在 `ui_saved_state.dart`（`picked` ≤64 字、`did` ≤5 条每条 ≤120 字）。
- 提示词：`features/assistant/domain/assistant_panel_catalog.dart`，只拼进助手会话的提示词。
- 执行：`features/assistant/application/assistant_panel_actions.dart`、`assistant_panel_providers.dart`。
- 新工具：`aicove_set_role_drawing_preset`（`assistant_role_tools.dart`，角色字段 `RoleField.drawingPreset`）。
- 界面：`ui/features/assistant/widgets/assistant_quick_panels.dart`；注入点 `MoeUiBlockScope.actions`，只在 `ChatMessageList` 的助手会话提供。

## 验收

- 离线：执行器评档与确认、状态清洗、新工具与撤销的单测；五个面板的 widget 测试（含普通会话不渲染）；窄屏（400）与宽屏（1100）源码渲染预览。
- 真实 DeepSeek：「帮我改一下纳西妲的绘图预设」回复里出现 `drawing-presets`（带 `role`）或 `roles`（purpose=drawing）面板且能解析渲染。

## 暂不做

音色设为默认（没有工具）、面板里直接编辑预设字段、插件开关面板、酒馆预设列表面板。
