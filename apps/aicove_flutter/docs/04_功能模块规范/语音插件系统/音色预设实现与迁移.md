## 完整预设

`lib/src/features/plugins/tts/tts_config.dart` 的 `VoicePreset` 增加可空 `synthesis`：

- `VoiceSynthesisSettings`（`voice_synthesis_settings.dart`）：精确供应商配置 ID、模型 ID、音色 ID、语速、分段长度、语音频率、可选语音提示词。
- 原有 `promptAudioUrl` / `localAudioPath` / `promptText` / `emoText` / `useEmoText` 继续属于该预设；无须重复创建第二套参考素材模型。
- `synthesis == null` 是旧数据“待完善”，不是自动继承全局渠道的标记。新字段 JSON 可往返，普通复制与远端绑定更新保留它；显式 `copyWith(synthesis: null)` 可清除新配置。
- 密钥与 API 地址不放进 `synthesis`，仍由供应商配置管理。旧 bindings 与供应商专用字段保留，供转换审查及回滚。

## 解析端口

`VoicePresetRuntimePort` / `VoicePresetRuntime` 位于 `voice_preset_runtime.dart`：

1. 上层提供本次发声 owner、角色绑定预设 ID、可选默认预设 ID、预设目录、可用供应商/模型目标。端口不读取当前页面，也不查凭据。
2. 明确绑定优先；仅未绑定时允许上层明确提供的默认**预设引用**。不读取旧 `selectedVoicePresetId` 作为隐式默认，不拼接旧全局渠道、模型、音色或合成参数。明确绑定丢失时不得降级到默认预设。
3. 精确匹配供应商配置 ID + 模型 ID。适配器只描述协议，不能代替账号身份；重复 ID、重复目标、参数非法、缺少资源、已知音色未就绪均有受控错误码。
4. 返回带 owner 的独立 `TtsConfig` 快照，仅包含该预设与本次唯一绑定，不包含其他渠道的旧绑定。快照列表不可变，不修改共享插件配置；只保留全局启停与公共提示词模板。
5. 文件存在性、读取、上传、模型实际支持的参考文件格式、凭据有效性及供应商返回仍由后续应用层/适配器验证。`supportsReferenceAudio` 是上层明确声明，不可根据模型名字瞎猜。此端口本身不发请求、不写文件。

## 转换与回滚

`voice_preset_migration.dart` 的 `prepareVoicePresetMigration` 只生成计划：

- `backupJson` 是转换前类型化配置快照，不包含解析时未知的 JSON 字段；真正接入存储时必须另外原样备份持久化原文，成功后才可保存新配置。本批未实现或执行这段持久化流程。
- 只自动处理有显式、唯一供应商配置/模型/远端音色绑定，且可核对目标和适配器的记录。旧厂商别名、仅参考文件、多渠道绑定、重复 ID、缺失目标、冲突协议与非法参数均原样保留并记录待处理原因。
- 不因另一供应商暂时不可用而把多绑定误认成唯一绑定；不改角色 ID 或其预设引用；不删除素材。
- 已有 `synthesis` 不覆盖；重复预演不会重复转换。保留所有旧字段和旧插件配置，不用破坏式替换数据。
- 本批回滚只需撤销这批基础代码；未来实际转换后，应先恢复备份配置，再回退消费代码。撤销备份之后新增的用户修改需另行核对，不允许无提示覆盖。

## 第二批：运行时与前端已接入

### 入口与交互

- `TtsPluginDetailPage` 只管理启停和完整预设库，不再先选择全局渠道。`VoicePresetList` 被管理页与角色选择弹窗复用，按具体渠道分组、搜索名称/渠道/模型/音色ID，长列表懒构建；同显示名渠道附配置 ID 区分。
- `VoicePresetEditorPage` 独立编辑名称、渠道与模型、音色ID/链接/本地文件、语速；频率、分段与可选提示词、情感参数放进高级设置。可直达供应商管理；模型切换清除旧音色ID与绑定，不把上家资源带给下家。
- 音色目录只请求编辑中的具体渠道与模型，选择后绑定当前目标；能力不支持的文件/链接选项禁用。支持上传的供应商可显式创建云端音色，操作前说明上传与费用；审核状态可通过重新浏览目录更新。
- 试听使用未保存的当前草稿与相同解析端口；插件关闭仍可试听。异步目录、文件、合成与保存都有状态/错误提示与卸载守卫。实际创建/试听由用户点击触发，本轮 agent 未调用。
- 修改共享预设前列出绑定角色；仍有角色引用的预设不能移除，默认预设移除会额外说明影响。移除只移除本地预设，不远端删除音色，也不删除可能复用的参考文件。默认预设可设置或取消。

### 请求归属与安全

`VoicePresetApplicationPort` 是 UI 与聊天共用应用端口（`voice_preset_application.dart`），负责从角色读取 `voiceFile` 预设引用、解析默认引用和供应商配置，构造 `VoiceRequest`。预设 ID 不变，无需迁移角色数据库字段。

`ChatSendBackendService.prepareApiConfig` 在请求发出前保存 `ApiConfig.voiceRequest`，用 `TtsPlugin.forRequest` 生成对应供应商提示词和分段事件；执行时不再从当前全局配置补渠道。执行 sessionId 与 owner 不同直接拒绝。缓存主动回复同样先解析角色，再处理插件事件。

流式回调以 Dart Zone 传递当前请求，`_StreamPlaceholderDelivery.onDelta` 固定该快照；后续定时刷新沿这个快照启动 TTS。非流式/后补事件用 `Expando` 关联到同一个请求，再在交付作用域取回。两者均在 `ChatPendingTtsResolver` 核对 convId；历史孤立待生成消息才按其显式 convId 解析，不读取活动页面。`TtsPlayerManager` 使用事件携带的服务，生产环境的旧 global getter 永远返回 null。

**Zone/Expando 只承载内存上下文，不序列化到事件 data 或 raw payload。** API地址、凭据、模型配置在本次请求建立时固定，跨角色、切默认、关闭页面或修改供应商不重新选路。语音标签提示词保留角色预设独立频率与分段，语音提示词可按预设覆盖。

阿里云复刻缓存键补入具体渠道/API地址/凭据的 SHA256 范围，避免相同参考素材和模型在不同账号复用远端音色。自动创建结果写回前比对预设目标与参考素材，不能覆盖用户期间修改。硅基本地参考音频转换为 data URI；官方依据：[SiliconFlow TTS 文档](https://docs.siliconflow.com/en/userguide/capabilities/text-to-speech) 的 references.audio 支持 Base64。文件不超过20MB，具体模型的格式/时长/授权仍由供应商约束。合成日志不再记录参考音频正文及完整请求体。

### 保存、转换与回滚

`TtsPluginConfigNotifier.ready` 等待旧配置加载；新操作串行保存，成功后才发布状态。`presetSchemaVersion=1` 标记转换，`defaultVoicePresetId` 是独立且可清空的默认引用。第一次新式写入前，把 SharedPreferences 中原始 JSON（包括未知字段）存入 `aicove.plugins.tts.before_voice_presets_v1`，备份返回成功后才提交新配置；损坏旧 JSON 不会被空默认值覆盖。

唯一可确认的旧绑定转换为完整预设并继承原参数/提示词；无法确定的保留“待完善”，不猜渠道。只有已成功转换的旧选中预设才成为默认预设。角色原引用、旧字段、素材均保留。恢复备份前应先另存当前配置（防止丢掉升级后新增内容），再恢复旧原文并回退运行时消费代码；不是盲目覆盖当前配置。
