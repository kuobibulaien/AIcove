# 绘图预设（绘图配置包）实现与迁移

日期：2026-09-06。绘图配置包是插件专属设置的组合，不是酒馆预设。界面沿用本次需求的限定名称「绘图预设」。架构依据：[统一规范](../../02_前后端分离与架构规范/插件预设与角色卡绑定规范.md)、[ADR 0009](../../../../../docs/项目记忆/决策记录/0009-绘图预设存储与请求快照.md)。

## 已实现

- 插件主页管理完整预设：新建、编辑、复制、设为默认、测试、确认删除；关闭绘图后仍可编辑。多个角色共享一个预设，编辑影响后续请求，不改正在执行的请求。
- 每张角色卡选择一个稳定 ID；未绑定使用默认预设。角色外貌等专属绘图要求继续保存在角色中，不随公共风格互相覆盖。
- 预设包含具体渠道引用、模型引用、正面画师串/负面风格、参考宽高/张数、NovelAI 步数/提示词强度，以及工具描述与快速模式辅助提示词。辅助提示词和超时、基础负面词默认折叠在「高级」。密钥仍留在渠道设置，不复制进预设。
- 工具模式和快速模式共用参数解析。`width/height/count` 可覆盖；NovelAI 另开放 `steps/guidance_scale`。覆盖不保存回预设，越界/非有限数/非整数或不支持的参数明确失败，模型不能换渠道或模型。
- 宽高 256–2048，NovelAI 要求 64 倍数；张数 1–4、步数 1–100，本次新编辑/调用的提示词强度 0–10。供应商更细的模型限制由原图片适配器及服务响应决定，不宣称支持任意参数。

## 请求与交付

`ChatSendBackendService.prepareApiConfig` 按传入的角色解析预设，把请求配置放入 `ApiConfig.drawingConfig`，并用该配置创建请求专属 `ImagePlugin` 与 `boundTools`。禁止修改全局插件实例来切角色。预设改名不影响 ID；明确绑定丢失、渠道/模型不可用、渠道与模型归属冲突，不静默找另一个供应商。

快速模式的 `image_generate` 事件携带不含凭据的绘图配置副本，`ChatTtsHandler` 的两条交付路径都传给 `ChatDeferredImageDelivery`；延迟生成不重新查询当前活动角色或新默认预设。无快照的旧入口仅按显式 `convId` 解析角色，不读取活动页面。

快速模式兼容 `<image>英文提示词</image>`，也可使用：

```xml
<image>{"prompt":"cat portrait","width":1024,"height":1024,"steps":30}</image>
```

仅把 `{` 后空白再跟双引号的文本作为 JSON 候选；`{{{pov}}}` 是 NovelAI 权重语法，不能误判。运行时契约覆盖旧默认提示词「禁止 JSON」的格式限制。快速模式返回的多张图片保留为图片块；稳定模式的原有单候选审图/发送策略没有重写。

## 存储与渐进迁移

| 对象 | 存储与规则 |
|---|---|
| 预设目录 | SharedPreferences `aicove.plugins.image.drawing_presets.v1`；含版本、预设列表、默认 ID、冻结的旧配置 |
| 旧配置 | `aicove.plugins.image.config` 原样保留；新入口不再回写旧全局散项 |
| 角色绑定 | 复用 `personaPrompt` 内部标记保存 `drawingPresetId`，解析时从模型人设正文剥离；不升级 SQLite schema |
| 旧角色 | 默认配置先转换；旧画师串/工具收藏也变成可见的完整预设；角色的复合旧绑定按确定性 ID 懒转换，同组合只保存一次 |
| 丢失引用 | 旧引用缺少定义或新 ID 不存在时要求重新选择，不猜配置；原角色文本不批量重写 |
| 保存 | 异步串行更新、先持久化成功再发布状态；false/异常不显示保存成功；损坏新目录不回退覆盖 |

用户打开角色或首次聊天时可完成该角色旧组合转换；未访问角色不是已批量改写的新 ID。未操作角色绑定时保留旧标记，选择新预设/默认项后才收成单绑定。

## 回滚与明确边界

- 回退本批绘图接线与界面即可回读旧全局键；新目录不删除。回退前保留目录及角色数据。旧版本不认识新绑定标记，故新建绑定不能声称能在旧版自动还原；需要反向映射或重新选择，禁止清理用户数据当作回滚。
- 2026-09-10 补齐删除入口：先确认，默认项要求先设置另一个默认项；仍被角色引用（含旧画师串／工具组合绑定）时拒绝删除并提示角色名称。引用读取失败或目录保存失败不移除列表项；删除与其他目录更新串行执行，保存成功后才发布新状态。不改写角色绑定，也不删除冻结的旧配置。
- 角色分享/跨设备备份暂不携带预设目录和渠道依赖。只有 ID 不等于恢复可用；新设备缺失引用会提示重新选择。导入导出正在单独止损，本批不扩大其格式或字段范围。
- 参数覆盖、渠道隔离通过本机 HTTP 模拟服务核验；没有调用真实供应商或消耗生图额度，图片质量和供应商可用性未验。

## 图片重新生成切换画师（2026-09-11）

重新生成用于对比相同画面内容的不同画师风格：按图片所属角色读取当前绘图配置包；明确绑定优先，未绑定跟随默认。保留原图渠道、模型、宽高、步数、强度、基础与运行时负面词及已保存扩展参数，仅替换画师正面前缀和负面风格词。每次只生成一张；本次开始后修改预设不改变已捕获配置。

`ImageGenerationSnapshot` v1 增加可选 `basePrompt`、`baseNegativePrompt`，分别保存不含画师风格的画面提示词和基础负面词。快速、同步工具、异步工具、重画落库与备份使用同一字段；图片显示/上下文用的新提示词随成功结果一起更新。连续更换或停用画师不会累积旧风格，失败保留原图。

旧图没有分离字段时，只在当前/冻结的旧预设目录中精确匹配已知正面前缀及对应负面前缀；缺失、歧义或独立提示词覆盖时明确拒绝，提示新生成一次以保存完整来源，不猜测删除标签。没有完整生成快照的更旧图片继续拒绝按原参数重画。不升级数据库schema或批量回填历史；回滚本次代码即可继续读取原v1快照，旧版忽略新增字段。

验证：本机HTTP请求体覆盖三条生成路径、NovelAI V5正负结构化提示词、原参数保留、角色绑定、同预设编辑、停用画师、DB重载、旧图兼容、扩展覆盖和备份恢复；相关120项测试通过。真实供应商画风效果未调用验收，设备交付状态见项目需求日志。
