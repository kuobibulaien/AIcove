## 功能概述

### 音频播放器组件

位置：`lib/src/features/chat/presentation/widgets/audio_player_widget.dart`

支持的功能：
- 播放/暂停控制
- 进度条显示和拖动
- 时间显示
- 加载状态和错误提示
- 自动处理相对/绝对 URL

### TTS 集成

通过插件系统集成，AI 回复时可自动生成语音消息。

配置位置：设置 → 插件设置 → TTS 插件
