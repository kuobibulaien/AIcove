# 酒馆预设、正则与世界书（2026-10）

## 基本规则

- 在「设置 · 插件 · 酒馆相关 · 酒馆预设」导入 SillyTavern 预设（JSON）；角色在聊天页「更多 · 酒馆预设」或角色编辑页绑定。
- 用哪个预设：角色绑定的优先；角色没绑定时用「酒馆相关」里设的全局默认预设；两者都没有才用 AIcove 自己的装配（人设提示词＋插件说明）。
- 绑定的预设丢失时不会悄悄换成别的预设，会报错让用户重新选择。
- 预设按当前选中的提示词顺序（prompt order）组装，每个条目可单独开关；marker 条目是占位（角色描述、聊天历史、世界书等由程序填充）。
- 带脚本的预设（SPreset／Kemini）在独立的 QuickJS 沙箱里执行。

## 正则

- 正则脚本需要用户「授权」后才执行；未授权的预设正则全部不跑。
- prompt_only 只改发给模型的内容；display_only 只改显示；输出 HTML 的美化正则不执行。

## 世界书

- 世界书挂在预设上，条目按关键词触发，constant 条目常驻；只注入到请求副本，不改聊天原文。
- 条目多或常驻条目多时很占上下文，用 aicove_inspect_context 看 token。

## 常见问题

| 现象 | 常见原因 |
|---|---|
| 工具全部失效、不能生图 | 预设 function_calling=false |
| 回复格式乱、出现奇怪标签 | 预设里的格式要求和插件标签说明冲突，或正则没授权 |
| 角色不像人设 | 预设没包含角色描述 marker，或被其他条目覆盖 |
| 上下文爆了、很慢 | 世界书常驻条目多、预设条目过长 |
| 参数不生效 | 看 parameter_compatibility，部分参数当前服务商不支持 |
