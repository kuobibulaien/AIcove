# AIcove 产品与界面地图（2026-10）

## 定位与边界

- 本地运行、隐私优先的 AI 陪伴聊天客户端（Flutter，Mac／Windows／Android／iOS；不支持网页版）。
- 不是治疗产品，不做心理监控或内容审核。
- 没有中心服务器、不内置 Key：模型由用户在「设置 · 模型」里接入自己的服务商。
- 聊天记录、角色、预设都存在用户设备上；可选的云同步只同步到用户自己部署的服务，局域网直连可在设备之间直接同步。

## 一级界面（底栏三个图标）

| 页 | 内容 |
|---|---|
| 聊天 | 所有角色的会话列表（一个角色＝一个会话）；右上角「＋」新建角色 |
| 空间 | Agent 可读写的文件空间，内置固定的「AIcove」默认空间 |
| 设置 | 个人资料卡；入口：模型、通用、插件、调试、新手教程 |

宽屏（≥900 逻辑像素）时左侧是上面这套一级界面，右侧显示打开的页面；窄屏就是手机布局。

## 常用位置

- **模型**：设置 · 模型 → 供应商（渠道）列表、「默认模型设置」；每个渠道里填 API Key、选可见模型、测试连接。
- **通用**：深色模式、字体大小、界面缩放、壁纸、材质（纯色／模糊／玻璃）、消息分段、新会话默认样式（气泡／文档）。
- **插件**：设置 · 插件（「聊天插件」页）→ 长期记忆、主动关怀、表情包、语音、绘图、时间感知、联网搜索、MCP 连接器、酒馆相关（预设、正则、世界书）；还有全局共用的「插件标签说明」。
- **调试**：日志中心、联系人上下文（查看某个角色发给模型的完整上下文）、增强对话、调用超时、消息分段、同步与备份、其他工具。
- **聊天页右上角「更多」**：详情（进入角色编辑）、聊天界面、绘图风格、酒馆预设、压缩上下文、清空历史记录、删除该角色。右上角电话图标是语音通话。
- **角色编辑页**：头像与立绘（自定义形象）、角色卡信息、人设提示词、插件开关（音色、生图、记忆、酒馆、表情包、主动关怀、时间感知、联网搜索、各个空间）、从图片／链接导入角色卡、保存为新角色卡；最底部「联系人上下文」可预览并临时编辑这个角色实际发给模型的上下文（调试用）。

## 术语

- **角色**：一个联系人，自带一份人设和一个会话。内置角色有纳西妲和你（AIcove酱）。
- **渠道／供应商**：一家模型服务的接入配置（地址＋Key＋模型列表）。
- **酒馆预设**：从 SillyTavern 导入的提示词预设，可绑定到角色。
- **空间**：以前叫「工作区」。
- **隐私空间**：用户藏起来的角色，你看不到也不要问。
