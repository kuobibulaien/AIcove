# 插件与生效规则（2026-10）

## 插件清单

| id | 名字 | 角色编辑页上的开关 | 作用 |
|---|---|---|---|
| tts | 语音合成 | 音色 | 把带标记的文本转成语音；语音通话也属于它 |
| image | 绘图工具 | 生图 | 工具调用或 `<image>` 标签生图；生图模型在「设置 · 插件 · 绘图」配 |
| sticker | 表情包 | 表情包 | 把 <sticker tag="标签"/> 换成表情包图片 |
| memory | 长期记忆 | 记忆 | 请求时带上角色的长期记忆，压缩时整理（聊天模型没有记忆工具） |
| trigger | 主动回复 | 主动回复 | AI 主动发消息、打电话 |
| time_awareness | 时间感知 | 时间感知 | 按角色选择是否告诉模型现在几点，并提供上次发消息的时间 |
| web_search | 联网搜索 | 联网搜索 | 智能体模式下由后台杂活助手代为搜索；工具模式直接搜索 |
| mcp:<id> | MCP 连接器 | 各连接器名 | 外部工具服务，必须在角色里显式开启 |
| （空间） | 空间授权 | 空间 · 名字 | 允许这个角色派出的杂活助手读写某个空间 |
| delegate_task | 派活（内置，不可关） | — | 仅智能体模式的角色拥有：前台模型把上网、读写文件的事交给后台杂活助手。纯聊天与工具模式不派活 |
| 酒馆兼容（内置） | 预设、正则、世界书、MVU 变量 | 酒馆 | |

角色编辑页的插件开关在「管理开启的插件」里；用户说「插件选择」时指的就是这里。你用 aicove_set_role_plugins 只能开关上表前七个普通插件；MCP 连接器和空间授权保持原样，要改请用户去角色编辑页。

时间感知是否告诉模型现在几点，按角色设置：在角色编辑页点「时间感知」修改，也可用 aicove_set_role_plugins 的 current_time 修改；时间感知的提示词由所有角色共用。

## 一个插件在某个角色上生效，要同时满足

1. 角色选中了它：「全部插件」包含所有普通插件，但 MCP 连接器和空间不在「全部」里，要显式勾选；新建角色默认一个都没选，这是「插件没生效」最常见的原因；
2. 模型支持工具调用（绘图工具、派活等靠工具的插件）：角色处于工具模式或智能体模式，渠道里模型没关工具调用，且（智能体模式下）绑定的酒馆预设没把函数调用关掉；
3. 插件自己的配置齐全：比如语音要有音色预设和 Key，绘图要有生图模型，联网搜索要配搜索供应商。

角色有三种模式（角色编辑页「角色模式」里切换，也可用 `aicove_role` 修改 `agent_mode`）：

- **纯聊天**（`chat`，默认）：不带任何 AIcove 工具（`tools` 为空），记忆、时间感知、语音 `<tts>`、表情包 `<sticker/>`、生图 `<image>` 等标签与提示词插件照常生效。
- **工具**（`tool`）：正常的单层 Agent，前台直接使用角色开启的全部插件工具、工作区与 AIcove 管理工具，不派活。AIcove酱固定是工具模式。
- **智能体**（`agent`）：前台作为带人设的路由层，保留轻量直出插件工具，联网搜索、MCP 和读写工作区通过 `delegate_task` 交给后台子 Agent 去执行，结果以「杂活回执」回来。

用户问「为什么这个角色没去搜索／不派活」时，先用 aicove_read_role 看 agent_mode。

插件关掉后，请求副本里会屏蔽它的标签和工具调用，原始聊天记录不动；重新打开就恢复。

## 提示词包（语音、绘图，2026-10-19 起）

发给聊天模型的「怎么写语音标签」「怎么写生图提示词」说明不再是全局一份，而是按模型家族分成提示词包：

- 语音出厂包：Fish Audio S2（方括号情绪／发声标签＋自然语言）、Fish Audio S1（圆括号标签）、MiniMax（语气词与停顿）、IndexTTS、阿里云／CosyVoice（不写标签）、通用兜底。
- 绘图出厂包：NovelAI（danbooru 标签、权重、{default_width} 等变量）、NovelAI 分镜漫画（只能手选）、MOSS 多格漫画、ComfyUI 通用、danbooru 标签类（Illustrious、Pony、SDXL…；ComfyUI 渠道默认走通用包，要用得手选）、自然语言（GPT Image、Flux、Seedream、Gemini 等，兜底）。漫画包带后处理，只能配对应渠道。
- 每个包由若干「节」组成，每节有发送位置（scope）：语音 chat／chat.off（频率 0 时）／call（语音通话）；绘图 inline（聊天里的 `<image>` 说明）和 tool.*（调用模式 draw_image 工具的各项说明）。
- 音色预设、绘图预设各自选一个包，或选「自动」：按渠道格式和模型名从上往下找第一个匹配的包（自建包优先），都不匹配用兜底包。预设还可以有只属于自己的「专属节」。绘图的优先顺序是角色绑定的生图方案、预设绑定的包、自动匹配；画风（绘图预设）和方案可以自由组合。自定义方案能导入导出 JSON。
- 出厂包可以改正文、关掉某节、加节，改过的可以恢复默认；出厂包的名字和匹配规则不能改，要改就另存为自建包。包是共享的：改它影响所有用它的预设。
- 用户在「设置 · 插件 · 语音／绘图 · 提示词包」或预设编辑页的「提示词」里看和改；预设编辑页能预览发给模型的最终全文。
- 你用 aicove_list_prompt_packs 看包和预设的绑定，aicove_read_prompt_pack 读全文（给 preset_id 会附渲染后的最终文本），改动用 aicove_edit_prompt_section／aicove_add_prompt_section／aicove_fork_prompt_pack／aicove_bind_prompt_pack，都能撤销。

## 排查顺序

先调用 aicove_inspect_context 看 `plugins` 里该插件 `injected` 是否为 true 以及 `reason`，再看 `tools` 里有没有对应工具，最后对照上面四条逐项确认。
