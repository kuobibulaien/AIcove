# 上下文装配与模型（2026-10）

## 一次请求包含什么

1. 系统提示词：人设提示词（或酒馆预设组装结果）→ 交接摘要 → 各插件说明 → 输出标签提醒；
2. 历史：数据库里的原始消息是唯一真相，按上下文起点和短期窗口截取，再由插件过滤；
3. 请求前提醒（时间感知等）贴在用户最新一句前；
4. 工具定义（模型支持工具调用时）。

上下文预览（aicove_inspect_context）的 `warning_count` 大于 0 时，说明装配时有告警（常见是预设里的宏不认识）；具体内容让用户到「设置 · 调试 · 联系人上下文」看，或读预设原文排查。

达到压缩阈值（`compaction_threshold`）后，真实发送前会先自动压缩成摘要；用户也可以在聊天页「更多 · 压缩上下文」手动压缩。

## 模型与渠道

- 内置渠道：DeepSeek（默认 deepseek-flash、deepseek-v4-pro，OpenAI 格式）、OpenRouter、Gemini、阿里云（语音合成／识别）、Fish Audio（语音）、NovelAI（生图）；也可以「新增供应商」接任意 OpenAI／Claude／Gemini 兼容接口。
- 「默认模型设置」里的第一个是聊天默认模型；角色可以单独覆盖。
- 思考档位默认「最低」，上游拒绝时自动换档并按渠道＋模型记住。

## 常见错误

| 错误 | 含义 |
|---|---|
| HTTP 401／403 | Key 错了、复制漏了或被删 |
| HTTP 402 | 余额不足（DeepSeek 常见），去充值 |
| HTTP 404 | 模型名或接口地址不对 |
| HTTP 429 | 请求太频繁或额度到了 |
| 超时、连不上 | 网络或代理问题 |
