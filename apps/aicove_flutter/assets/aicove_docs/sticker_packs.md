# 表情包：导入与打标

给 AIcove酱 看的资料。用户问表情包的事（怎么用、怎么导入、怎么打标签、为什么没发出来），先读这一篇再答。

## 你能做什么

- **从网页链接导入一套表情**：`aicove_sticker_import_url`。它会抓取页面里的表情图（公众号图片消息这类），新建一套表情。这一步会下载外部文件，默认直接执行，开启「修改前每次问我」后才逐次确认；撤销会删除这套表情。
- **给表情改标签**：`aicove_sticker_set_tags`。一次最多 200 张，直接生效，可撤销。
- **看图打标**：用 workspace_read 读 aicove 空间的 stickers/ 看图，再用 aicove_sticker_set_tags 打标签。
- 解释用法、帮忙想标签、用工作区的文件工具整理素材。

## 你做不到的

- **抓取不到的页面**：需要登录、需要点击展开、或者图片不在页面里的，抓不到。导入失败时如实说，不要编张数。
- 不能替用户决定版权问题。

## 导入流程

1. 只导入用户给出的链接。先说清楚要导入什么、导入后会在哪里看到。
2. 调用 `aicove_sticker_import_url`。工具会返回套组名、导入张数、跳过的小图张数，以及每张表情的 id。
3. 如实告诉用户结果：导入了几张，跳过了几张（小图或头像）。新表情都是「未标注」，**不会被发出**，直到打了标签。
4. 用 `workspace_read` 读取 aicove 空间的 `stickers/index.md` 与图片，再用 `aicove_sticker_set_tags` 按 id 打标签。当前模型不支持图片时，如实说明并建议换支持图片的模型。
5. 提醒：公众号表情常带水印或版权信息，请用户确认自己有权使用。

## 用户怎么用（可以直接转述）

- 设置 → 表情包：选图片或 ZIP 导入；ZIP 每个一级文件夹是一个套组。
- 文件名就是标签：`开心-2.png` 得到「开心」，`猫猫 摇尾巴.gif` 得到「猫猫」「摇尾巴」。`IMG_1234`、`微信图片_…` 这类没有意义的名字标为「未标注」，要用户手动补，AI 才会用。
- 表情包只在聊天模型输出 `<sticker tag="标签"/>` 时发出，不用方括号。

## 打标签规则

- 标签 2～4 个字最好，写情绪或动作：开心、委屈、摸鱼、晚安、抱抱。
- 一张表情 1～3 个标签，不要堆砌近义词（同义词表库里已经有）。
- 不要用 `<`、`>`、引号、方括号，单个标签不超过 16 个字。

## 常见问题

- **表情没发出来**：先看是不是没有对应标签的表情，或者套组被停用了；不要承诺「下次一定能发」。
- **想一次性把所有表情都发出去**：不行，每轮回复最多一张，克制使用。
