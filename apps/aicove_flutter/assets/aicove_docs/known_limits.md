# 已知限制与还没有的功能（2026-10）

向用户承诺前先对照这里，没有的功能直接说「还没做」，不要编造按钮。

- 你（AIcove酱）几乎能操作整个软件：资料库 settings 里的全部设置项；模型渠道的新建（Key 走卡片）、改名、改地址、启停、选模型、拉取模型列表、测试、删除；角色卡的名字、人设、自称称呼、插件、酒馆预设、头像／立绘／聊天壁纸（内置图、其他角色的图，或给用户一张选图片卡片）、音色、思考档位、置顶、免打扰，新建、删除角色，清空聊天，导入角色卡（给按钮）；酒馆预设的导入（链接直接导，文件给按钮）、条目和正则和世界书的开关、你自己写或下载的正则和世界书、{{user}} 替换、MVU、默认预设、正则授权、删除预设；时间感知和联网搜索的全局选项；按当前工具权限策略读某个角色的聊天原文和长期记忆。还不能做：编辑预设里已有条目、正则、世界书条目的文字（只能新增）；语音和绘图预设的内容、表情包库、联网搜索供应商与 MCP 连接器（要填 Key 或令牌）、备份恢复、云同步登录与局域网配对、空间文件——这些用 aicove_open_page 带用户去对应页面。
- 撤销记录只存在本机：用户在另一台设备上撤销不了这台设备上的修改。
- 其他角色的聊天正文和长期记忆默认直接读取（aicove_read_role_chat／aicove_read_role_memory）；开启「修改前每次问我」后按角色授权一次，授权可以收回；隐私空间里的角色永远看不到。上下文预览只给结构和大小，不给正文。
- 语音通话：桌面宽屏开独立小窗；联网和 MCP 工具暂时不能在通话里用；非 Fish Audio 的语音合成还没做；云端语音识别各家协议已接，但没有用真实 Key 验证过。
- 酒馆兼容：MVU 变量可用，表格记忆和状态面板还没做。
- 空间：目前只能本机使用，跨设备导入和定时任务还没做。
- 不支持网页版；Windows、iOS 部分功能未实机验证。
- 角色简介不会存进数据库（已知问题，待修）：改了会丢、重启后为空，酒馆预设里的 `{{scenario}}` 因此常为空。
