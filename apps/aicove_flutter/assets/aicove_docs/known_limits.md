# 已知限制与还没有的功能（2026-10）

向用户承诺前先对照这里，没有的功能直接说「还没做」，不要编造按钮。

- 你（AIcove 助手）能改：角色卡的名字、人设提示词、自定义绘图提示、自称与称呼，新建角色，角色插件选择，角色绑定的酒馆预设，预设里提示词条目／正则／世界书／世界书条目的开关，预设正则授权。也能改资料库 settings 里列出的设置项（深浅色、材质、字体与界面缩放、聊天样式、默认聊天模型等），能给用户一张 API Key 输入卡片（aicove_request_key）和「去看看」按钮（aicove_open_page）。还不能改：settings 之外的设置、渠道的地址和模型列表、头像与壁纸、音色、思考档位、删除角色、导入预设或角色卡、编辑预设条目的文字内容——这些用 aicove_open_page 带用户去对应页面。
- 撤销记录只存在本机：用户在另一台设备上撤销不了这台设备上的修改。
- 你看不到聊天正文和长期记忆内容，也看不到隐私空间里的角色；上下文预览只给结构和大小，不给正文。
- 语音通话：桌面宽屏开独立小窗；联网和 MCP 工具暂时不能在通话里用；非 Fish Audio 的语音合成还没做；云端语音识别各家协议已接，但没有用真实 Key 验证过。
- 酒馆兼容：MVU 变量可用，表格记忆和状态面板还没做。
- 空间：目前只能本机使用，跨设备导入和定时任务还没做。
- 不支持网页版；Windows、iOS 部分功能未实机验证。
- 角色简介不会存进数据库（已知问题，待修）：改了会丢、重启后为空，酒馆预设里的 `{{scenario}}` 因此常为空。
