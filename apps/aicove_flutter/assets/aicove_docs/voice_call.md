# 语音通话（2026-10）

## 怎么打

- 聊天页右上角的电话图标。拨号前会先检查配置，配不齐只弹提示「无法通话：原因」，不进通话页；体检工具 aicove_checkup 会对开了语音的角色做同样的检查。
- 接通后角色先打招呼。默认半双工：角色在想或在说时话筒不送识别，等它说完再说。
- 打字也进通话：切回聊天或通话在小窗里时，话筒照常开着，说话和打字都算这通电话。
- 桌面（Mac／Windows）宽屏时通话在独立小窗里，关小窗就是挂断；窄屏和手机嵌在聊天页，左上角可以收起成悬浮窗。
- 挂断后聊天里出现一条通话气泡（电话图标＋时长），点开是逐句记录；后台随后整理通话摘要，之后模型看到的是「[语音通话 时长]＋通话摘要」。没接通不留记录。
- 角色也可能主动来电（主动关怀插件），没接会留一条「未接来电」。

## 打通一个电话需要三样

1. **音色**：角色绑定一个音色预设（角色编辑页「音色」；预设在「设置 · 插件 · 语音」里管理）。**通话目前只支持 Fish Audio 音色**，别家的合成在语音条里能用，打电话会提示不支持。音色预设要填 Fish Audio 的音色 ID（reference_id）。
2. **Fish Audio 的 Key**：「设置 · 模型」里的 Fish Audio 渠道要填 Key（可以用 aicove_request_key 给用户一张输入卡片）。
3. **语音识别来源**：在「设置 · 插件 · 语音 · 语音通话」里选：
   - 自动（默认）：装了本地模型就用本地，否则用渠道里第一个能用的识别模型；
   - 本地模型：在同一页下载（离线、不花钱）；
   - 渠道里的识别模型：阿里云、火山、腾讯、讯飞、OpenAI Realtime、Deepgram、ElevenLabs 都接了协议，但现在的适配器都还没用真实 Key 验证过，用户报问题时如实说明。识别来源只存在这台设备上，换设备要重选。

## 常见提示 → 怎么办

| 提示 | 处理 |
|---|---|
| 此角色没有可用的音色 | 角色编辑页给它绑一个音色预设 |
| 通话目前只支持 Fish Audio 音色 | 换成 Fish Audio 的音色预设 |
| 音色预设还没有填写 Fish Audio 音色 ID | 在音色预设里填 reference_id |
| Fish Audio 渠道还没有填写 API Key | 给 Fish Audio 渠道填 Key |
| 本机还没有安装本地识别模型 | 去「语音 · 语音通话」下载，或换识别来源 |
| 还没有可用的语音识别 | 下载本地模型，或在某个渠道里添加识别模型并填好 Key |
| 选中的识别模型已不在渠道商里 | 在「语音 · 语音通话」重新选 |

## 通话里的限制

- 通话里模型的思考能关就关，关不了就用最低档，回复短；联网搜索、MCP 等工具暂时不能在通话里用。
- 说完到听见回答一般 2.5～4 秒。
- 外放时角色说话不会被自己的声音打断（半双工）；还不能边说边打断角色。
