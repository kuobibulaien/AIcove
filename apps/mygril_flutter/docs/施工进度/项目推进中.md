## 2026-02-24

- 重构：**HTTP 网络策略改为“全自动”，移除用户代理配置**
  - 现象：App 曾受历史代理设置影响（如手动 `127.0.0.1:7890`），在手机上会把请求打到“手机自己”，导致外网请求失败
  - 原因：
    - 启动时会读取 `proxy_config` 并覆盖全局 `HttpOverrides`
    - 该配置可被设置页“网络与代理”改成手动/直连，错误值会长期保存在本地
  - 调整：
    - `main.dart`：删除读取本地 `proxy_config` 的逻辑，启动时只安装自动网络策略
    - `windows_proxy_http_overrides.dart`：删除手动/直连分支，改为系统代理探测 + 环境变量回退 + Android 常见本地代理端口自动探测（`127.0.0.1:7890/7897/...`）
    - `settings_models.dart`、`app_settings.dart`：删除 `ProxyConfig` 模型及 `proxy_config` 读写方法
    - `settings_page.dart`：移除“网络与代理”入口
    - 删除页面：`ui/features/settings/pages/proxy_settings_page.dart`
  - 验证：
    - 已执行 `flutter run`（真机 `2211133C`），应用可安装并启动
    - 启动日志显示：`Android proxy override installed (no system proxy detected → env / direct)`
  - **状态：已完成** ✅

## 2026-02-23

- 修复：**聊天输入框与键盘/更多面板联动不稳（部分机型被键盘遮挡）**
  - 现象：输入框会“先跳到中部”，键盘还没完全弹起；在全局 UI 缩放下，输入框抬升高度偏小，出现“被键盘挡住一截”
  - 原因：
    - 聊天页采用自定义键盘面板（`resizeToAvoidBottomInset: false`），输入区高度由代码手动计算
    - 旧逻辑在键盘高度回落到 0 的瞬间会回退到缓存高度，且未处理全局 UI 缩放换算，导致不同设备/输入法下高度不一致
  - 调整：
    - `composer.dart`：改为“系统 `MediaQuery.viewInsets` 为主，插件高度兜底”
    - `composer.dart`：新增输入态锚点高度（`_anchorPanelHeight`），保证“键盘 ↔ 更多面板”切换时输入框不跳动
    - `composer.dart`：去掉输入框点击时对键盘的强制预动画，改为原生 focus 驱动，让输入框跟随键盘自然抬升
    - `composer.dart`：修复“键盘态点加号直接收回”竞态，切到 more 时按 `readOnly -> 切 other -> hide 键盘` 的顺序执行
    - `composer.dart`：`none` 回调新增“正在切 more”保护，避免中途把 more 状态冲掉
    - `chat_message_list.dart`：底部 fallback padding 增加 UI 缩放换算，确保最后一条消息始终贴输入框上沿
  - 涉及文件：
    - `lib/src/features/chat/presentation/widgets/composer.dart`
    - `lib/src/ui/features/chat/widgets/chat_message_list.dart`
  - **状态：已完成** ✅
