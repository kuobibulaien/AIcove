## 🛠️ 服务使用示例

### 发送消息

```dart
class ChatPage extends ConsumerWidget {
  void _sendMessage(WidgetRef ref, String text) async {
    final chatActions = ref.read(chatActionsProvider);
    
    try {
      await chatActions.send(text);
    } catch (e) {
      MoeToast.error(context, '发送失败: $e');
    }
  }
}
```

### 更新设置

```dart
void _updateModel(WidgetRef ref, String modelName) async {
  final notifier = ref.read(appSettingsProvider.notifier);
  
  await notifier.setDefaultModel(modelName);
  MoeToast.success(context, '已切换到 $modelName');
}
```

### 导入新渠道

```dart
void _importProvider(WidgetRef ref) async {
```

## 📐 设计原则

### 1. 门面模式
```
外部调用 → ChatActions (门面)
              ↓
  ChatSendService ← ChatRequestExecutor
              ↓
  ChatMessageProcessor ← ChatTtsHandler
```

### 2. 职责分离
- **服务层**：纯业务逻辑，不依赖 UI
- **数据层**：数据持久化和访问
- **领域层**：数据模型定义
- **表现层**：UI 组件和页面

### 3. 依赖注入
- 使用 Riverpod Provider 管理依赖
- 服务之间通过 Provider 互相访问
- 避免直接实例化，方便测试
