## 📋 各目录职责说明

### `lib/src/core/` - 公共基础设施

这是"零件箱"，放所有功能模块都可能用到的东西。

| 子目录 | 职责 | 放什么 |
|--------|------|--------|
| `api/` | API 通信 | REST 客户端、AI API 封装 |
| `database/` | 数据持久化 | Drift 数据库、Repository |
| `models/` | 通用数据模型 | 多个功能模块共用的模型 |
| `theme/` | 主题系统 | 颜色、字体、圆角等 tokens |
| `widgets/` | 公共组件 | 按钮、输入框、弹窗等 |
| `utils/` | 工具函数 | 格式化、解析、计算等 |
| `services/` | 通用服务 | 日志、触觉反馈等 |

### `lib/src/features/` - 功能模块

每个功能模块遵循 **Clean Architecture** 分层：

```
features/xxx/
├── domain/                # 领域层：业务模型、接口定义
│   ├── models/           # 业务实体
│   └── repositories/     # 仓库接口（可选）
│
├── data/                  # 数据层：实现细节
│   ├── services/         # 业务服务
│   ├── repositories/     # 仓库实现
│   └── datasources/      # 数据源
│
├── providers/             # 状态层：Riverpod Provider
│   └── xxx_provider.dart
│
└── presentation/          # 表现层：UI
    ├── pages/            # 页面
    └── widgets/          # 页面专用组件
```

### 各 Feature 模块职责

| 模块 | 职责 | 包含内容 |
|------|------|----------|
| `chat` | 聊天核心 | 消息发送/接收、对话管理、聊天页面 |
| `characters` | 角色管理 | 角色卡展示、编辑、详情页 |
| `settings` | 应用设置 | 设置页面、Provider 配置、模型管理 |
| `auto_reply` | 主动消息 | 触发器管理、上下文分析 |
| `plugins` | 插件系统 | TTS/记忆/表情等插件管理 |
| `memory` | 记忆系统 | 记忆存储、召回 |
| `sync` | 云同步 | 数据备份同步 |
| `emoji` | 表情系统 | 表情解析、展示 |
| `tts` | 语音播放 | TTS 播放控制 |

## 📝 文件命名规范

### 1. 页面文件

```
xxx_page.dart      # 完整页面
xxx_dialog.dart    # 弹窗
xxx_sheet.dart     # Bottom Sheet
```

### 2. 组件文件

```
xxx_widget.dart    # 通用组件
xxx_card.dart      # 卡片组件
xxx_list_item.dart # 列表项
xxx_button.dart    # 按钮
```

### 3. 逻辑文件

```
xxx_provider.dart  # Riverpod Provider
xxx_notifier.dart  # StateNotifier/AsyncNotifier
xxx_controller.dart# 控制器
xxx_service.dart   # 业务服务
xxx_repository.dart# 数据仓库
xxx_api.dart       # API 封装
```

### 4. 模型文件

```
xxx.dart           # 领域模型（如 conversation.dart）
xxx_model.dart     # 视图模型或 DTO
```

## 🚨 禁止事项

### 1. 禁止放错位置

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| 把设置页面放在 `chat/presentation/pages/` | 放在 `settings/presentation/pages/` |
| 把通用模型放在 `features/xxx/` | 放在 `core/models/` |
| 把业务逻辑写在 Widget 里 | 抽到 Provider 或 Service |

### 2. 禁止创建巨型文件

| 阈值 | 处理方式 |
|------|----------|
| 文件超过 400 行 | 考虑拆分 |
| 文件超过 600 行 | 必须拆分 |
| 单个类超过 300 行 | 考虑拆分职责 |

### 3. 禁止留存废弃文件

| 类型 | 处理方式 |
|------|----------|
| `.bak` 文件 | 删除或移到专门的 backup 分支 |
| `.backup` 文件 | 删除或移到专门的 backup 分支 |
| 注释掉的大段代码 | 删除（Git 会记录历史） |
