# 模型导入界面改造方案 (修订版)

> 创建日期：2026-01-21  
> 参考素材：`参考素材/kelivo-master/lib/features/provider/`  
> 目标：一比一复刻 kelivo 的供应商管理界面，接入项目公共组件，适配多用途标签标识。

---

## 📋 改造目标概览

将现有的「模型列表页 + 导入弹窗」改造为 kelivo 风格的「供应商管理系统」，包括：
1. **列表页复刻** - 移除顶部分组，改为单列列表，一比一复刻 kelivo UI。
2. **详情页复刻** - 采用 kelivo 的供应商详情页布局（配置 + 模型双 Tab），接入我们的公共组件。
3. **添加流程复刻** - 采用 kelivo 的底部弹窗流程，增加「模型用途」手动选择步骤。
4. **组件对齐** - 使用 `MoeSettingsGroup`、`MoeSettingsRow` 等公共组件，确保接入项目主题系统。

---

## 🏷️ 与 kelivo 的核心差异：模型用途标识

由于我们的系统支持多种模型用途（对话、嵌入、图片、语音），我们在复刻基础上做如下适配：
1. **能力标签**：在供应商名称后紧跟小标签（如 `[对话]` `[语音]`）。
2. **导入分类**：导入模型时，需手动勾选导入的用途，这会影响后续配置模版。
