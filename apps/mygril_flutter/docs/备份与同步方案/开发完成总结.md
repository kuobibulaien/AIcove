# 数据备份功能开发总结

> 📅 完成日期：2026-01-20  
> 📁 功能模块：离线导入导出 + 云同步设置

## 一、功能概述

实现了完整的数据备份管理功能，包括：
- **离线导出**：将角色和聊天记录打包为 `.aicove` 文件
- **离线导入**：从备份文件还原数据，支持冲突处理
- **云同步设置**：离线模式开关 + 自定义服务器配置 + 同步范围选择

## 三、核心模型 (export_format.dart)

| 类名 | 用途 |
|------|------|
| `SyncScope` | 同步范围常量（聊天记录、角色卡、设置等） |
| `ExportOptions` | 导出选项（包含图片/音频、选择的范围） |
| `ExportProgress` | 导出进度状态 |
| `ExportResult` | 导出结果（文件路径、统计信息） |
| `ImportMode` | 导入模式枚举 |
| `ImportPreview` | 导入预览信息 |
| `ConversationPreview` | 单个角色预览 |
| `ImportConflict` | 冲突信息 |
| `ImportConflictResolution` | 冲突解决策略（合并/新建/替换/跳过） |
| `ExportManifest` | 导出清单（manifest.json 结构） |

## 四、服务层

### ConversationExporter - 导出服务

```dart
// 核心方法
Future<ExportResult> export(ExportOptions options);

// 内部流程
1. 查询选中的 conversations + messages + blocks
2. 复制关联的媒体文件到临时目录
3. 生成 manifest.json + conversations.json + messages.json
4. 打包为 ZIP 文件（.aicove 格式）
5. 返回文件路径和统计信息
```

### ConversationImporter - 导入服务

```dart
// 核心方法
Future<ImportPreview> preview(String filePath);  // 预览备份文件
Future<ImportResult> import(ImportPreview preview, ...);  // 执行导入

// 冲突处理策略
- createNew: 创建新角色（添加副本后缀）
- merge: 合并到现有角色（追加消息）
- replace: 替换现有角色
- skip: 跳过不导入
```

## 五、UI 页面

### 1. DataManagementPage - 数据管理主页

**入口**：设置页 → 数据管理

**包含内容**：
- 离线备份区：导出/导入入口
- 云同步服务区：离线模式开关、自定义服务器配置
- 同步范围区：各数据类型的同步开关

### 2. 导出流程

```
ExportScopePage → ExportCharacterPage
   ↓                    ↓
选择数据范围        选择角色 → 导出 → 分享文件
（聊天/角色卡等）    （可预览聊天）
```

### 3. 导入流程

```
ImportFilePage → ImportPreviewPage
   ↓                    ↓
选择 .aicove 文件   预览内容 → 选择范围/角色 → 处理冲突 → 导入
```
