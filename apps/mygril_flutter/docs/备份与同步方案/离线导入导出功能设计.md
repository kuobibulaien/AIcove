# 离线导入导出功能设计

> 版本：v1.0  
> 日期：2024-12-31  
> 状态：设计稿

## 1. 功能概述

### 1.1 目标

实现角色聊天记录的离线导入导出功能，让用户可以：

- **导出**：将某个角色的完整聊天记录（含图片、语音等多媒体）打包成单个文件
- **导入**：从文件恢复聊天记录到当前设备，支持与已有数据合并

### 1.2 使用场景

| 场景 | 说明 |
|-----|------|
| 换手机 | 旧手机导出 → 传文件 → 新手机导入 |
| 分享角色 | 把调教好的角色分享给朋友 |
| 备份 | 定期导出到网盘/电脑保存 |
| 恢复 | 卸载重装后恢复数据 |

### 1.3 设计原则

1. **一个文件包含所有内容** —— 用户不需要管理多个文件
2. **离线可用** —— 不依赖服务器
3. **版本兼容** —— 旧版本导出包可在新版本导入
4. **支持多模态** —— 图片、语音、视频都能导出
5. **可选择性导入** —— 可以只导入部分内容，支持合并

## 2. 文件格式设计

### 2.1 文件扩展名

```
.mygril
```

实际上是 ZIP 格式，改了扩展名。用户双击可以用解压软件打开查看。

### 2.2 文件结构

```
export_角色名_20241231.mygril (ZIP格式)
│
├── manifest.json           # 元数据（版本、导出时间等）
├── conversation.json       # 角色/会话信息
├── messages.json           # 全部聊天记录
├── settings.json           # 角色特定设置（可选）
│
└── files/                  # 附件目录
    ├── avatar.jpg          # 角色头像
    ├── character_bg.jpg    # 角色背景图
    ├── voice_preset.mp3    # 角色音色样本
    ├── img_001.jpg         # 聊天中的图片
    ├── img_002.png
    ├── audio_001.m4a       # 语音消息
    └── video_001.mp4       # 视频消息
```

### 2.3 manifest.json（元数据）

```json
{
  "format_version": 1,
  "app_version": "1.0.0",
  "app_name": "MyGril",
  "export_time": "2024-12-31T16:30:00.000Z",
  "export_device": "Android / Pixel 7",
  "conversation_id": "conv_abc123",
  "character_name": "小雪",
  "message_count": 1234,
  "file_count": 56,
  "total_size_bytes": 32456789,
  "checksum": "sha256:abcdef..."
}
```

**字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| `format_version` | int | ✅ | 导出格式版本，用于兼容性判断 |
| `app_version` | string | ✅ | 导出时的 App 版本 |
| `app_name` | string | ✅ | 固定为 "MyGril" |
| `export_time` | ISO8601 | ✅ | 导出时间 |
| `export_device` | string | ❌ | 导出设备信息 |
| `conversation_id` | string | ✅ | 原始会话ID |
| `character_name` | string | ✅ | 角色名称 |
| `message_count` | int | ✅ | 消息数量 |
| `file_count` | int | ✅ | 附件数量 |
| `total_size_bytes` | int | ❌ | 解压后总大小 |
| `checksum` | string | ❌ | 文件完整性校验 |

#### 导出流程伪代码

```dart
Future<ExportResult> exportConversation(...) async {
  // 1. 创建临时目录
  final tempDir = await getTemporaryDirectory();
  final exportDir = Directory('${tempDir.path}/export_$conversationId');
  await exportDir.create();
  final filesDir = Directory('${exportDir.path}/files');
  await filesDir.create();
  
  // 2. 查询数据
  final conversation = await database.getConversation(conversationId);
  final messages = await database.getMessages(conversationId);
  
  // 3. 复制文件并记录映射
  final fileMapping = <String, String>{};  // 原路径 → ZIP内路径
  
  // 复制头像
  if (conversation.avatarPath != null) {
    final newPath = 'files/avatar${_ext(conversation.avatarPath!)}';
    await _copyFile(conversation.avatarPath!, '${exportDir.path}/$newPath');
    fileMapping[conversation.avatarPath!] = newPath;
  }
  
  // 复制消息附件
  for (final msg in messages) {
    for (final block in msg.blocks) {
      if (_isMediaBlock(block) && options.shouldInclude(block.type)) {
        final originalPath = block.data['file_path'];
        if (originalPath != null && await File(originalPath).exists()) {
          final newPath = 'files/${block.id}${_ext(originalPath)}';
          await _copyFile(originalPath, '${exportDir.path}/$newPath');
          fileMapping[originalPath] = newPath;
        }
      }
    }
  }
  
  // 4. 生成 JSON 文件（路径替换）
  await _writeManifest(exportDir, conversation, messages, fileMapping);
  await _writeConversation(exportDir, conversation, fileMapping);
  await _writeMessages(exportDir, messages, fileMapping);
  
  // 5. 打包成 ZIP
  final archive = Archive();
  await _addDirectoryToArchive(archive, exportDir);
  final zipBytes = ZipEncoder().encode(archive);
  
  final fileName = 'export_${conversation.displayName}_${_dateStr()}.mygril';
  final outputFile = File('${tempDir.path}/$fileName');
  await outputFile.writeAsBytes(zipBytes!);
  
  // 6. 清理临时目录
  await exportDir.delete(recursive: true);
  
  return ExportResult(
    file: outputFile,
    messageCount: messages.length,
    fileCount: fileMapping.length,
    sizeBytes: await outputFile.length(),
  );
}
```

### 4.4 导入流程伪代码

```dart
Future<ImportResult> import(...) async {
  // 1. 解压 ZIP
  final bytes = await file.readAsBytes();
  final archive = ZipDecoder().decodeBytes(bytes);
  
  // 2. 解压到临时目录
  final tempDir = await getTemporaryDirectory();
  final importDir = Directory('${tempDir.path}/import_${DateTime.now().millisecondsSinceEpoch}');
  await _extractArchive(archive, importDir);
  
  // 3. 读取并验证 manifest
  final manifest = await _readManifest(importDir);
  if (manifest.formatVersion > CURRENT_FORMAT_VERSION) {
    throw ImportError('文件版本过新，请更新 App');
  }
  
  // 4. 读取 conversation 和 messages
  final convJson = await _readConversation(importDir);
  final messagesJson = await _readMessages(importDir);
  
  // 5. 处理文件：复制到应用目录
  final fileMapping = <String, String>{};  // ZIP内路径 → 本地路径
  final filesInZip = importDir.listSync(recursive: true)
      .whereType<File>()
      .where((f) => f.path.contains('/files/'));
  
  for (final zipFile in filesInZip) {
    final relativePath = path.relative(zipFile.path, from: importDir.path);
    final localPath = await fileStorage.saveImportedFile(zipFile, relativePath);
    fileMapping[relativePath] = localPath;
  }
  
  // 6. 根据模式处理
  String conversationId;
  int skipped = 0;
  
  switch (mode) {
    case ImportMode.create:
      // 生成新 ID
      conversationId = 'conv_${DateTime.now().millisecondsSinceEpoch}';
      final conversation = Conversation.fromImportJson(convJson, conversationId, fileMapping);
      await database.insertConversation(conversation);
      
      for (final msgJson in messagesJson['messages']) {
        final msg = Message.fromImportJson(msgJson, conversationId, fileMapping);
        await database.insertMessage(msg);
      }
      break;
      
    case ImportMode.merge:
      conversationId = targetConversationId!;
      final existingMsgIds = await database.getMessageIds(conversationId);
      
      for (final msgJson in messagesJson['messages']) {
        final originalId = msgJson['id'];
        if (existingMsgIds.contains(originalId)) {
          skipped++;
          continue;
        }
        final msg = Message.fromImportJson(msgJson, conversationId, fileMapping);
        await database.insertMessage(msg);
      }
      break;
      
    case ImportMode.replace:
      // 危险操作，需要先确认
      conversationId = targetConversationId!;
      await database.deleteAllMessages(conversationId);
      // ... 然后像 create 模式一样导入
      break;
  }
  
  // 7. 清理临时目录
  await importDir.delete(recursive: true);
  
  return ImportResult(
    conversationId: conversationId,
    characterName: convJson['display_name'],
    messagesImported: messagesJson['messages'].length - skipped,
    filesImported: fileMapping.length,
    skipped: skipped,
  );
}
```

## 5. 版本兼容性策略

### 5.1 版本号规则

```
format_version: 1  → 初始版本
format_version: 2  → 新增字段或 block 类型
format_version: 3  → 结构性变更
```

### 5.2 兼容性处理

```dart
Future<void> _migrateIfNeeded(Map<String, dynamic> manifest, Directory importDir) async {
  final version = manifest['format_version'] as int;
  
  if (version < 2) {
    // v1 → v2 迁移：补充缺失字段
    // 例如：旧版本没有 blocks，只有 content
  }
  
  if (version < 3) {
    // v2 → v3 迁移
  }
  
  // 更新 manifest
  manifest['format_version'] = CURRENT_FORMAT_VERSION;
}
```

### 5.3 向后兼容原则

- **新版本导出的文件**：旧版本 App 应该能读取核心内容（消息文本），忽略不认识的字段
- **旧版本导出的文件**：新版本 App 负责迁移，补充缺失字段

## 8. 错误处理

### 8.1 导出错误

| 错误 | 处理 |
|-----|------|
| 磁盘空间不足 | 提示用户清理空间 |
| 文件写入失败 | 检查权限，重试 |
| 数据库读取失败 | 显示错误信息 |

### 8.2 导入错误

| 错误 | 处理 |
|-----|------|
| 文件格式无效 | 不是有效的 .mygril 文件 |
| 版本不兼容 | 文件版本过新，请更新 App |
| 文件损坏 | manifest.json 缺失或无法解析 |
| 校验失败 | 文件可能被篡改 |
