# MyGril 公共组件统一规范方案

> 编写日期：2025-12-28
> 基于 Kelivo 项目参考设计
> 适用项目：MyGril Flutter App

---

## 📋 概述

### 当前问题

由于项目由 AI 开发，不同功能模块各自为战，导致：

| 问题 | 表现 |
|------|------|
| 按钮样式不统一 | 有的用 ElevatedButton，有的用 TextButton，每次都自定义 styleFrom |
| 输入框样式分散 | TextField 的 decoration 在各页面单独写，没有统一规范 |
| 列表行重复造轮子 | 设置页每个行都手写 Padding + Row + Icon + Text |
| 弹窗组件被遗忘 | MeoTalkDialog 已存在但几乎无人调用 |
| 动画不一致 | 动画时长各处随意写 200ms、300ms、400ms |

### 目标

1. **提供 7 个核心公共组件**（按钮、输入框、列表行、开关等）
2. **补充 Design Tokens**（动画时长、间距常量）
3. **推广现有弹窗组件**（MeoTalkDialog）
4. **制定使用规范**（何时用什么组件）

---

## 🎨 设计原则

参考 Kelivo 的 iOS 风格设计：

| 原则 | 说明 |
|------|------|
| **无水波纹** | 不使用 InkWell 的 Material 水波纹，改用背景色渐变 |
| **轻微缩放** | 按钮按压时可选 0.98 缩放效果 |
| **颜色过渡** | 使用 AnimatedContainer 或 TweenAnimationBuilder |
| **暗色适配** | 每个组件必须适配 dark mode |
| **最小触控区** | 按钮点击区域不小于 44x44 |

## 🧩 组件规范详解

### 1. 按钮组件

#### 1.1 MoePrimaryButton（主按钮）

用于：确认操作、提交表单等主要动作

```dart
/// 主按钮 - 用于主要操作
class MoePrimaryButton extends StatefulWidget {
  const MoePrimaryButton({
    super.key,
    required this.label,
    required this.onPressed,
    this.icon,
    this.isLoading = false,
    this.isEnabled = true,
    this.width,           // 可选固定宽度
    this.height = 48,     // 默认高度
  });
}
```

**视觉规范：**
- 背景色：`moeDialogWarning`（黄色）或主题色
- 文字色：深色
- 圆角：8
- 最小高度：48
- 按压效果：背景色变深 + 可选缩放

#### 1.2 MoeSecondaryButton（次级按钮）

用于：取消、返回等次要操作

```dart
class MoeSecondaryButton extends StatefulWidget {
  const MoeSecondaryButton({
    super.key,
    required this.label,
    required this.onPressed,
    this.icon,
    this.isEnabled = true,
  });
}
```

**视觉规范：**
- 背景色：`moeSurfaceAlt`（浅灰）
- 文字色：`moeText`
- 圆角：8
- 按压效果：背景色变深

#### 1.3 MoeIconButton（图标按钮）

用于：AppBar 按钮、操作栏图标等

```dart
class MoeIconButton extends StatefulWidget {
  const MoeIconButton({
    super.key,
    required this.icon,
    required this.onTap,
    this.onLongPress,
    this.size = 22,
    this.padding = const EdgeInsets.all(8),
    this.color,               // 默认跟随主题
    this.semanticLabel,
    this.enabled = true,
    this.minTapSize = 44.0,   // 最小点击区域
  });
}
```

**实现要点：**
```dart
// 无水波纹，颜色渐变
GestureDetector(
  onTapDown: (_) => setState(() => _pressed = true),
  onTapUp: (_) => setState(() => _pressed = false),
  onTapCancel: () => setState(() => _pressed = false),
  onTap: widget.onTap,
  child: TweenAnimationBuilder<Color?>(
    tween: ColorTween(end: _pressed ? pressedColor : normalColor),
    duration: const Duration(milliseconds: 180),
    builder: (ctx, color, _) => Icon(widget.icon, color: color, size: widget.size),
  ),
);
```

#### 1.4 MoeTileButton（功能入口按钮）

用于：设置项、功能卡片等

```dart
class MoeTileButton extends StatefulWidget {
  const MoeTileButton({
    super.key,
    required this.label,
    required this.icon,
    required this.onTap,
    this.subtitle,

    this.showChevron = true,  // 是否显示箭头
    this.enabled = true,
  });
}
```

### 2. 表单组件

#### 2.1 MoeTextField（统一输入框）

```dart
class MoeTextField extends StatelessWidget {
  const MoeTextField({
    super.key,
    this.controller,
    this.label,
    this.hint,
    this.errorText,
    this.helperText,
    this.prefixIcon,
    this.suffixIcon,
    this.obscureText = false,
    this.maxLines = 1,
    this.keyboardType,
    this.onChanged,
    this.onSubmitted,
    this.enabled = true,
    this.autofocus = false,
  });
}
```

**视觉规范：**

| 属性 | 值 |
|------|-----|
| 背景色 | `moeSurface` |
| 边框颜色 | `moeBorderLight` |
| 聚焦边框 | `moeFocus` |
| 错误边框 | 红色 |
| 圆角 | 8 |
| 内边距 | horizontal: 12, vertical: 14 |
| 标签样式 | fontSize: 12, color: moeTextSecondary |
| 输入样式 | fontSize: 16, color: moeText |

**实现示例：**
```dart
InputDecoration(
  filled: true,
  fillColor: context.moeColors.surface,
  contentPadding: const EdgeInsets.symmetric(horizontal: 12, vertical: 14),
  border: OutlineInputBorder(
    borderRadius: BorderRadius.circular(8),
    borderSide: BorderSide(color: context.moeColors.borderLight),
  ),
  focusedBorder: OutlineInputBorder(
    borderRadius: BorderRadius.circular(8),
    borderSide: BorderSide(color: context.moeColors.focus, width: 1.5),
  ),
  ...
)
```

#### 2.2 MoeSwitch（统一开关）

参考 Kelivo 的 IosSwitch：

```dart
class MoeSwitch extends StatefulWidget {
  const MoeSwitch({
    super.key,
    required this.value,
    required this.onChanged,
    this.activeColor,         // 默认用主题色
    this.inactiveColor,
    this.size = MoeSwitchSize.normal,  // small/normal
    this.enabled = true,
  });
}
```

**视觉规范：**
- 尺寸：44x26（normal）或 36x22（small）
- 动画：AnimatedAlign + AnimatedContainer
- 按压：微缩 0.98

#### 2.3 MoeCheckbox（统一复选框）

### 3. 列表组件

#### 3.1 MoeSettingsGroup（设置分组卡片）

用于：设置页面的分组容器

```dart
class MoeSettingsGroup extends StatelessWidget {
  const MoeSettingsGroup({
    super.key,
    this.title,               // 可选分组标题
    required this.children,   // MoeSettingsRow 列表
    this.titleFirst = false,  // 是否为第一个分组（影响上边距）
  });
}
```

**视觉规范：**
- 背景：白色 96% 透明度（亮色）/ 白色 10% 透明度（暗色）
- 边框：outlineVariant 6% 透明度，宽度 0.6
- 圆角：12
- 内边距：vertical 4
- 分组标题：fontSize 13, fontWeight w600, 上边距 12（首个 2）

#### 3.2 MoeSettingsRow（设置行）

用于：设置分组内的每一行

```dart
class MoeSettingsRow extends StatelessWidget {
  const MoeSettingsRow({
    super.key,
    required this.icon,
    required this.label,
    this.subtitle,
    this.trailing,            // 右侧控件（文字、Switch、自定义）
    this.onTap,               // 点击回调
    this.showDivider = true,  // 是否显示分割线（最后一项为 false）
  });
}
```

**视觉规范：**
| 元素 | 规格 |
|------|------|
| 水平内边距 | 12 |
| 垂直内边距 | 11 |
| 图标尺寸 | 20 |
| 图标区宽度 | 36 |
| 图标与文字间距 | 12 |
| 标签样式 | fontSize 15, fontWeight w500 |
| 副标题样式 | fontSize 13, opacity 0.6 |
| 分割线缩进 | 54（左）, 12（右） |

#### 3.3 MoeListTile（通用列表项）

用于：聊天列表、联系人列表等业务场景

```dart
class MoeListTile extends StatelessWidget {
```

## 📋 使用指南

### 何时使用什么按钮

| 场景 | 使用组件 |
|------|----------|
| 弹窗确认 | MoePrimaryButton |
| 弹窗取消 | MoeSecondaryButton |
| AppBar 图标 | MoeIconButton |
| 设置项/功能入口 | MoeTileButton |
| 功能卡片入口 | GradientBlurCard（已存在） |

### 何时使用什么输入框

| 场景 | 使用组件 |
|------|----------|
| 单行文本 | MoeTextField |
| 多行文本 | MoeTextField(maxLines: N) |
| 搜索框 | MoeTextField(prefixIcon: Icons.search) |
| 密码框 | MoeTextField(obscureText: true) |

### 何时使用什么列表

| 场景 | 使用组件 |
|------|----------|
| 设置页分组 | MoeSettingsGroup + MoeSettingsRow |
| 聊天列表 | 现有 CharacterListItem |
| 通用列表 | MoeListTile |

### 弹窗使用

```dart
// ✅ 正确用法：使用公共弹窗
final confirmed = await showMeoTalkConfirm(
  context: context,
  title: '确认删除',
  message: '删除后无法恢复，确定要删除吗？',
  confirmText: '删除',
  cancelText: '取消',
);

// ❌ 错误用法：自己写 AlertDialog
showDialog(
  context: context,
  builder: (ctx) => AlertDialog(
    title: Text('确认删除'),
    // ... 自定义样式
  ),
);
```

## 📝 代码迁移示例

### 迁移前：硬编码按钮

```dart
ElevatedButton(
  onPressed: () {},
  style: ElevatedButton.styleFrom(
    backgroundColor: const Color(0xFFFFD60A),
    foregroundColor: moeText,
    elevation: 2,
    padding: const EdgeInsets.symmetric(horizontal: 32, vertical: 16),
    shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(8)),

  child: const Text('确认', style: TextStyle(fontSize: 20, fontWeight: FontWeight.w700)),
)
```

### 迁移后：使用公共组件

```dart
MoePrimaryButton(
  label: '确认',
  onPressed: () {},
)
```

### 迁移前：硬编码输入框

```dart
TextField(
  controller: _ctrl,
```

```dart
MoeTextField(
```

## 📊 预期收益

| 指标 | 迁移前 | 迁移后 |
|------|--------|--------|
| 按钮样式一致性 | ❌ 各页面不同 | ✅ 全局统一 |
| 输入框样式一致性 | ❌ 各页面不同 | ✅ 全局统一 |
| 代码重复度 | 高（每处单独写样式） | 低（调用公共组件） |
| 主题切换支持 | 部分支持 | 完全支持 |
| 新页面开发效率 | 需要手写样式 | 直接调用组件 |
| 设计变更成本 | 需要修改每个页面 | 只改组件一处 |
