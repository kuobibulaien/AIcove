# 5. 迁移指南

---

## 📌 概述

本文档说明如何将现有插件迁移到新的插件架构。

**核心原则**：
1. 现有功能逻辑基本不变
2. 只需要补充元数据和生命周期实现
3. 可以渐进式迁移，不需要一次性完成所有插件

---

## 🔄 迁移步骤

假设现有的 TTS 插件长这样：

### 步骤 1：创建元数据

### 步骤 2：继承 BasePlugin

将 `implements Plugin` 改为 `extends BasePlugin`：

```dart
// 迁移前
class TTSPlugin implements Plugin {

// 迁移后
class TTSPlugin extends BasePlugin {
  TTSPlugin() : super(metadata: _metadata);
```

**好处**：
- `BasePlugin` 已经提供了状态管理、配置管理的默认实现
- 不需要再维护 `_enabled`、`_config` 等字段

### 步骤 3：实现生命周期方法

根据插件的实际需求，实现相应的生命周期方法：

```dart
class TTSPlugin extends BasePlugin {
  
  // 资源
  AudioPlayer? _player;
  TTSClient? _client;
  
  TTSPlugin() : super(metadata: _metadata);

  @override
  Future<void> onInitialize() async {
    // 调用父类方法（会设置状态为 ready）
    await super.onInitialize();
    
    // 加载配置
    final savedConfig = await _loadConfigFromStorage();
    if (savedConfig != null) {
      updateConfig(savedConfig);
    }
    
    // 初始化 TTS 客户端
    final apiKey = getConfig()['apiKey'] as String?;
    if (apiKey != null && apiKey.isNotEmpty) {
      _client = TTSClient(apiKey: apiKey);
    }
    
    // 初始化音频播放器
    _player = AudioPlayer();
    
    print('[TTSPlugin] 初始化完成');
  }

  @override
  Future<void> onEnable() async {
    await super.onEnable();
    print('[TTSPlugin] 已启用');
  }

  @override
  Future<void> onDisable() async {
    // 停止当前播放
    await _player?.stop();
    
    await super.onDisable();
    print('[TTSPlugin] 已禁用');
  }

  @override
  Future<void> onDestroy() async {
    // 释放所有资源
    await _player?.dispose();
    _player = null;
    
    await _client?.close();
    _client = null;
    
    await super.onDestroy();
    print('[TTSPlugin] 已销毁');
  }

  @override
  Future<void> onConfigChanged(Map<String, dynamic> newConfig) async {
    // 更新配置
    updateConfig(newConfig);
    
    // 重新初始化客户端
    final apiKey = newConfig['apiKey'] as String?;
    if (apiKey != null && apiKey.isNotEmpty) {
      await _client?.close();
      _client = TTSClient(apiKey: apiKey);
    }
    
    print('[TTSPlugin] 配置已更新');
  }
  
  // ... 其他方法
}
```

### 步骤 4：实现功能注册（可选）

如果插件需要提供命令或 AI 工具，实现相应的方法：

```dart
class TTSPlugin extends BasePlugin {
  // ...

  @override
  List<CommandHandler> getCommands() => [
    CommandHandler(
      command: '/tts',
      alias: {'/语音', '/speak'},
      description: '将文字转换为语音，用法：/tts 要说的话',
      handler: _handleTTSCommand,
    ),
    CommandHandler(
      command: '/tts-stop',
      alias: {'/停止语音'},
      description: '停止当前语音播放',
      handler: (_) async {
        await _player?.stop();
        return '已停止播放';
      },
    ),
  ];

  @override
  List<AITool> getTools() => [
    AITool(
      name: 'speak_text',
      description: '将文字转换为语音并播放。当用户要求朗读或语音播报时使用。',
      parameters: {
        'text': ToolParameter(
          type: 'string',
          description: '要转换为语音的文字内容',
          required: true,
        ),
      },
      handler: _handleSpeakTool,
    ),
  ];

  @override
  List<LLMHook> getHooks() => [
    LLMHook(
      type: LLMHookType.afterResponse,
      handler: _handleAfterResponse,
    ),
  ];

  // === 命令处理器 ===
  
  Future<String> _handleTTSCommand(List<String> args) async {
    if (args.isEmpty) {
      return '用法：/tts 要说的话';
    }
    
    final text = args.join(' ');
    await _speakText(text);
    return '正在播放语音...';
  }

  // === AI 工具处理器 ===
  
  Future<String?> _handleSpeakTool(Map<String, dynamic> args) async {
    final text = args['text'] as String?;
    if (text == null || text.isEmpty) {
      return '错误：没有提供要转换的文字';
    }
    
    await _speakText(text);
    return '已开始播放语音';
  }

  // === LLM 钩子 ===
  
  Future<void> _handleAfterResponse(dynamic context) async {
    // 如果开启了自动播放，AI 回复后自动播放语音
    final autoPlay = getConfig()['autoPlay'] as bool? ?? true;
    if (autoPlay && context is String) {
      await _speakText(context);
    }
  }

  // === 内部方法 ===
  
  Future<void> _speakText(String text) async {
    if (_client == null) {
      print('[TTSPlugin] 客户端未初始化');
      return;
    }
    
    try {
      final audioData = await _client!.synthesize(text);
      await _player?.play(audioData);
    } catch (e) {
      print('[TTSPlugin] 语音合成失败: $e');
    }
  }
}
```

### 步骤 5：保留现有方法

原有的 `getSystemPrompt()` 和 `processResponse()` 方法保持不变：

```dart
class TTSPlugin extends BasePlugin {
  // ...

  @override
  Future<String?> getSystemPrompt({String? userMessage}) async {
    // 保持原有逻辑
    return '''
当你想让用户听到语音时，使用 [TTS] 标签包裹内容。
例如：[TTS]你好，欢迎使用语音功能[/TTS]
''';
  }

  @override
  Future<PluginProcessResult> processResponse(String text) async {
    // 保持原有逻辑
    final List<PluginEvent> events = [];
    String processedText = text;
    
    final regex = RegExp(r'\[TTS\](.*?)\[/TTS\]', dotAll: true);
    final matches = regex.allMatches(text);
    
    for (final match in matches) {
      final ttsContent = match.group(1);
      if (ttsContent != null && ttsContent.isNotEmpty) {
        events.add(PluginEvent(
          pluginId: id,
          type: 'tts_convert',
          data: {'text': ttsContent},
        ));
      }
    }
    
    // 移除 TTS 标签
    processedText = text.replaceAll(regex, '');
    
    return PluginProcessResult(
      processedText: processedText.trim(),
      events: events,
    );
  }
}
```

## 📋 迁移清单

对于每个插件，完成以下检查：

### 基础迁移

- [ ] 定义 `PluginMetadata`（id、name、version、author 等）
- [ ] 定义 `configSchema`（配置项模板）
- [ ] 改为继承 `BasePlugin`
- [ ] 构造函数调用 `super(metadata: _metadata)`
- [ ] 删除原有的 `_enabled`、`_config` 字段（由 BasePlugin 管理）

### 生命周期

- [ ] 实现 `onInitialize()`（初始化资源）
- [ ] 实现 `onEnable()`（启用时的操作）
- [ ] 实现 `onDisable()`（禁用时的操作）
- [ ] 实现 `onDestroy()`（销毁资源）
- [ ] 实现 `onConfigChanged()`（配置变更处理）

### 功能注册（可选）

- [ ] 实现 `getCommands()`（如果提供命令）
- [ ] 实现 `getTools()`（如果提供 AI 工具）
- [ ] 实现 `getHooks()`（如果需要介入 LLM 流程）

### 验证

- [ ] `flutter analyze` 无错误
- [ ] `flutter run` App 正常启动
- [ ] 插件初始化日志正常打印
- [ ] 插件功能正常工作
- [ ] 启用/禁用切换正常

## 🆚 迁移前后对比

### 文件结构

```
迁移前：
lib/src/features/plugins/implementations/tts/
├── tts_plugin.dart          # 单文件，所有逻辑混在一起

迁移后（建议）：
lib/src/features/plugins/implementations/tts/
├── tts_plugin.dart          # 主文件，继承 BasePlugin
├── tts_client.dart          # TTS API 客户端
└── tts_audio_player.dart    # 音频播放器封装
```

### 代码对比

| 方面 | 迁移前 | 迁移后 |
|-----|--------|--------|
| 元数据 | 分散在各个 getter 中 | 集中在 `PluginMetadata` 对象 |
| 状态管理 | 手动维护 `_enabled` | 由 `BasePlugin` 自动管理 |
| 配置管理 | 手动维护 `_config` | 由 `BasePlugin` 自动管理 |
| 资源初始化 | 在构造函数或首次调用时 | 在 `onInitialize()` 中 |
| 资源清理 | 无 | 在 `onDestroy()` 中 |
| 命令支持 | 无 | 通过 `getCommands()` 注册 |
| AI 工具 | 无 | 通过 `getTools()` 注册 |

## ⚠️ 注意事项

### 1. 保持向后兼容

迁移过程中，确保：
- `getSystemPrompt()` 返回值不变
- `processResponse()` 行为不变
- 现有的配置文件格式兼容

### 2. 状态管理

迁移后，不要再手动设置 `_enabled` 字段：
- 启用/禁用由 `PluginManager.enable()` / `disable()` 控制
- 状态由 `BasePlugin` 自动维护

### 3. 生命周期顺序

务必调用 `super.onXXX()` 来确保状态正确更新：

```dart
@override
Future<void> onEnable() async {
  await super.onEnable();  // 先调用父类，设置状态
  // 然后是你的逻辑
}
```

### 4. 错误处理

在生命周期方法中做好错误处理，避免一个插件失败影响整体：

```dart
@override
Future<void> onInitialize() async {
  try {
    await super.onInitialize();
    await _initClient();
  } catch (e) {
    print('[TTSPlugin] 初始化失败: $e');
    // 可以选择抛出异常或设置错误状态
    setState(PluginState.error);
  }
}
```
