# 08 测试方案

> 本文档描述主动关怀系统的测试用例与验收标准

---

## 测试分类

| 类型 | 目的 | 工具 |
|------|------|------|
| **单元测试** | 验证单个函数/类的正确性 | Flutter Test |
| **集成测试** | 验证组件间协作 | Flutter Test + Mock |
| **端到端测试** | 验证完整用户流程 | 手动测试 + 自动化 |

---

## 验收前置条件（最容易遗漏）

很多“看起来像 bug”的问题，其实是基础步骤没做全。施工/验收前先确认：

1. 依赖安装：`flutter pub get`
2. 已用 `flutter run` 启动到真机/模拟器（你这边是安卓真机）
3. App 内开关已打开（路径：`主动回复设置` 页面）
   - 打开 `允许 AI 主动发消息`（对应 `AutoReplySettings.enabled`）
   - 打开 `允许 AI 设定提醒`（对应 Trigger 插件开关，`triggerPluginConfigProvider`）
4. 如果要验收“原生工具调用（tools/tool_calls）”：必须满足
   - provider 的 capabilities 包含 `tools`
   - 配好了直连 `providerApiKey`（否则 `sendMessageRich()` 会直接报错并退化成无 tools 的普通对话）

## 手动验收（推荐流程：不等时间、直接点“立即触发”）

关键页面与文件对应（方便你定位问题）：
- `主动回复设置` 页面：`lib/src/ui/features/auto_reply/pages/auto_reply_settings_page.dart`
- `待触发列表` 页面（含“立即触发/暂停/删除”）：`lib/src/ui/features/auto_reply/pages/auto_reply_trigger_list_page.dart`
- 触发器轮询与 fired 事件：`lib/src/features/chat/data/auto_reply_trigger_controller.dart`
- fired 事件转“主动发消息”：`lib/src/features/chat/data/auto_reply_service.dart`
- 发送链路（注入 tools/执行 tool_calls）：`lib/src/features/chat/services/chat_send_service.dart`
- 两回合工具调用直连：`lib/src/core/api/agent_api.dart`（`sendMessageRich`）
- 三方适配（OpenAI/Claude/Gemini）：`lib/src/core/api/providers/`
- AI 管家触发调度：`lib/src/features/chat/data/analyzer_scheduler.dart`
- App 切后台回调入口：`lib/src/app.dart`

建议验收步骤：
1. 打开 `待触发列表`，先用“创建自定义触发”创建一个 1 分钟后的触发器，确认列表能显示
2. 直接点该条目的 `立即触发`，确认会话里出现一条新的 AI 消息（验证“触发→发消息”链路）
3. 再验收“工具调用创建触发器”（create_reminder）：在聊天里发“明天早上 8 点叫我起床”，然后回到 `待触发列表` 看是否新增条目
4. 验收“两回合工具调用 + list/search/delete”：在聊天里依次发
   - “我有哪些提醒？”（list_reminders）→ AI 应该用人话列出提醒（证明 tool 结果回填成功）
   - “帮我搜一下起床相关的提醒”（search_reminders）→ 能搜到“起床”那条
   - “把起床那条提醒删掉”（delete_reminder 走 query 删除）→ 回到 `待触发列表` 确认被删除
5. 验收“AI 管家自动创建触发器”（schedule_proactive）：发“我去睡了，晚安”，然后按重构目标等待 `5分钟无新消息/切后台` 触发分析（或把 AnalyzerPrompt 临时改成 delay=1 分钟方便观察）

### 1. AutoReplyTrigger 测试

**文件**：`test/features/chat/data/auto_reply_trigger_test.dart`

```dart
void main() {
  group('AutoReplyTrigger', () {
    group('shouldExpire', () {
      test('高优先级触发器不应该作废', () {
        final trigger = AutoReplyTrigger(
          id: 'test',
          priority: AutoReplyTriggerPriority.high,
          contextLastUserMessageId: 'u_10',
          contextLastUserMessageAt: DateTime(2026, 1, 27, 10, 0),

        );

        expect(
          trigger.shouldExpire(
            currentLastUserMessageId: 'u_15', // 用户发了新消息

          ),
          false,  // 仍然不作废
        );
      });

      test('中优先级触发器在用户发新消息后应该作废', () {
        final trigger = AutoReplyTrigger(
          id: 'test',
          priority: AutoReplyTriggerPriority.medium,
          contextLastUserMessageId: 'u_10',
          contextLastUserMessageAt: DateTime(2026, 1, 27, 10, 0),
          // ...
        );

        expect(
          trigger.shouldExpire(
            currentLastUserMessageId: 'u_11',
            currentLastUserMessageAt: DateTime(2026, 1, 27, 10, 1),
            isChatActive: false,
          ),
          true,  // 应该作废
        );
      });

      test('中优先级触发器在用户无新消息时不应该作废', () {
        final trigger = AutoReplyTrigger(
          id: 'test',
          priority: AutoReplyTriggerPriority.medium,
          contextLastUserMessageId: 'u_10',
          contextLastUserMessageAt: DateTime(2026, 1, 27, 10, 0),
          // ...
        );

        expect(
          trigger.shouldExpire(
            currentLastUserMessageId: 'u_10', // 还是同一条用户消息
            currentLastUserMessageAt: DateTime(2026, 1, 27, 10, 0),
            isChatActive: true,  // 即使在聊天界面
          ),
          false,  // 不作废
        );
      });

      test('低优先级触发器在用户聊天界面时应该作废', () {
        final trigger = AutoReplyTrigger(
          id: 'test',
          priority: AutoReplyTriggerPriority.low,
          contextLastUserMessageId: 'u_10',
          contextLastUserMessageAt: DateTime(2026, 1, 27, 10, 0),
          // ...
        );

        expect(
          trigger.shouldExpire(
            currentLastUserMessageId: 'u_10',
            currentLastUserMessageAt: DateTime(2026, 1, 27, 10, 0),
            isChatActive: true,  // 但在聊天界面
          ),
          true,  // 应该作废
        );
      });
    });

    group('shouldFire', () {
      test('活跃触发器到达时间应该触发', () {
        final trigger = AutoReplyTrigger(
          id: 'test',
          status: AutoReplyTriggerStatus.prepared,
          nextFireAt: DateTime.now().subtract(Duration(minutes: 1)),
          allowNight: true,
          // ...
        );

        expect(trigger.shouldFire(DateTime.now()), true);
      });

      test('非活跃触发器不应该触发', () {
        final trigger = AutoReplyTrigger(
          id: 'test',
          status: AutoReplyTriggerStatus.expired,
          nextFireAt: DateTime.now().subtract(Duration(minutes: 1)),
          // ...
        );

        expect(trigger.shouldFire(DateTime.now()), false);
      });

      test('夜间触发器在 allowNight=false 时不应该触发', () {
        final nightTime = DateTime(2026, 1, 27, 2, 0);  // 凌晨2点
        final trigger = AutoReplyTrigger(
          id: 'test',
          status: AutoReplyTriggerStatus.prepared,
          nextFireAt: nightTime.subtract(Duration(minutes: 1)),
          allowNight: false,
          // ...
        );

        expect(trigger.shouldFire(nightTime), false);
      });
    });
  });
}
```

### 2. TriggerPlugin 工具测试

**文件**：`test/features/plugins/trigger/trigger_plugin_test.dart`

```dart
void main() {
  group('TriggerPlugin', () {
    late TriggerPlugin plugin;
    late MockRef mockRef;

    setUp(() {
      mockRef = MockRef();
      plugin = TriggerPlugin(TriggerConfig(enabled: true), mockRef);
    });

    group('getTools', () {
      test('启用时应该返回工具列表', () {
        final tools = plugin.getTools();

        expect(tools.length, 2);
        expect(tools.map((t) => t.name), contains('create_reminder'));
        expect(tools.map((t) => t.name), contains('delete_reminder'));
      });

      test('禁用时应该返回空列表', () {
        plugin = TriggerPlugin(TriggerConfig(enabled: false), mockRef);
        final tools = plugin.getTools();

        expect(tools, isEmpty);
      });
    });

    group('_handleCreateReminder', () {
      test('有效时间格式应该创建触发器', () async {
        // Mock 触发器控制器
        when(mockRef.read(autoReplyTriggersProvider.notifier))
            .thenReturn(mockController);

        final result = await plugin.handleCreateReminder({
          'title': '测试提醒',
          'time': '08:00',
          'prompt': '测试提示',
        });

        verify(mockController.createTrigger(any)).called(1);
        expect(result, contains('08:00'));
      });

      test('无效时间格式应该返回错误', () async {
        final result = await plugin.handleCreateReminder({
          'title': '测试提醒',
          'time': 'invalid-time',
        });

        expect(result, contains('没能理解'));
        verifyNever(mockController.createTrigger(any));
      });
    });

    group('时间解析', () {
      test('应该解析 ISO 8601 格式', () {
        final time = plugin.parseTime('2026-01-27T08:00:00');
        expect(time, isNotNull);
        expect(time!.hour, 8);
        expect(time.minute, 0);
      });

      test('应该解析 HH:mm 格式', () {
        final time = plugin.parseTime('14:30');
        expect(time, isNotNull);
        expect(time!.hour, 14);
        expect(time.minute, 30);
      });

      test('过去的时间应该自动加一天', () {
        // 假设现在是 15:00
        final now = DateTime(2026, 1, 27, 15, 0);
        final time = plugin.parseTime('08:00', referenceTime: now);

        expect(time, isNotNull);
        expect(time!.day, 28);  // 明天
      });
    });
  });
}
```

### 1. 触发器完整生命周期测试

**文件**：`test/integration/trigger_lifecycle_test.dart`

```dart
void main() {
  group('触发器生命周期', () {
    test('创建 → 预生成 → 触发 完整流程', () async {
      // 1. 创建触发器
      await controller.createTrigger(
        title: '早安',
        type: AutoReplyTriggerType.delay,
        nextFireAt: DateTime.now().add(const Duration(minutes: 1)),
        allowNight: false,
        requireExact: false,
        delayMinutes: 1,
        priority: AutoReplyTriggerPriority.medium,
        conversationId: 'conv_1',
        contextLastUserMessageId: 'u_10',
        contextLastUserMessageAt: DateTime(2026, 1, 27, 10, 0),
      );

      // 验证状态
      var trigger = controller.getTrigger('早安');
      expect(trigger.status, AutoReplyTriggerStatus.created);

      // 2. 等待预生成完成
      await Future.delayed(Duration(seconds: 5));
      trigger = controller.getTrigger('早安');
      expect(trigger.status, AutoReplyTriggerStatus.prepared);
      expect(trigger.cachedContent, isNotNull);

      // 3. 模拟时间到达
      await controller.checkAndFire(trigger.id);

      // 验证状态
      trigger = controller.getTrigger('早安');
      expect(trigger.status, AutoReplyTriggerStatus.fired);
    });

    test('创建 → 用户发消息 → 作废 流程', () async {
      // 1. 创建中优先级触发器
      await controller.createTrigger(
        title: '早安',
        priority: AutoReplyTriggerPriority.medium,
        contextLastUserMessageId: 'u_10',
        contextLastUserMessageAt: DateTime(2026, 1, 27, 10, 0),
      );

      // 2. 模拟用户发消息
      mockConversation.messages.add(Message(
        id: 'u_11',
        role: 'user',
        content: '我又想聊两句',
        createdAt: DateTime(2026, 1, 27, 10, 1),
      ));

      // 3. 触发时间到达
      await controller.checkAndFire(trigger.id);

      // 验证被作废
      final trigger = controller.getTrigger('早安');
      expect(trigger.status, AutoReplyTriggerStatus.expired);
      expect(trigger.expireReason, contains('新消息'));
    });
  });
}
```

## 端到端测试场景

### 场景 1：用户主动创建提醒

**步骤**：
1. 用户发送"明天早上8点叫我起床"
2. AI 回复确认并创建触发器
3. 验证触发器列表中有新条目
4. 第二天8点，触发器触发
5. 用户收到 AI 的起床提醒消息

**验收标准**：
- [ ] AI 正确识别用户意图
- [ ] 触发器创建成功，优先级为 high
- [ ] 时间解析正确（明天8点）
- [ ] 触发时发送消息
- [ ] 消息内容自然，不包含系统信息

### 场景 2：AI 管家自动创建关怀

**步骤**：
1. 用户发送"我去睡了，晚安"
2. AI 回复"晚安~"
3. 用户切到后台（模拟对话结束）
4. 系统触发 AI 管家分析
5. AI 管家创建"早安"触发器
6. 第二天早上，触发器触发

**验收标准**：
- [ ] AI 管家正确分析对话
- [ ] 触发器创建成功，优先级为 medium
- [ ] 预生成内容完成
- [ ] 触发时使用预生成内容
- [ ] 消息自然，体现 AI 主动发起

### 场景 3：触发器作废

**步骤**：
1. AI 管家创建"早安"触发器（中优先级）
2. 用户在触发前发送新消息
3. 触发时间到达
4. 系统检测到用户已发新消息
5. 触发器被作废，不发送

**验收标准**：
- [ ] 系统正确检测“最后一条用户消息 id/时间”的变化
- [ ] 触发器状态变为 expired
- [ ] 不发送过时的消息
- [ ] 日志记录作废原因

### 场景 4：低优先级触发器在聊天时作废

**步骤**：
1. AI 管家创建"想你了"触发器（低优先级）
2. 触发时间到达，但用户正在聊天界面
3. 系统检测到用户正在聊天
4. 触发器被作废

**验收标准**：
- [ ] 系统正确检测聊天界面状态
- [ ] 低优先级触发器被作废
- [ ] 不打扰正在聊天的用户

### 场景 5：高优先级触发器不作废

**步骤**：
1. 用户创建提醒"下午3点提醒我开会"
2. 用户在3点前发送了其他消息
3. 3点到达，触发器触发
4. 用户收到提醒消息

**验收标准**：
- [ ] 高优先级触发器不被作废
- [ ] 即使用户发了新消息也会触发
- [ ] 提醒内容正确

## 性能测试

### 1. 预生成性能

- 预生成应在 10 秒内完成
- 预生成不应阻塞主线程
- 预生成失败应有重试机制

### 2. 轮询性能

- 轮询间隔 30 秒
- 单次轮询应在 100ms 内完成
- 大量触发器（100+）时不应卡顿

### 3. 工具调用性能

- 工具注入不应显著增加请求延迟
- 工具调用处理应在 500ms 内完成

## 错误场景测试

| 场景 | 预期行为 |
|------|---------|
| API 超时 | 预生成失败，降级为实时生成 |
| 工具调用参数错误 | 返回友好错误消息 |
| 触发器存储失败 | 重试 + 告知用户 |
| 后台任务被系统杀死 | 下次打开 App 补发 |
| 时间解析失败 | 返回错误，不创建触发器 |
