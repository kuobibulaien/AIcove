## 🛠️ 开发指南

### 新增页面

所有新页面应创建在 `lib/src/ui/features/<模块名>/pages/`

### Import 规范

```dart
// 在 UI 页面中引用业务逻辑
import '../../../../features/chat/chat_actions.dart';

// 引用公共组件
import '../../../../ui/shared/widgets/index.dart';
```

### 服务使用方式

```dart
// 方式1：门面类（推荐，保持向后兼容）
final chatActions = ref.read(chatActionsProvider);
await chatActions.send('Hello');

// 方式2：直接使用服务（更细粒度控制）
final sendService = ref.read(chatSendServiceProvider);
final ttsHandler = ref.read(chatTtsHandlerProvider);
```

### 文件命名规范

```
公共组件：moe_xxx.dart（如 moe_button.dart）
服务文件：xxx_service.dart 或 xxx_handler.dart
页面文件：xxx_page.dart
组件文件：xxx.dart 或 xxx_widget.dart
```
